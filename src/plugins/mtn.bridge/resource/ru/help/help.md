# Мост служб

Плагин подключает внешние программы на любом языке как поставщиков услуг JSON-RPC. Программа читает по одному JSON-сообщению на строку из stdin и пишет по одному в stdout; каждый её инструмент становится услугой `bridge.<сервер>.<инструмент>`.

Откройте «Плагины», выберите «Мост служб», нажмите «Настройки».

- **Серверы** – список JSON. В записи есть `name`, `command` и, по желанию, `args`, `cwd`, `env`, `startTimeoutMs` и `allow` (какие инструменты можно предлагать).
- При сохранении настроек показывается полная командная строка каждого нового или изменённого сервера. Программа запускается только после вашего разрешения; изменённая команда спрашивается снова.
- Списки инструментов читаются один раз и сохраняются. Сохранение настроек их очищает; после этого перезапустите программу.
- Сервер запускается при первом вызове и перезапускается после сбоя до трёх раз подряд.

Пример:

    [{"name": "sample", "command": "python", "args": ["C:/Tools/echo_server.py"]}]

В папке плагина лежит `samples/echo_server.py` – минимальный сервер. Протокол описан в `docs/PLUGIN_SERVICES.ru.md`.
