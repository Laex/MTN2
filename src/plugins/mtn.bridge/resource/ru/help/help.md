# Мост служб

Плагин подключает внешние службы на любом языке как поставщиков услуг JSON-RPC. Сервер – это либо программа, которая читает по одному JSON-сообщению на строку из stdin и пишет по одному в stdout, либо HTTP-адрес, принимающий по одному POST на сообщение. Каждый инструмент сервера становится услугой `bridge.<сервер>.<инструмент>`.

Откройте «Плагины», выберите «Мост служб», нажмите «Настройки». Серверы показаны списком с колонками: номер, имя, тип, программа или адрес, состояние.

- **Добавить**, **Изменить** (F2), **Удалить** (Del) меняют список; **Вверх** и **Вниз** (Ctrl+Вверх, Ctrl+Вниз) меняют его порядок – в этом порядке регистрируются услуги.
- **Проверить** (F5) запускает программу или обращается по адресу, читает инструменты и пишет результат в колонку «Состояние»: число инструментов или причину, по которой сервер недоступен. Если сервер ещё не подтверждён, сначала спрашивается разрешение.
- OK сохраняет список, «Отмена» отбрасывает все изменения, сделанные в диалоге.
- Поля сервера описаны ниже.
- При сохранении настроек показывается полная командная строка или адрес каждого нового или изменённого сервера. Программа запускается, а по адресу обращаются, только после вашего разрешения; после изменения оно спрашивается снова.
- Списки инструментов читаются один раз и сохраняются. Сохранение настроек их очищает; после этого перезапустите программу.
- Сервер запускается при первом вызове и перезапускается после сбоя до трёх раз подряд.

## Поля при добавлении и изменении сервера

Общие для обоих типов:

- **Имя** – короткое уникальное имя: буквы a-z, цифры, `_` и `-`. Входит в имя услуги: сервер `files` с инструментом `list` даёт `bridge.files.list`.
- **Тип** – «Программа (stdin/stdout)» или «HTTP-адрес». От типа зависят поля ниже: ненужные типу поля игнорируются.
- **Запуск, мс** – сколько ждать ответа сервера при запуске и проверке. Пусто – 10000 (10 секунд).
- **Разрешённые службы** – имена инструментов сервера, которые нужно предоставить, через пробел. Пусто – все инструменты.

Тип «Программа»:

- **Программа** – исполняемый файл или команда из PATH (`python`, `node`, `C:\Tools\server.exe`).
- **Аргументы** – через пробел; значение с пробелами – в "двойных кавычках".
- **Папка** – рабочая папка программы (необязательно).
- **Окружение** – дополнительные переменные в виде `ИМЯ=ЗНАЧЕНИЕ` через пробел; значение с пробелами – в кавычках.

Тип «HTTP-адрес»:

- **Адрес** – полный адрес `http://` или `https://`, на который уходят запросы POST.
- **Заголовки** – дополнительные заголовки запроса в виде `ИМЯ=ЗНАЧЕНИЕ` через пробел; значение с пробелами – в кавычках.

## Примеры

Программа на Python:

| Поле | Значение |
|---|---|
| Имя | `echo` |
| Тип | Программа (stdin/stdout) |
| Программа | `python` |
| Аргументы | `C:\Tools\echo_server.py` |

Программа на Node.js с папкой и окружением:

| Поле | Значение |
|---|---|
| Имя | `notes` |
| Программа | `node` |
| Аргументы | `server.js --verbose` |
| Папка | `D:\Work\notes-server` |
| Окружение | `LANG=ru NOTES_DIR="D:\My Notes"` |

Локальный HTTP-сервер:

| Поле | Значение |
|---|---|
| Имя | `local` |
| Тип | HTTP-адрес |
| Адрес | `http://127.0.0.1:8080/rpc` |

Внешний HTTP-сервер с заголовками и ограниченным набором инструментов:

| Поле | Значение |
|---|---|
| Имя | `remote` |
| Тип | HTTP-адрес |
| Адрес | `https://example.com/rpc` |
| Заголовки | `X-Client=mtn2 X-Team="Отдел 5"` |
| Запуск, мс | `5000` |
| Разрешённые службы | `search read` |

После добавления нажмите «Проверить»: в колонке «Состояние» появится число инструментов или причина недоступности.

## Как работает HTTP

HTTP-серверу каждое сообщение уходит POST-запросом с телом JSON. Он отвечает телом JSON или потоком событий (`text/event-stream`), по одному сообщению на событие; заголовок сессии, который он задал, отправляется обратно со следующими запросами.

В папке плагина лежит `samples/echo_server.py` – минимальный сервер. Протокол описан в `docs/PLUGIN_SERVICES.ru.md`.
