# Макросы

Плагин выполняет макросы на Lua. Макрос – текстовый файл в папке `macros` каталога настроек. Он запускается своей клавишей или из меню **Макросы** на панелях, в просмотрщике, редакторе и консоли (не из командной строки). Esc останавливает выполняющийся макрос.

## Запись

* **Ctrl+.** начинает запись нажатых клавиш; **Ctrl+.** ещё раз (или щелчок по метке **ЗАПИСЬ**) завершает её. **Ctrl+Shift+.** ставит запись на паузу и продолжает.
* После записи диалог спрашивает название, клавишу и показ макроса в меню «Макросы». Поле клавиши записывает нажатую комбинацию; Backspace убирает её. Если клавишу уже занимает программа или другой плагин, окно предупреждает: повторный OK всё равно назначает её; после записи занятая клавиша не назначается.
* Макрос сохраняется как файл Lua и редактируется как обычный текст.

## Управление макросами

**Макросы > Управление макросами...** показывает макросы таблицей.

| Клавиша | Действие |
|---|---|
| Enter | запустить |
| Пробел | включить / выключить |
| F2 | назначить клавишу |
| F4 | открыть в редакторе (после сохранения файла макросы перечитываются) |
| F5 | перечитать папку без перезапуска |
| Del | удалить |

Кнопка **Импорт...** принимает файл макроса или папку с ними; **Экспорт...** копирует все макросы в папку.

## Написание макроса

```lua
macro {
  name = "Make folder",
  area = "panels",
  requires = "has_selection",
  key = "Ctrl+Alt+2",
  menu = true,
  run = function()
    mtn.key("F7")
    mtn.text("New folder")
    mtn.key("Enter")
  end,
}
```

| Поле | Значение |
|---|---|
| `name` | название в меню и списке |
| `area` | где работает: `panels`, `editor`, `viewer`, `terminal`, несколько через запятую или `any` |
| `requires` | условия перед запуском через запятую: `has_selection`, `no_selection`, `cursor_file`, `cursor_dir`, `editable`, `modified` |
| `key` | сочетание клавиш, например `Ctrl+Alt+2` |
| `menu` | `true` показывает макрос в меню «Макросы» |
| `run` | функция, которая выполняет работу |

Функции, доступные в `run`:

| Функция | Действие |
|---|---|
| `mtn.key("F7")` | нажать клавишу или сочетание |
| `mtn.text("abc")` | ввести текст |
| `mtn.action(name)` | выполнить команду программы |
| `mtn.state()` | таблица состояния: `area`, `has_selection`, `selected_count`, `cursor_kind`, `cursor_name`, `panel_kind`, `active_side`, `editor_modified`, `editor_has_selection`, `viewer_mode`, `busy`, `jobs` |
| `mtn.selected()` | список отмеченных элементов |
| `mtn.message(text)` | показать уведомление |
| `mtn.wait_idle()` | дать программе отрисовать и обработать начатое макросом |
| `mtn.wait_jobs()` | ждать, пока не завершатся все фоновые задачи (копирование, перемещение, удаление, упаковка, задачи плагинов); задача, задавшая вопрос, ждёт ответа |

Каждый вызов, затрагивающий программу, дожидается, пока программа его обработает, и только потом макрос продолжается. В окружении Lua есть базовая библиотека и `string`, `table`, `math`, `utf8`, `coroutine`; `io`, `os`, `package` и `debug` недоступны. Макрос, который долго работает без ожидания, останавливается.

## Редактор, панели, диалоги и программы

Эти функции тоже ждут, пока программа обработает вызов. Строки и столбцы считаются с 1; сторона панели – `"left"`, `"right"` или `nil` (активная).

| Функция | Действие |
|---|---|
| `mtn.editor.info()` | таблица: `uri`, `lines`, `row`, `col`, `dirty`, `can_edit`, `has_selection`; `nil`, если документа нет |
| `mtn.editor.text()`, `.selection()`, `.current_line()` | весь текст, выделение, текущая строка |
| `mtn.editor.line(n)` | строка `n` или `nil` |
| `mtn.editor.replace(text)` | заменить выделение (или вставить в позиции курсора) |
| `mtn.editor.replace_all(text)`, `.replace_line(text)` | заменить весь текст или текущую строку |
| `mtn.editor.set_cursor(row, col)`, `.set_selection(r1, c1, r2, c2)` | поставить курсор или выделение |
| `mtn.panel.list(side)` | таблица: `path`, `files` (строки с `name`, `uri`), `cursor`, `truncated` |
| `mtn.panel.path(side)`, `.cursor(side)` | путь панели, строка под курсором |
| `mtn.panel.open(uri, side)`, `.set_cursor(uri, side)` | перейти в папку, поставить курсор на элемент |
| `mtn.panel.select(mask, side)`, `.unselect(mask, side)`, `.clear_selection(side)` | отметить, снять отметки по маске, снять все |
| `mtn.panel.select_item(uri, side)`, `.unselect_item(uri, side)` | отметить или снять один элемент |
| `mtn.panel.refresh()` | перечитать панели |
| `mtn.clipboard.get()`, `.set(text)` | буфер обмена |
| `mtn.input(prompt, default, title)` | строка ввода; `nil`, если окно закрыто |
| `mtn.confirm(text, title)` | вопрос «Да/Нет»: `true` или `false` |
| `mtn.choose(title, items)` | выбор из списка строк: номер пункта или `nil` |
| `mtn.exec(program, args, opts)` | запустить программу: вывод и код возврата либо `nil` и причина |

Программа запускается только если её имя (без пути и расширения) перечислено в поле `exec` макроса через запятую, например `exec = "git, hg"`. Параметры `opts`: `stdin` (текст на вход) и `timeout` (секунды, по умолчанию 10, не больше 60). Вывод усекается до 1 МБ. Диалоги недоступны, пока открыт другой диалог.

### События

`mtn.on(тема, функция, {exec = "..."})`, вызванный при загрузке файла, регистрирует обработчик. Когда программа публикует событие (`doc.opened`, `doc.saved`, `doc.changed`, `doc.closed`, `panel.dir`, `panel.cursor`), функция выполняется как макрос и получает таблицу события с полем `topic`. Событие, пришедшее во время работы другого макроса или обработчика, пропускается, чтобы обработчик не запускал сам себя.

```lua
mtn.on("doc.saved", function(e)
  mtn.message("Saved: " .. (e.uri or ""))
end)
```

### Колонки панели

`mtn.column{...}`, вызванный при загрузке файла, добавляет колонку в файловые панели (Параметры – Колонки...).

```lua
mtn.column {
  id = "kb", title = "KB", width = 7, align = "right", default = true,
  value = function(f)
    if f.dir then return nil end
    return f.size // 1024 .. " KB"
  end,
}
```

| Поле | Значение |
|---|---|
| `id` | имя колонки (обязательно) |
| `title` | заголовок, по умолчанию `id` |
| `width` | ширина (по умолчанию 10) |
| `align` | `"left"` или `"right"` |
| `default` | `true` показывает колонку, пока пользователь не выбрал свой набор |
| `value` | функция: получает таблицу файла (`name`, `uri`, `dir`, `size`), возвращает текст или число; `nil` оставляет ячейку пустой |

Значения считаются для обеих панелей при загрузке макросов и при каждой смене папки, для первых 3000 файлов, и только в локальных папках. Функция работает как макрос, но без ожидания: вызовы, которые обращаются к программе (`mtn.key`, `mtn.editor.*`, диалоги, `mtn.exec`), в ней недоступны. Колонка, функция которой вызвала ошибку, отключается до перезагрузки макросов, а сообщение об ошибке показывается один раз. По значениям колонки сортировать нельзя.

Три образца лежат в папке `samples/macros` дистрибутива: сортировка строк без повторов, создание папки, отчёт об отмеченных файлах.
