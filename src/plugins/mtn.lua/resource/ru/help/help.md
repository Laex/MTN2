# Макросы

Плагин выполняет макросы на Lua. Макрос – текстовый файл в папке `macros` каталога настроек. Он запускается своей клавишей или из меню **Макросы** на панелях, в просмотрщике, редакторе и консоли (не из командной строки). Esc останавливает выполняющийся макрос.

## Запись

* **Ctrl+.** начинает запись нажатых клавиш; **Ctrl+.** ещё раз (или щелчок по метке **ЗАПИСЬ**) завершает её. **Ctrl+Shift+.** ставит запись на паузу и продолжает.
* После записи диалог спрашивает название, клавишу и показ макроса в меню «Макросы». Поле клавиши записывает нажатую комбинацию; Backspace убирает её. Если клавишу уже занимает программа или другой плагин, окно предупреждает: повторный OK всё равно назначает её; после записи занятая клавиша не назначается.
* Макрос сохраняется как файл Lua и редактируется как обычный текст.

## Управление макросами

**Макросы > Управление макросами...** показывает макросы таблицей.

| Клавиша | Действие |
|---|---|
| Enter | запустить |
| Пробел | включить / выключить |
| F2 | назначить клавишу |
| F4 | открыть в редакторе (после сохранения файла макросы перечитываются) |
| F5 | перечитать папку без перезапуска |
| Del | удалить |

Кнопка **Импорт...** принимает файл макроса или папку с ними; **Экспорт...** копирует все макросы в папку.

## Написание макроса

```lua
macro {
  name = "Make folder",
  area = "panels",
  requires = "has_selection",
  key = "Ctrl+Alt+2",
  menu = true,
  run = function()
    mtn.key("F7")
    mtn.text("New folder")
    mtn.key("Enter")
  end,
}
```

| Поле | Значение |
|---|---|
| `name` | название в меню и списке |
| `area` | где работает: `panels`, `editor`, `viewer`, `terminal`, несколько через запятую или `any` |
| `requires` | условия перед запуском через запятую: `has_selection`, `no_selection`, `cursor_file`, `cursor_dir`, `editable`, `modified` |
| `key` | сочетание клавиш, например `Ctrl+Alt+2` |
| `menu` | `true` показывает макрос в меню «Макросы» |
| `run` | функция, которая выполняет работу |

Функции, доступные в `run`:

| Функция | Действие |
|---|---|
| `mtn.key("F7")` | нажать клавишу или сочетание |
| `mtn.text("abc")` | ввести текст |
| `mtn.action(name)` | выполнить команду программы |
| `mtn.state()` | таблица состояния: `area`, `has_selection`, `selected_count`, `cursor_kind`, `cursor_name`, `panel_kind`, `active_side`, `editor_modified`, `editor_has_selection`, `viewer_mode` |
| `mtn.selected()` | список отмеченных элементов |
| `mtn.message(text)` | показать уведомление |
| `mtn.wait_idle()` | дать программе отрисовать и обработать начатое макросом |

Каждый вызов, затрагивающий программу, дожидается, пока программа его обработает, и только потом макрос продолжается. В окружении Lua есть базовая библиотека и `string`, `table`, `math`, `utf8`, `coroutine`; `io`, `os`, `package` и `debug` недоступны. Макрос, который долго работает без ожидания, останавливается.

Три образца лежат в папке `samples/macros` дистрибутива: сортировка строк без повторов, создание папки, отчёт об отмеченных файлах.
