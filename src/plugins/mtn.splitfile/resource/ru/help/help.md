# Разрезать / склеить

«Файл» > «Разрезать / склеить...» работает с файлом под курсором (на диске).

- На обычном файле спрашивает папку (по умолчанию папка другой панели) и размер части (`700M`, `1.44M`, `4G` или байты) и записывает `имя.001`, `имя.002`, ...
- На любой части (`имя.001`...) склеивает все части в один файл; имя результата по умолчанию – имя части без номера.
- Работа идёт в фоне. Существующие файлы не перезаписываются; Esc в списке заданий отменяет работу и удаляет незавершённый результат.
- Части – простые куски файла, их можно склеить и командой `copy /b`. Клавиши по умолчанию нет; её можно назначить в диалоге раскладки.
