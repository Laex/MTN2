# Работа с архивами

**Проверить архив** («Файл» > «Проверить архив»): сверяет каждый файл архива под курсором с записанными контрольными суммами, не распаковывая архив (Esc в списке заданий – отмена). ZIP проверяет этот плагин, 7z, RAR, TAR и другие форматы плагина 7-Zip – тот плагин. Целый архив даёт короткое сообщение, повреждённые записи перечисляются по именам.

**Упаковать каждый элемент** («Файл» > «Упаковать каждый элемент»): каждый выбранный файл или папка упаковывается в свой ZIP (`имя.zip`) в папке другой панели; существующий архив не заменяется (новый получит имя `имя (2).zip`). Работает в фоне, Esc в списке заданий – отмена.

Клавиши по умолчанию у команд нет; их можно назначить в диалоге раскладки.
