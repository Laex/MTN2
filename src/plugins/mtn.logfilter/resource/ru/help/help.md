# Фильтр строк

Ctrl+Alt+J в просмотре или редакторе открывает диалог:

- текст или регулярное выражение для поиска;
- параметр «регулярное выражение»;
- параметр «инвертировать»: оставить строки, которые не подходят.

Подходящие строки открываются в новой вкладке просмотра с исходными номерами строк. Исходный документ не меняется.
