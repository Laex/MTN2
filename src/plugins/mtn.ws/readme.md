# Workspace panel (`mtn.ws`)

Панель **ссылок** на файлы и каталоги на диске. Содержимое не копируется: в `ws:///` хранится только reference (`targetUri`). Оригиналы на диске не трогаются, пока вы сами не откроете их в обычной файловой панели.

Схема `ws://` — встроенный VFS ядра (`uWorkspaceVfs.pas`). WASM-модуль в этом каталоге (`plugin.wasm`) не владеет схемой: хост отклоняет `register_vfs_scheme` для `file` / `recycle` / `sys` / `find` / `ws`, чтобы пустая панель не падала в file VFS с «Invalid path». Модуль по-прежнему регистрирует пункты меню, если рядом есть `wasmtime.dll`.

Живой набор ссылок один на процесс. Пока его не сохранили, он только в памяти. **Commands → Workspaces...** (`Ctrl+Shift+D`) — библиотека именованных снимков. **Commands → Save workspace** (`Ctrl+Alt+Shift+D`) пишет текущий набор. Последний открытый снимок поднимается при старте (`session.json` → `lastWorkspaceId`). **Commands → Clear workspace** очищает живой набор сразу. **Ctrl+W** здесь ни при чём: это закрытие вкладки панели, не Workspace.

---

## Три разных «Workspace»

В UI и коде слово встречается в трёх местах. Это не одно и то же.

| Что | Где | Что хранит |
|---|---|---|
| Панель ссылок `ws:///` | Change Drive **4**, этот документ | Ссылки на файлы/каталоги + виртуальные группы F7 |
| Dual Panel Tabs | полоса вкладок окна, `Ctrl+T` / `Ctrl+Tab` | Снимок двух панелей (`wkPanels`), Viewer/Editor (`wkDocument`), терминал (`wkTerminal`) |
| Terminal Workspace | `Ctrl+Shift+N` | сессия ConPTY как вкладка `wkTerminal` |

Библиотека снимков (`Ctrl+Shift+D`) относится **только** к `ws:///`. Вкладки Dual Panel и пути панелей по-прежнему пишутся в `session.json` отдельно.

## Как открыть

| Действие | Как |
|---|---|
| Change Drive | **Alt+F1** / **Alt+F2**, пункт **4** (Workspace) → `ws:///` |
| Курсор popup | если панель уже на `ws:///`, выделен пункт **4**, не первый диск |
| Строка дисков | глиф **4** |
| Меню | **Commands → Workspace** (если загружен WASM-плагин) |
| URI | `ws:///` — корень; `ws:///имя` — виртуальная группа, созданная F7 |

## Что лежит в панели

- **Ссылка на файл** — имя в списке, `targetUri` = исходный `file://…`. Enter / F3 / F4 работают с оригиналом.
- **Ссылка на каталог** — Enter открывает **реальный** каталог на диске (не виртуальный узел `ws://`). **`..` в корне этого каталога** возвращает в Workspace **только на той вкладке панели, которая вошла сюда из `ws:///`**. Соседняя панель (или другая вкладка) на том же пути идёт в обычного дискового родителя. Глубже по дереву `..` всегда дисковый, пока не вернётесь в корень ссылки.
- **Виртуальная папка (F7)** — существует только внутри панели. В ней можно складывать другие ссылки. Своего `targetUri` нет: Enter остаётся внутри `ws://`. **Ctrl+Alt+Enter** на такой строке ничего не делает.

F5 **на** Workspace (активна файловая панель, соседняя — `ws:///`): в список добавляется reference, байты не копируются. Перенос (F6) **на** Workspace запрещён.

F5 **с** Workspace: копируется оригинал в соседнюю панель, если у строки есть реальный путь (ссылка на каталог использует `file://` как URI строки).

## Строка F-клавиш (Dual Panel)

Пока активная панель на `ws://…` (корень или виртуальная группа), нижняя строка переключается в контекст Workspace:

- **F8 = Unlink** (не Del)
- справа подсказка **CtAlt+Ent:GoTo**
- с зажатыми **Ctrl+Alt** — **Ent:GoTo**
- F7 остаётся **MkDir** (виртуальные папки)

После Enter по ссылке на каталог URI панели становится `file://…`: строка снова как у обычных панелей (F8 = Del). **Ctrl+Alt+Enter** при этом по-прежнему работает (см. ниже).

Диалог **Workspaces...** — отдельный контекст F-bar (`fbcWorkspaceLibrary`), не этот.

## Ctrl+Alt+Enter — исходное расположение

Открывает элемент на **соседней** панели и ставит курсор. Файл **не** запускается и **не** открывается во Viewer. Фокус остаётся на исходной панели.

| Где курсор | Что делает |
|---|---|
| Workspace, ссылка на **файл** | Соседняя панель: каталог оригинала, курсор на файле |
| Workspace, ссылка на **каталог** | Соседняя панель: родитель оригинала, курсор на каталоге |
| **Внутри** каталога (после Enter по ссылке, уже `file://`) | Соседняя панель: текущий каталог (для файла) или родитель (для подкаталога), курсор на этом имени |
| Виртуальная папка F7 или `..` | Ничего |

На обычной файловой панели то же сочетание тоже показывает текущий элемент на соседней панели, а не открывает его.

## Сохранённые Workspace

Модель: **один живой набор** `ws:///` + библиотека именованных снимков на диске. Restore **подменяет** живой набор целиком (не сливает с тем, что уже открыто). Пустой живой набор не сохраняется. При выходе грязный набор **не** пишется сам — только то, что уже лежит в `workspaces.json`, плюс id последнего снимка в `session.json`.

Команды ядра (работают без WASM):

| Пункт | Клавиши | Что делает |
|---|---|---|
| **Commands → Workspaces...** | `Ctrl+Shift+D` | диалог снимков |
| **Commands → Save workspace** | `Ctrl+Alt+Shift+D` | записать живой набор. Если снимок уже именован — перезаписать; иначе спросить имя |

### Диалог Workspaces

Заголовок показывает живое имя: `(unsaved)` или имя снимка; `*` — набор изменился после save/restore.

| Клавиша / кнопка | Действие |
|---|---|
| **Enter** / **Go** | восстановить выделенный снимок и открыть `ws:///` в активной панели. Если живой набор грязный — сначала подтверждение («discard?») |
| **Ins** / **Save** | то же, что **Save workspace** |
| **F2** | переименовать снимок в библиотеке |
| **Del** | удалить **снимок из JSON** (см. таблицу ниже) |
| **Esc** / **Cancel** | закрыть диалог |

F-bar, пока открыт список: `Enter:Go`, `Ins:Save`, `Del:Del`, `Esc:Cancel` (`fbcWorkspaceLibrary`). Клик по подписи Ins/Del делает то же, что клавиша.

**Ins на пустом живом наборе** не закрывает список и не спрашивает имя: поверх открывается stub `Nothing to save` (`skShellInfo`). Список остаётся под ним. **Esc** закрывает stub, диалог на месте. F-bar в этот момент — контекст stub (`Enter:OK` / `Esc:Cancel`), потому что видимый stub важнее диалога.

Текущий снимок в списке помечается `[current]`. Рядом — число узлов.

### Три вида «удалить»

| Действие | Что пропадает | Что остаётся |
|---|---|---|
| **F8** на панели `ws:///` (Unlink) | живая ссылка / виртуальная группа | файлы на диске; снимки в `workspaces.json` |
| **Del** в диалоге Workspaces | одна запись библиотеки | живой набор; файлы на диске |
| **Commands → Clear workspace** | все живые ссылки сразу | снимки в JSON; файлы на диске |

### Хранение

`workspaces.json` в каталоге конфига (`GetConfigFilePath`: `%APPDATA%\MTN2\` или рядом с exe при `portable.dat`):

```json
{
  "version": 1,
  "items": [
    {
      "id": "uuid",
      "name": "Daily",
      "nodes": [
        { "path": "/docs", "target": "file:///D:/docs", "dir": true },
        { "path": "/notes/todo.txt", "target": "file:///D:/todo.txt" },
        { "path": "/group", "virt": true }
      ]
    }
  ]
}
```

`session.json`:

| Поле | Смысл |
|---|---|
| `lastWorkspaceId` | id последнего save/restore; `""` — не привязан |
| `restoreWorkspaceOnStart` | при старте поднять этот снимок в живой набор (по умолчанию `true`) |

Код: `uWorkspaceLibrary.pas` (JSON), `uDualPanelWorkspaceLibrary.pas` (диалог), `uWorkspaceVfs.pas` (живой набор), `dialogs/workspaces.json` (`DIALOG_WORKSPACES`).

Диалоги грузятся **только из RCDATA**, не с диска `src/dialogs/*.json`. После правки `workspaces.json` нужен `brcc32` (`src/build.ps1` или Pre-build в `MTN2.dproj`). Канонический exe — `bin\MTN2.exe`; копия `src\Win64\Debug\MTN2.exe` может быть со старым `.dres` и тогда покажет `Dialog resource "DIALOG_WORKSPACES" not found`. Заголовок диалога с em dash в Pascal — `#$2014` (не UTF-8 в `.pas`).

## Меню плагина (WASM)

Нужны `wasmtime.dll` и собранный `plugin.wasm`. Без рантайма пункты не появляются; панель **4** / `ws:///` всё равно работает.

| Пункт | Что делает |
|---|---|
| **Commands → Workspace** | перейти на `ws:///` в активной панели |
| **Commands → Clear workspace** | снять все ссылки и виртуальные папки, затем открыть `ws:///` (`{"uri":"ws:///","clear":true}`) |

Сборка модуля (из этого каталога):

```text
rustup target add wasm32-unknown-unknown
cargo build --target wasm32-unknown-unknown --release
copy target\wasm32-unknown-unknown\release\mtn_ws.wasm plugin.wasm
```

`src/tools/run-panel-smoke.ps1` делает это сам, если в PATH есть `cargo`.

## Отличие от Temporary (`tmp:///`)

| | Workspace `ws:///` | Temporary `tmp:///` |
|---|---|---|
| Содержимое | ссылки, не копии | снимок/список (плагин `mtn.tmp`) |
| F8 на панели | Unlink, оригинал цел | Remove из списка |
| Переход к оригиналу | **Ctrl+Alt+Enter** → соседняя панель + курсор (и внутри каталога после Enter) | Ctrl+PgUp (эта панель), Alt+Shift+F3 (соседняя) |
| Change Drive | **4** | **3** |
