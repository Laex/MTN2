# Просмотр документов

F3 на файле одного из этих типов показывает его текст во встроенном просмотрщике.

| Файлы | Что показывается |
|---|---|
| `.docx` | Абзацы, табуляции и переводы строк основного текста |
| `.xlsx` | Каждый лист строками, ячейки разделены табуляцией (первые 100000 строк листа) |
| `.pptx` | Текст каждого слайда по порядку |
| `.pdf` | Текст, который рисуют потоки страниц |
| `.svg` | Размеры, число элементов, заголовок и текст, затем исходник (с отступами, если он записан несколькими длинными строками) |
| `.sqlite`, `.sqlite3`, `.db`, `.db3` | Схема, затем первые 200 строк каждой таблицы |

Файл только читается и не изменяется. F4 по-прежнему открывает оригинал в редакторе.

В быстром просмотре (Ctrl+Q) показывается тот же текст для файлов до 16 МБ.

Ограничения:

- Текст PDF берётся из текстовых операторов как есть. Сканы, зашифрованные файлы и шрифты с собственной кодировкой дают пустой или нечитаемый текст; тогда файл открывается обычным способом.
- Для формул листа показывается последнее вычисленное значение.
- Файл `.db`, который не является базой SQLite, открывается обычным способом.
