# Сохранение списка

Файлы > Сохранить список в файл... записывает выделенные элементы (без выделения – элемент под курсором) в файл.

**В диалоге задаются**
- имя файла;
- формат – по расширению (`.md` – таблица Markdown, `.csv` – CSV, иначе выровненный текст), обычный текст, Markdown или CSV;
- поля: имя, полный путь, расширение, размер, даты изменения / создания / доступа, тип и атрибуты.

Строку заголовков можно отключить (у таблицы Markdown она есть всегда). Вместо размера у папок выводится `<DIR>`. Выбор запоминается между запусками. Только элементы локальных папок; у пункта нет клавиши по умолчанию – её можно назначить в диалоге назначения клавиш (команда `exportlist.run`).
