# ripgrep

Плагин выполняет поиск по тексту файлов в **Alt+F7** программой [ripgrep](https://github.com/BurntSushi/ripgrep) (`rg`), которая заметно быстрее встроенного обхода на больших деревьях. Нужен `rg` в PATH или рядом с плагином; без него работает встроенный поиск.

Плагин берёт на себя этап поиска текста: при выборочной маске окно поиска запускает конвейер (сначала имена, затем текст), а кнопка **Конвейер** выбирает для этапа **Авто**, **Встроенный** или этот плагин. Поиск внутри архивов, по байтам и по атрибутам всегда идёт встроенным кодом, как и этап, который плагин обслужить не может.
