# Дерево JSON и YAML

Enter на файле `.json`, `.yaml` или `.yml` открывает его как папку (`jtree:///путь/файл.json!/`). Объекты и массивы – папки, значения – файлы. Колонка **Значение** показывает значение (`{3}` / `[3]` для папки с 3 элементами), **Тип** – `object`, `array`, `string`, `number`, `boolean` или `null`.

| Клавиша | Действие |
|---|---|
| Enter | войти в объект или массив |
| F3 | просмотр значения (строка как есть, число и `true` / `false` / `null` как текст) |
| F5 | копировать значение, а для объекта или массива – отформатированный JSON, в локальную папку |

Элементы массива называются по индексу (`00`, `01`, ...), поэтому сортируются по порядку. `/` в ключе пишется как `%2F`. Дерево только для чтения. Файл читается целиком в память, поэтому больше 200 МБ не открывается: показывается ошибка.

YAML: блочные словари и списки, строки в кавычках и без, flow-коллекции в одной строке, блочные строки `|` и `>`, комментарии. Якоря, алиасы, теги и многострочные flow-коллекции не поддерживаются: файл тогда показывается ошибкой с номером строки. Читается только первый документ потока.
