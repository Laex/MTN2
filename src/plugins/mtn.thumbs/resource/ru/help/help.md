# Миниатюры

«Миниатюры папки» в меню «Плагины» открывает лист с картинками (PNG, JPEG, GIF, BMP, TIFF, ICO, WebP) папки активной панели, по имени. Сначала выделена картинка под курсором панели.

- Стрелки, Home, End и Page Up / Down перемещают выделение, колесо мыши листает страницы;
- Enter или двойной щелчок открывает выбранную картинку во встроенном просмотре;
- красный квадрат отмечает файл, который не удалось прочитать.

Показываются только папки на диске. Картинки читаются в фоне, по одной странице. В Linux для чтения нужен SDL2 (BMP) или SDL2_image (остальные форматы).
