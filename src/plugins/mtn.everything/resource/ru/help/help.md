# Everything

Плагин показывает результаты поиска программы [Everything](https://www.voidtools.com/) как панель (`everything:///<запрос>`). Только Windows; Everything должна быть запущена.

**Плагины > Поиск Everything...** спрашивает запрос (синтаксис Everything: `*.log`, `ext:pdf size:>10mb`, `path:"C:\Work" отчёт`) и открывает результаты в активной панели. Запрос хранится в адресе; `/` в нём пишется как `%2F`.

Строки – настоящие файлы, поэтому F3, F4, F5, F6 и F8 работают с ними. Показывается не больше 5000 результатов. Результаты читаются через оконные сообщения Everything, библиотека Everything SDK не нужна.
