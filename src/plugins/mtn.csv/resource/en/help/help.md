# CSV table viewer

F3 on a `.csv` or `.tsv` file shows it as an aligned table with a rule under the header row.

- The delimiter (comma, semicolon, tab) is detected from the first lines.
- Cells in quotes are understood, including doubled quotes and line breaks inside a cell.
- A big file is shown by its first rows; the last line says how many are shown.

F4 opens the file in the editor as usual.
