# Просмотр CSV-таблиц

F3 на файле `.csv` или `.tsv` показывает его выровненной таблицей с линией под строкой заголовка.

- Разделитель (запятая, точка с запятой, табуляция) определяется по первым строкам.
- Ячейки в кавычках понимаются, включая удвоенные кавычки и переводы строк внутри ячейки.
- Большой файл показывается первыми строками; последняя строка сообщает, сколько их показано.

F4 по-прежнему открывает файл в редакторе.
