# Устройства Android (adb)

Плагин добавляет **Android** (`adb:///`) в список дисков (Alt+F1 / Alt+F2). Он запускает программу `adb` из Android platform-tools. Она берётся из PATH, а если там её нет – из папки `platform-tools` Android SDK: `ANDROID_HOME`, `ANDROID_SDK_ROOT` или папка SDK по умолчанию (`%LOCALAPPDATA%\Android\Sdk` в Windows, `~/Android/Sdk` в Linux).

## Подготовка устройства

1. Включите на устройстве параметры разработчика и **отладку по USB**.
2. Подключите кабель и разрешите отладку для этого компьютера в запросе на экране устройства. Устройство по сети подключается командой `adb connect <адрес>` в терминале.
3. В Linux пользователю нужен доступ к USB-устройству (правила udev дистрибутива).

## Список устройств

Каждое подключённое устройство – папка с его серийным номером. Готовое устройство зелёное; жёлтым пока пользоваться нельзя, а колонка «Состояние» говорит почему: `unauthorized` (ответьте на запрос на устройстве), `offline` (переподключите), `no permissions` (правила udev). При открытии такого устройства показывается причина. Ctrl+R перечитывает список.

## Файлы устройства

| Клавиша | Действие |
|---|---|
| F3, F4 | просмотр файла; правка и сохранение |
| F5 | копирование между устройством и локальной папкой или внутри устройства |
| F6 | переименование и перенос внутри устройства; перенос в локальную папку или из неё копирует и затем удаляет |
| F7 | создать папку |
| F8 | удалить файл или папку со всем содержимым (корзины нет) |

Нужен Android 7 или новее. Без root часть системных папок закрыта; общая память лежит в `sdcard`. Копирование между двумя устройствами не поддерживается – копируйте через локальную папку. Просмотр и правка пропускают файл через программу, поэтому большие файлы лучше копировать по F5.

Колонки: в режиме колонок «Custom» (**Columns...**) список устройств может показывать состояние, модель и изделие.
