# Screensavers

The plugin shows a screensaver picture when MTN2 gets no input for a while.
Open Plugins, select Screensavers, press Settings.

- **Random screensaver** – the picture is chosen at random from the available ones.
- **Picture** – which screensaver to show: the sharks, the starfield and the plasma come with the plugin.
- **Start after (minutes)** – the idle time before it starts.
- OK saves the choice, Cancel drops it.

Each picture is one library in the `savers` folder of the plugin. To add your own, put its library into that folder.
