# Хранители экрана

Плагин показывает картинку хранителя экрана, когда MTN2 долго не получает ввода.
Откройте «Плагины», выберите «Хранители экрана», нажмите «Настройки».

- **Случайный хранитель экрана** – картинка выбирается случайно из имеющихся.
- **Картинка** – какой хранитель показывать: в комплекте акулы, звёздное поле и плазма.
- **Запускать через (минут)** – время бездействия до запуска.
- OK сохраняет выбор, «Отмена» его отбрасывает.

Каждая картинка – одна библиотека в папке `savers` плагина. Чтобы добавить свою, положите библиотеку в эту папку.
