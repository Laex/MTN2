# Временная панель

Пункт Temporary в списке дисков (Alt+F1 / Alt+F2) открывает `tmp:///`: панель со списком файлов и папок, собранных из разных мест. Файлы остаются на своих местах; F8 только убирает их из списка.

- Меню «Плагины», «Панель из вывода команды»: выполняет команду и показывает имена существующих файлов и папок из её вывода.
- Меню «Плагины», «Найти повторяющиеся файлы»: сканирует папку активной панели и показывает файлы с одинаковым содержимым.
- F5 и F6 копируют и переносят файлы из списка, как в любой панели.
