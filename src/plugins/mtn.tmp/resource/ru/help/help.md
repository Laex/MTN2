# Временная панель

Пункт Temporary в списке дисков (Alt+F1 / Alt+F2) открывает `tmp:///`: панель со списком файлов и папок, собранных из разных мест. Файлы остаются на своих местах; F7 убирает их из списка, F8 удаляет сами файлы.

- Меню «Плагины», «Панель из вывода команды»: выполняет команду и показывает имена существующих файлов и папок из её вывода.
- Меню «Плагины», «Найти повторяющиеся файлы»: сканирует папку активной панели и показывает файлы с одинаковым содержимым.
- Меню «Плагины», «Отметить лишние копии»: после такого поиска отмечает лишние копии во временной панели. Без отметки в каждой группе остаётся одна копия: самая новая, самая старая или с самым коротким путём; либо остаются все копии из выбранной папки, а группы без копии в ней не трогаются. Файлы, изменённые после поиска, не отмечаются. Ничего не удаляется, пока не нажата F8.
- F5 и F6 копируют и переносят файлы из списка, как в любой панели.
