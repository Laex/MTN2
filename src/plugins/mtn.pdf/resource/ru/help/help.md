# Просмотр PDF

F3 на файле `.pdf` открывает его страницы картинками, которые рисует PDFium: с настоящими шрифтами, изображениями и вёрсткой.

| Клавиша | Действие |
|---|---|
| PgDn, Пробел | Прокрутка на экран вниз; внизу страницы – переход к следующей |
| PgUp, Backspace | Прокрутка вверх; вверху страницы – переход к предыдущей |
| Вверх, вниз, влево, вправо | Прокрутка малым шагом |
| Home, End | Первая и последняя страница |
| `+`, `-` | Увеличить, уменьшить |
| `0` | Страница целиком |
| `w` | По ширине страницы (по умолчанию) |
| `1` | 100% |
| Колесо | Прокрутка; с Ctrl – масштаб |
| Перетаскивание | Двигает страницу |

Быстрый просмотр (Ctrl+Q) показывает текст первых 300 страниц файла до 16 МБ. Tab в быстром просмотре открывает тот же просмотрщик в панели: работают все клавиши из таблицы, а также колесо мыши и перетаскивание; Tab или Esc возвращают файловую панель. Кнопка «Настройки» плагина в Параметры – Плагины задаёт два варианта того, что показывает быстрый просмотр до Tab:

- *Всегда показывать страницы картинками*: рисуется первая страница, даже если в документе есть текст.
- *Показывать страницы картинками, если текст извлечь не удалось* (включено по умолчанию): скан без текстового слоя рисуется, а не остаётся пустой панелью.

Повреждённый файл или файл с паролем открывается другими средствами просмотра. Плагину нужен `pdfium.dll` (в Linux `libpdfium.so`) в его папке; без него работает текстовый просмотр плагина документов.
