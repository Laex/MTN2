# Описания файлов

Файлы > Описание... (Ctrl+Alt+Z) запрашивает строку текста и сохраняет её как описание выбранных элементов (без выделения – элемента под курсором) в файле `Descript.ion` этой папки, в формате Far и Total Commander. Пустая строка удаляет описание. Для одного элемента в строке сразу стоит его текущее описание.

Строка состояния панелей показывает описание файла под курсором. Поддерживаются только папки на локальном диске.
