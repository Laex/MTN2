# File descriptions

Files > Describe... (Ctrl+Alt+Z) asks for a line of text and stores it as the description of the selected items (or, with nothing selected, of the item under the cursor) in the `Descript.ion` file of the folder, in the format Far and Total Commander use. An empty line removes the description. With one item the line starts with its current description.

The status line of the panels shows the description of the file under the cursor. Only folders on a local disk are supported.
