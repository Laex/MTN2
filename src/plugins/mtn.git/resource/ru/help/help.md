# Состояние git

Строка состояния показывает состояние git папки активной панели цветными плашками: ветка, коммиты впереди и позади, файлы в индексе, изменённые, новые и конфликтующие, либо `чисто`.

Имена файлов в панелях окрашены по состоянию в git.

| Клавиша | Действие |
|---|---|
| Ctrl+Shift+G | показать git diff файла под курсором в просмотре |

`git` должен быть в PATH. Папка вне репозитория ничего не показывает.
