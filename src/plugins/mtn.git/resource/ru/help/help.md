# Состояние git

Строка состояния показывает состояние git папки активной панели цветными плашками: ветка, коммиты впереди и позади, файлы в индексе, изменённые, новые и конфликтующие, либо `чисто`.

Имена файлов в панелях окрашены по состоянию в git.

| Клавиша | Действие |
|---|---|
| Ctrl+Shift+G | показать git diff файла под курсором в просмотре |

## Меню «Плагины»

- **Git: добавить в индекс** и **Git: убрать из индекса** работают с отмеченными файлами и папками, а без отметки – с тем, что под курсором. Удаления внутри папки добавляются вместе с ней. Сами файлы при удалении из индекса не меняются.
- **Git: коммит...** показывает, что лежит в индексе, и спрашивает сообщение в одну строку. Сообщение неудавшегося коммита сохраняется до следующей попытки.
- **Git: переключить ветку...** переключает на выбранную локальную ветку. Если переключение затёрло бы локальные изменения, git отказывается.

Команды выполняются в фоне и отменяются из списка заданий. Длинный ответ git, например отказ хука, открывается в просмотре. Pull, push и stash выполняются в консоли.

`git` должен быть в PATH. Папка вне репозитория ничего не показывает.
