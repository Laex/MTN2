# Архивы 7-Zip

Enter на архиве или образе диска (7z, RAR, TAR, GZ, ISO, CAB, WIM, VHD, MSI, DEB, RPM и других) открывает его как папку.

Внутри архива:

- F3 показывает файл, F5 распаковывает файлы под курсором или выделенные;
- F5 из панели в архив добавляет файлы, если 7-Zip умеет обновлять этот формат (7z, zip, tar и другие);
- F8 удаляет записи из такого архива.

В Windows `7z.dll` берётся из папки плагина; в Linux программа `7zz` или `7z` должна быть в PATH.
