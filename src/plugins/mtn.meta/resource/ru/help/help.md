# Метаданные файлов

Плагин показывает в строке состояния метаданные файла под курсором панели. Клавиш и команд он не добавляет.

| Файл | Что показывается |
|---|---|
| JPEG, PNG, GIF, BMP, WebP | формат, размер в пикселях; для JPEG с блоком EXIF – ещё камера и время съёмки |
| MP3 | исполнитель, название, альбом и год (ID3v2 и ID3v1) |
| EXE, DLL (Windows) | версия, компания и описание |

Сегмент появляется через мгновение после остановки курсора и исчезает на файлах других видов. Читаются только локальные файлы и только их начальные байты.

Колонки: в режиме колонок «Свой» (**Колонки...**) панель может показывать для файлов папки:
- изображения: размер в пикселях и камеру;
- файлы MP3: исполнителя, название, альбом и год;
- файлы EXE, DLL, SYS, OCX и SCR (Windows): версию, компанию и описание.

Колонки размера в пикселях, камеры, исполнителя и названия включены по умолчанию; альбом, год, версию, компанию и описание добавляют в **Колонки...** по необходимости. Щелчок по заголовку колонки сортирует по ней: размер в пикселях – по площади изображения, версия – как упорядочиваются версии (`1.10.0.0` после `1.9.0.0`).

Примеры:
- Узнать, какая сборка библиотеки установлена: открыть папку, добавить колонку **Версия** и отсортировать по ней.
- Найти файлы одного производителя в `C:\Windows\System32`: добавить **Компания** и отсортировать по ней.
- Навести порядок в папке с музыкой: показать **Исполнитель**, **Альбом** и **Год**, отсортировать по **Году**.
- Найти самые крупные фотографии: отсортировать по колонке размера в пикселях.
