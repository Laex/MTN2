# Сетевые подключения

Плагин открывает удалённые серверы как папки панелей: **FTP**, **FTPS**, **SFTP**, **SCP**, **WebDAV** (HTTP и HTTPS) и **S3** (Amazon S3 и совместимые службы). С ними работает всё, что панели умеют с папками: просмотр, F3 / F4, копирование и перемещение (F5 / F6) в обе стороны и между двумя серверами, переименование, удаление, создание папки.

## Как открыть подключение

* **Alt+F1 / Alt+F2** – в списке дисков появился пункт **Сетевые подключения** (следующая свободная цифра). Тот же список открывают **Ctrl+Shift+B** и **Команды – Сетевые подключения**.
* В списке подключений: **F7** добавляет подключение, **F4** изменяет то, на котором курсор, **F8** удаляет. **Enter** открывает.
* Сохранённое подключение можно набрать и адресом: `net://Название/папка`, или прямым адресом `ftp://user@host:21/папка`, `ftps://`, `nsftp://`, `scp://`, `dav://`, `davs://`, `s3://бакет/ключ`. Для входа по прямому адресу берётся сохранённое подключение к тому же серверу. Не вписывайте пароль в адрес: адреса попадают в историю папок.

## Окно подключения

| Поле | Значение |
|---|---|
| Протокол | FTP, FTPS (явный TLS; неявный – в «Ещё...»), SFTP и SCP (SSH), WebDAV, WebDAV по HTTPS, S3 |
| Сервер, порт | Имя или адрес сервера; порт можно не заполнять, тогда берётся обычный |
| Пользователь / ключ доступа | Имя для входа. Для S3 – идентификатор ключа доступа, а секретный ключ вводится в поле пароля |
| Вход | Пароль, файл ключа (с паролем ключа), агент SSH, анонимно (FTP) |
| Начальная папка | Где подключение откроется. Для S3 начните с `/бакет` |
| Сохранить пароль | Хранит пароль в зашифрованном виде для пользователя Windows; без флажка пароль спрашивается один раз за запуск |

В «Ещё...» собраны пассивный режим FTP, неявный TLS, проверка сертификатов, кодировка имён файлов, прокси (`socks5h://host:1080`, `http://host:3128`), тайм-аут, регион и способ адресации S3, базовый путь общего ресурса WebDAV.

## Вопросы о доверии

* **Неизвестный ключ сервера** (SFTP / SCP): показывается отпечаток SHA-256; сверьте его с отпечатком сервера и доверьтесь. Ключ сохраняется в подключении и проверяется при каждом входе. **Изменившийся** ключ – предупреждение: между вами и сервером может быть посторонний.
* **Сертификат без доверия** (FTPS, HTTPS): можно продолжить на этот запуск; исправьте сертификат или выключите проверку в подключении, если сервер ваш.

## Замечания

* SFTP плагина отделён от встроенного `sftp://` программы (тот работает через системный `ssh` и только по ключам): подключения плагина спрашивают пароли, проверяют ключи серверов и показывают ход копирования. Для прямого адреса используйте `nsftp://`.
* SCP передаёт содержимое файлов по SCP, а списки папок получает через службу SFTP того же сервера.
* Папки S3 – это префиксы ключей: переименование папки переносит каждый ключ под ней. Большие файлы загружаются частями по 32 МБ.
* Права доступа можно менять по FTP и SFTP. Свободное место показывается для серверов WebDAV, которые сообщают квоту.
* Рядом с плагином (`plugins\mtn.net`) должна лежать `libcurl`. Если её нет, подключение сообщит об этом.
