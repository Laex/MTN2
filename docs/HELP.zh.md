# MTN2 – 用户指南

[English](HELP.md) | [Русский](HELP.ru.md) | [Deutsch](HELP.de.md) | **中文**

Modern Terminal Navigator 2 是一款双面板文件管理器,风格类似 NDN / FAR Manager,内置控制台、终端、查看器和编辑器。

文中的按键均为内置配置下的按键;你可以重新定义它们(见[快捷键](#快捷键))。

## 快捷键

内置按键集可以通过设置文件夹中的 `keymap.json` 文件(或通过**选项 → 快捷键...**)部分重新定义: 只列出更改过的操作,其余保持内置。**Ctrl+Alt+K** – 无需重启即可重新加载该文件。

除面板外,查看器和编辑器的命令也可以重新绑定。它们在 `keymap.json` 中的名称以如下前缀开头:
- `Doc` – 查看和编辑都适用: `DocHex`、`DocFind`、`DocEncoding`、`DocClose` 等;
- `Viewer` – 仅查看: `ViewerWrap`;
- `Markdown` – 渲染后的 Markdown: `MarkdownSource`;
- `Editor` – 仅编辑: `EditorSave`、`EditorUndo`、`EditorDeleteLine` 等。

同一个组合键在面板和文档中可以有不同含义 – Ctrl+H 在面板上显示隐藏文件,在文档中切换十六进制。范围较窄的含义会覆盖较宽的含义: 在渲染后的 Markdown 上 F4 切换源码,而不是十六进制。

全局命令在任何窗口都有效 – 面板、文档、终端:
- `Help` (F1)、`TopMenu` (F9)、`CommandPalette` (Shift+F9);
- `NextTab` / `PrevTab` (Ctrl+Alt+PgDn / Ctrl+Alt+PgUp);
- `AppConsoleToggle` (Ctrl+O)、`NewTerminal` (Ctrl+Shift+N)、`SelectConsoleProfile` (Ctrl+Alt+O);
- `AppQuit` (Alt+X)、`ZoomReset` (Ctrl+0)、`ReloadKeymap` (Ctrl+Alt+K);
- `ToggleMouse` (Ctrl+Shift+M,仅文本终端版本)。

**窗口自己绑定的组合键。**它仍归窗口所有:
- F10 在文档中关闭文档,只有在面板上才退出(`Quit`);
- 面板获得焦点时,面板上的 Esc 显示控制台(`ConsoleToggle`); 在命令行中它先清除命令行,再把焦点交还面板。

**全屏程序。**当控制台或终端中运行全屏程序时(配置的按键模式为*自动*或*终端*,见"终端"),控制台也会收到这些按键,但用于离开控制台的按键除外: F11、Ctrl+O、切换标签页、Ctrl+Shift+N 和 Ctrl+Alt+O。

**对话框。**对话框打开期间全局命令不会触发; `ZoomReset` 和 `ReloadKeymap` 始终触发。

在控制台 (Ctrl+O) 和终端中,名称以 `Shell…` 开头的命令可以重新绑定:
- `ShellHistory` (Alt+F8)、`ShellSelectAll` (Ctrl+A);
- `ShellCopyOrInterrupt` (Ctrl+C – 复制所选内容,没有选择时中断命令)、`ShellCopy` (Ctrl+Ins)、`ShellPaste` (Ctrl+V, Shift+Ins);
- `ShellFind` (Ctrl+Shift+F – 搜索输出)、`ShellFindNext` / `ShellFindPrev` (F3 / Shift+F3);
- 在控制台中还有 `ConsoleSyncDir` (Ctrl+Shift+O – 面板转到控制台的文件夹)。

其他按键都交给 Shell。

**设置 → 快捷键**按窗口对操作分组 – 全局、文件面板、查看器和编辑器、控制台和终端 – 并使用易读的名称; 编辑窗口中会显示 `keymap.json` 中的名称。底部的功能键标签、`A:All` 之类的提示以及顶部菜单中的快捷键都来自键位配置: 重新绑定后它们会显示新的按键。

一个操作可以有多个快捷键: 在编辑窗口中用 `;` 分隔列出,或者在 `keymap.json` 中写成单独的条目。除字母、数字和特殊键外,还可以分配 `/`、`,`、`.`、`'`、`=` 这些符号; 分号和主键盘区的减号写作 `Semicolon` 和 `Minus`(`-`、`+` 和 `*` 表示小键盘上的按键)。

修饰键必须完全匹配: Ctrl+Shift+A 不是 Ctrl+A。方向键、Home/End、输入以及查看器中的 `/` 不可配置。

### 标签页按键

所有标签页按键都是普通的键位操作,可以在 `keymap.json` 中重新绑定。面板标签页和工作区(顶行的标签页)是不同的东西,各有自己的操作:

| 内容 | `keymap.json` 中的操作 | 默认 |
| --- | --- | --- |
| 新建面板标签页 | `NewTab` | Ctrl+T |
| 下一个 / 上一个面板标签页 | `NextPanelTab` / `PrevPanelTab` | Ctrl+Tab / Ctrl+Shift+Tab |
| 关闭面板标签页 | `CloseTab` | Ctrl+W |
| 新建工作区 | `NewWorkspace` | Ctrl+Shift+W |
| 下一个 / 上一个工作区 | `NextTab` / `PrevTab` | Ctrl+Alt+PgDn / Ctrl+Alt+PgUp |

标签行中的 `[+]` 和 `[x]` 按钮以及顶部菜单项作用相同。

### 你自己的 `keymap.json` 和更新

设置文件夹中的 `keymap.json` 叠加在内置键位之上: 它列出的操作优先于内置的操作。
- **设置 → 快捷键**对话框只把更改过的操作写入文件,所以更新后其他按键会跟随内置键位。
- 早期版本保存的文件列出了所有操作,会冻结旧按键: 要获得新按键,请从中删除你需要的那些操作的行,或删除整个文件(如果其中有你自己的更改,请先备份)。
- 没有按键的操作写成空列表。

### Far 和 MC 习惯的示例

仓库里有两个示例 `keymap.json`：[`keymap.far.json` 和 `keymap.mc.json`](https://github.com/Laex/MTN2/tree/main/docs/keymap-presets)。把需要的那个以 `keymap.json` 为名复制到设置文件夹（或把其中的操作加到你自己的文件里），然后按 **Ctrl+Alt+K**。
- **Far：**面板中的 Esc 清空命令行，不再打开控制台（仍可用 Ctrl+O）。
- **MC：**Alt+. 显示隐藏文件，Ctrl+\ 打开文件夹列表，Alt+Enter 把文件名插入命令行，Alt+A 和 Alt+Shift+A 插入活动面板和另一面板的文件夹路径，属性改为 Ctrl+Shift+P。

### 保留按键

尚未占用,留给计划中的功能: **Shift+F3**(压缩包命令)、**F11**(插件菜单)、**Ctrl+Alt+Ins**(网络 UNC 路径)、**Ctrl+.**(宏录制)。自动检查会防止内置键位占用它们。

## 程序界面

从上到下:
- **顶部菜单** – 左面板 / 文件 / 编辑 / 命令 / 选项 / 右面板几个类别和一个时钟。用 **F9**、**Alt** 或点击打开。
- **工作区标签页** – 面板和终端的组合(见[标签页和工作区](#标签页和工作区))。
- **两个文件面板** – 活动面板用边框高亮; **Tab** 切换两侧。驱动器字母显示在面板的底边。
- **命令行** – 带当前文件夹的提示符。
- **功能键栏** – 当前模式下各操作的提示; 可以点击。按住 Shift / Ctrl / Alt 时,栏中显示对应的操作。在宽度不少于 100 列的窗口中,面板上的栏左侧还会标出命令面板的按键。
- **状态栏** – 面板信息; 点击某一段会打开相关对话框: 左右侧和可用空间打开驱动器列表, 路径打开文件夹历史, 列模式打开模式菜单, 当前项或选中项打开属性。在查看器和编辑器中: 位置打开“转到行”, 编码打开编码列表, 搜索结果打开“查找”。

**控制台**位于面板下方: **Ctrl+O**(或焦点在面板上时按 **Esc**)隐藏面板并显示命令输出。

如果 MTN2 本身以管理员身份启动,窗口标题会显示 **[管理员]**; 管理员助手运行期间显示 **[管理员助手]**(见[文件操作](#文件操作))。

**对话框按钮**像真实按钮一样按下: 被按下的按钮向右移动并盖住自己的阴影。
- **鼠标。**在同一个按钮上松开鼠标键才会执行命令; 把指针移开再松开,则什么都不会发生。
- **Enter 和空格。**会让按钮保持按下状态直到松开按键,松开时执行命令; 期间按 **Esc** 会让按钮弹起,不执行命令,对话框保持打开。
- **高亮字母和 Y / N。**会让按钮短暂按下然后触发。
- 其他情况下 **Esc** 立即关闭对话框。

**对话框中的热键字母。**按钮、复选框和单选按钮的标题中有一个字母以颜色高亮(某些主题中带下划线)。
- 按该字母会按下按钮、切换复选框或选中单选按钮; 焦点在输入框中时,需配合 Alt 使用。
- 该字母在另一种键盘布局下同样有效: 高亮字母为 S 的"跳过",既响应 S,也响应另一种布局中同一物理键上的字母。
- 默认按钮(带尖括号)和取消按钮不需要字母 – 由 Enter 和 Esc 负责。

**F1** – 当前屏幕内容的帮助(面板、查看器、打开的对话框或菜单); 在帮助中按 **F1** – 目录。**F10** – 退出。

## 面板和导航

| 按键 | 作用 |
| --- | --- |
| ↑ ↓ PgUp PgDn Home End | 移动光标 |
| ← / → | 在简要模式下 – 向左 / 向右移动一列; 在其他模式下 – 到第一项 / 最后一项(同 Home / End) |
| Enter | 进入文件夹 / 压缩包,打开文件(按[文件关联](#文件关联)); 控制台程序在内置控制台中运行(见下文) |
| Backspace | 上一级,相当于在 `..` 上按 Enter(命令行为空时; 否则在命令行中删除一个字符) |
| Ctrl+PgUp / Ctrl+PgDn | 上一级 / 进入光标处的文件夹,与 FAR 相同; 在文件上, Ctrl+PgDn 把它作为压缩包打开(见[压缩包](#压缩包)) |
| Shift+Enter | 在单独的系统窗口中运行文件或命令 |
| Alt+Shift+Enter | 在后台运行命令行: 控制台短暂显示,然后面板回来,命令行为空时以同样方式运行光标下的控制台程序 |
| Ctrl+Alt+Enter | 在新的终端标签页中运行命令行(使用后台控制台的 Shell),命令行为空时在面板标签页的终端标签页中运行光标下的控制台程序 |
| Alt+Shift+F3 | 在另一个面板中显示光标下的项目 |
| Tab | 切换活动面板 |
| Ctrl+\\ | 转到驱动器根目录(在压缩包内 – 退出压缩包) |
| Alt+← / Alt+→ | 文件夹历史后退 / 前进 |
| Ctrl+U | 交换面板 |
| Ctrl+] | 非活动面板 := 活动面板的文件夹 |
| Ctrl+[ | 活动面板 := 非活动面板的文件夹 |
| Ctrl+F1 / Ctrl+F2 | 隐藏 / 显示左 / 右面板 |
| Ctrl+P | 隐藏 / 显示非活动面板 |
| Ctrl+L | 在另一侧显示信息面板(驱动器、内存) |
| Ctrl+H | 显示 / 隐藏隐藏文件和系统文件 |
| Ctrl+R | 刷新面板 |
| Ctrl+Q | 在另一个面板中快速查看文件: 图片、文本、Markdown 或十六进制 |
| Alt+F10 | 活动面板上方显示驱动器的文件夹树(见下文) |
| Alt+字母 | 在面板中按名称快速搜索 |

**文件夹树 (Alt+F10)** 在活动面板上方打开。同一时间只能在一个面板上方打开文件夹树。

**打开。**显示驱动器根目录,到当前文件夹的路径已展开,光标位于其上。

**键盘**
- ↑ ↓ PgUp PgDn Home End – 移动。
- → 或 `+` – 展开分支(`[+]─`)或进入分支。
- ← 或 `-` – 折叠分支(`[-]─`)或回到上级。
- 字母 – 跳到下一个以它开头的文件夹。
- Enter – 在活动面板中打开该文件夹并关闭文件夹树。
- Esc 或 Alt+F10 – 关闭文件夹树,同一个面板重新显示。

**另一个面板。**光标停下后,另一个面板会转到光标处的文件夹。

**焦点**
- Tab 或点击另一个面板会把焦点移到那里,文件夹树保留,就像 FAR 的树面板。
- Tab 或点击树的边框会把焦点带回来。

**鼠标。**树起索引的作用:
- 点击文件夹会立即在另一个面板中显示它并把焦点移过去;
- 点击 `[+]` / `[-]` 展开或折叠分支而不移动焦点;
- 鼠标滚轮滚动树而不移动光标。

**跟随与后台读取**
- 另一个面板转到另一个文件夹时,树会展开到该路径并把光标放在那里,换驱动器时会重新构建。
- 文件夹在后台读取; 如果期间树下面的面板转到了别的文件夹,树会关闭。

**快速查看 (Ctrl+Q)** 在另一个面板中显示光标处的文件: 图片、文本(自动检测编码)、渲染后的 Markdown 或二进制文件的十六进制转储。
- 大文件以流方式读取。
- 鼠标滚轮可在预览上滚动。
- SFTP 上的文件和压缩包内的大文件不会在每次移动光标时读取 – 面板会提示用 F3 打开它们。
- Tab 或再次按 Ctrl+Q 关闭快速查看。

**控制台程序**(控制台子系统的 `.exe`、`.bat`、`.cmd`、`.ps1`)按 Enter 运行,使其输出留在屏幕上,而不是在单独的 Windows 窗口中:
- 当后台控制台(Ctrl+O)的 Shell 是 cmd、PowerShell 或 pwsh 且其中没有运行任何内容时,在其中运行: 与在命令行中输入的命令相同;
- 其他情况(WSL、Git Bash 或 SSH 控制台,或者控制台正忙于其他命令) – 在使用 cmd 的新终端标签页中运行, `.ps1` 则使用 PowerShell; 程序结束后标签页保持打开。

勾选**在终端标签页中运行面板中的程序**(**命令 → 后台控制台...**)后,所有控制台程序都在终端标签页中运行,因此程序运行期间其他标签页仍可使用。
- 从面板标签页启动的第一个程序会在其旁边打开一个终端标签页。
- 后续程序在该标签页的 Shell 空闲且输入行为空时输入到其中(在文件所在文件夹),否则打开新标签页。
- 该标签页的 Shell 有自己的环境配置(Shell 列表中按 **F6**)和自己的 Shell 历史。

窗口程序和文档仍用其 Windows 程序打开。**Shift+Enter** 仍然在单独的窗口中运行任何文件。

鼠标单击放置光标,双击相当于 Enter。可以用鼠标在面板之间以及向其他程序(和从其他程序)拖动文件。

## 选择文件

| Ins | 选择 / 取消选择并下移 |
| Shift+方向键, Shift+Home/End/PgUp/PgDn | 随光标移动选择 |

### 掩码组

<!--mask-groups-->在任何掩码（选择、面板过滤、搜索、颜色组）中，`@名称` 表示一组命名的掩码，例如 `@Images` 或 `*.log;@Documents`。内置 Images、Audio、Video、Documents、Archives 和 Sources。自定义组通过“选项”菜单中的“掩码组...”管理（设置文件夹中的 `maskgroups.json`）；按掩码选择的对话框也可以把其掩码保存为组。在对话框的掩码字段中，Ctrl+G 会把输入的掩码保存为以第一个掩码命名的组，并在字段中填入 `@名称`。

## 文件操作

| 按键 | 作用 |
| --- | --- |
| F3 | 查看文件; 在文件夹上 – 计算所选文件夹的大小(Esc – 取消) |
| F4 | 编辑 |
| Shift+F4 | 新建文件 |
| F5 | 复制 |
| Shift+F5 | 在同一文件夹中以另一个名称复制 |
| F6 | 移动 / 重命名 |
| Shift+F6 | 重命名光标处的项目 |
| F7 | 新建文件夹 |
| Alt+F6 | 创建链接(符号链接、硬链接、联接点) |
| F8, Del | 删除到回收站 |
| Shift+F8, Shift+Del | 永久删除(擦除) |
| Ctrl+A | 属性、所有者和日期(创建 / 修改 / 访问) |
| Alt+Enter | Windows"属性"窗口(针对所选项目或光标处的项目; 仅限磁盘上的文件和文件夹) |
| Shift+F10, 菜单键 | Windows 右键菜单(针对所选项目或光标处的项目) |
| Ctrl+Alt+C | 比较两个面板光标所在的文件，或活动面板中标记的两个文件；对话框显示大小、修改时间和内容比较结果 |
| Ctrl+Alt+H | 所选文件和文件夹的校验和(MD5、SHA-1、SHA-256、SHA-512); 在 `.md5` / `.sha1` / `.sha256` / `.sha512` 文件上 – 校验它 |
| Ctrl+Alt+M | 批量重命名选中的项目:名称与扩展名掩码、计数器、查找替换、字母大小写 |
| Ctrl+C / Ctrl+X / Ctrl+V | 通过剪贴板复制 / 剪切 / 粘贴文件 |
| Alt+Shift+Ins | 把完整路径复制到剪贴板 |
| Ctrl+Shift+Ins | 只把名称(不含路径)复制到剪贴板 |
| Ctrl+Z | 文件说明: 一个输入行,文字保存在文件旁边的 `Descript.ion` 中 |

**Alt+Shift+Ins** 和 **Ctrl+Shift+Ins** 取所选项目(每行一个),没有选择时取光标处的项目; 在 `..` 上则取当前文件夹。结果可用 **Shift+Ins** / **Ctrl+V** 粘贴到任何地方。右下角会有一条简短通知确认复制(或说明没有可复制的内容); 可以在**选项 → 界面...**中关闭。

<!--export-list-->**文件 → 导出列表...** 把所选项目(没有选择时为光标处的项目)保存到文件。

**对话框中可设置**
- 文件名;
- 格式 – 按扩展名(`.md` 为 Markdown 表格,`.csv` 为 CSV,其他为对齐的文本)、纯文本、Markdown 或 CSV;
- 字段: 名称、完整路径、扩展名、大小、修改 / 创建 / 访问日期、类型和属性。

标题行可以关闭(Markdown 表格始终有标题行)。文件夹的大小处显示 `<DIR>`。所选设置在重启后保留; 该菜单项没有默认快捷键,可在按键设置对话框中分配(动作 `ExportList`)。

<!--attributes-->在 **Ctrl+A** 对话框中,日期按系统日期格式输入,时间格式为 `hh:mm:ss`(秒和时间部分可省略)。
- 输入框留空则保持原日期: 所选文件的日期不同时就这样显示。
- **当前**会把当前时间填入三个输入框,**原始**恢复从文件读取的值。
- "包含子文件夹"同样适用于日期。

同一对话框还包含文件的其他标志: **已压缩**、**已加密**、**不索引**、**稀疏**、**临时**和**脱机**(每项: 保持 / 设置 / 清除; 压缩、加密和稀疏标志由文件系统执行,不支持的卷会报错)。

**驱动器根目录。**对于驱动器根目录(在 **Alt+F1** / **Alt+F2** 驱动器列表中按 **F4**),顶部显示卷(GUID 路径)和设备; **系统属性**按钮打开 Windows 属性窗口。

**Windows 右键菜单** – 与在资源管理器中右键点击相同的菜单: "打开方式"、"发送到"、压缩软件、杀毒软件和版本控制项目等。

**打开方式:**用 **Shift+F10** 或**菜单键**在光标行打开,也可通过**文件 → Windows 右键菜单**,或在文件上按住鼠标右键约一秒。

**作用对象**
- 用键盘和菜单打开时,作用于所选项目,没有选择时作用于光标处的项目(在 `..` 上 – 作用于当前文件夹)。
- 按住鼠标键则打开鼠标下文件的菜单。

仅限磁盘上的文件和文件夹: 压缩包、SFTP、回收站和搜索结果没有 Windows 菜单。

<!--copy-->复制/移动对话框可让你保留所有时间戳、只复制较新的文件、复制符号链接的内容并设置排除掩码。出现名称冲突时,程序会询问如何处理(覆盖、跳过、重命名,可应用于全部…)。

<!--checksums-->**校验和。**它们在后台计算(Esc – 取消)。在结果列表中: **复制** – 到剪贴板, **保存** – 到 `<文件>.sha256`(单个文件)或面板文件夹中的 `checksums.sha256`。校验会把每一行标记为 `OK`、`FAILED` 或 `MISSING`。可识别 `hash *name`、`hash  name` 和 `SHA256 (name) = hash` 这几种行。

<!--multi-rename-->**批量重命名。**名称和扩展名掩码支持:
- `[N]` – 原名称,不含扩展名;
- `[E]` – 原扩展名;
- `[C]` – 计数器,可设置起始值、步长和位数;
- `[Date]` 和 `[Time]` – 修改日期(`2026-11-05`)和时间(`14-30-07`); `[Year]`、`[Month]`、`[Day]` – 日期的各部分;
- `[Parent]` – 文件夹名称; `[Size]` – 以字节为单位的大小;
- `[Dim]`、`[Camera]`、`[Artist]`、`[Title]` – 元数据插件列的值(图像尺寸和相机、音频艺术家和标题),与面板显示一致; 插件读取文件前为空;
- 其他文本原样保留。

“查找”和“替换”作用于新的名称和扩展名,字母大小写从列表中选择。 启用“正则表达式”后,“查找”是模式,“替换”可使用 `$1`、`$2`; 无效的模式会使名称保持不变。标记不区分大小写; 未知的值为空,名称不能包含的字符会变为 `_`。字段下方的列表即时显示“原名 -> 新名”。

**错误。**名称为空、无效、重复或在文件夹中已存在(包括选中的其他项目)时以 `!` 标记,仍有此类名称时 **重命名** 不会执行。

只能选择同一文件夹中的项目。重命名与移动一样作为后台任务运行。

<!--admin-->**受保护的文件夹。**当本地路径上的复制、移动、删除、新建文件夹或重命名因"拒绝访问"失败时(例如在 `C:\Program Files` 中),错误窗口会提供**管理员**按钮,而新建文件夹和重命名会询问"以管理员身份重试?"。

**工作方式**
- 确认后 Windows 会显示通常的 UAC 提示,MTN2 启动一个具有管理员权限的小型助手进程。
- 失败的项目和任务的其余部分在其中运行,使用相同的进度和错误窗口。
- 在你确认之前,不会以这些权限运行任何内容。
- 助手运行期间,窗口标题显示 **[管理员助手]** 并有通知说明; 它在两分钟没有工作后会自行结束,或在 MTN2 关闭时结束。

**限制**
- 助手只在本地路径上复制、移动、删除、创建文件夹和保存文本: 它不能启动程序,而且只有启动它的那个 MTN2 能与它通信。
- 压缩包和虚拟文件夹没有这一步。

**以管理员身份运行 MTN2。**如果 MTN2 本身以管理员身份启动(右键,以管理员身份运行),标题显示 **[管理员]**,不需要助手; 此时 Windows 会阻止来自资源管理器等非提权程序的拖放。

## 命令行和控制台

命令行始终在面板下方: 直接开始输入即可。命令在内置控制台中运行; 用 **Ctrl+O** 查看其输出。

| 按键 | 作用 |
| --- | --- |
| Enter | 运行命令; 输入的文件夹路径会转到该文件夹,文件(包括用 Ctrl+Enter 放到命令行里的名称)会被运行: 控制台程序在内置控制台中运行,其他程序用其 Windows 程序运行。之后焦点回到面板,方向键又可以移动光标 |
| Ctrl+↓ / Ctrl+↑ | 聚焦命令行 / 返回面板 |
| ↑ / ↓(输入命令时) | 命令历史 |
| Tab | 补全: 面板中的名称,或当词中含有 `\`、`/` 或 `X:` 时补全磁盘上的路径(重复按键会在匹配项之间循环) |
| Ctrl+↓ / Alt+↓(焦点在命令行时) | 以列表形式显示命令历史: Enter – 放到命令行, Del – 从历史中删除, Esc – 关闭 |
| 在命令行中键入 | 以所键入文本开头的旧命令会以列表形式显示在命令行上方,列表不占用按键: ↑ / ↓ 选择条目, Enter 放到命令行(未选择时 Enter 运行命令行), Del 从历史中删除, Esc 关闭列表。开启「键入时不将焦点移到命令行」后,在面板上键入的内容会进入命令行但不移动焦点(空格和退格仅在命令行已有文本时); 用 Ctrl+↓ 或鼠标点击移动焦点 |
| Ctrl+Enter | 插入光标处项目的名称 |
| Ctrl+F, Ctrl+Shift+Enter | 插入项目的完整路径 |
| Alt+Shift+Enter | 在后台运行命令行: 控制台会短暂显示开始运行,然后面板回来(见下面的**选项 → 控制台...**),命令行为空时以同样方式运行光标下的控制台程序 |
| Ctrl+Alt+Enter | 在新的终端标签页中运行命令行: 新建一个使用后台控制台 Shell(cmd、PowerShell、WSL 等)的工作区标签页,命令在其中启动,标签页保持打开,命令行为空时在面板标签页的终端标签页中运行光标下的控制台程序 |
| Esc | 逐步执行: 清除命令行 → 把焦点交还面板 → 显示控制台。命令行为空时跳过第一步; 焦点在面板上时, 先清除命令行中残留的文本, 命令行为空时 Esc 直接显示控制台 |
| Ctrl+O | 面板 ↔ 控制台 |
| Ctrl+Shift+O | 同步活动面板和控制台之间的文件夹 |
| Ctrl+Alt+O | 选择后台控制台的 Shell(cmd、PowerShell、WSL 等) |

<!--console-profile-->**命令 → 后台控制台...**是同一个对话框。
- **程序启动时启动 Shell**默认关闭: Shell 在第一次按 **Ctrl+O** 或第一次从命令行运行命令时启动。开启此选项则像以前一样,Shell 与程序一起启动。
- **在终端标签页中运行面板中的程序**使面板中按 Enter 启动的控制台程序在终端标签页中运行,而不是在此控制台中。

**在控制台中:** **Ctrl+C** 中断命令; **Esc** 只隐藏控制台,不会停止进程。鼠标滚轮滚动输出。文本用鼠标选择(见[文本和鼠标操作](#文本和鼠标操作))。

**搜索输出**(控制台和终端):
- **Ctrl+Shift+F** 询问要查找的文字; 匹配项在整个历史中高亮,当前匹配项像鼠标选择一样被选中。在对话框中输入空字符串可清除搜索。
- **F3** / **Shift+F3** 跳到下一个 / 上一个匹配项(循环),前提是已设置搜索且窗口中没有运行全屏程序。
- 在使用 cmd 的控制台中, **↑** / **↓** 翻阅共享命令历史(同 Alt+F8),在最新命令之后按 **↓** 会恢复已输入的行。

**粘贴到控制台**(**Ctrl+V**, **Shift+Ins**): 每个换行都会作为 Enter 发送给 Shell,因此粘贴的各行会依次运行,最后一行也一样。开启**粘贴多行时确认**后,程序会先询问。

**选项 → 控制台...**设置:
- 控制台和终端的回滚大小(1000 – 50,000 行,默认 10,000);
- 粘贴多行时的确认(默认关闭; vim 等全屏程序从不询问);
- 复制和粘贴时去掉行尾空格;
- **命令结束后总是返回面板**(默认关闭)。开启后,从面板下方命令行运行的命令,在 Shell 重新显示提示符时会立即带你回到面板; 在后台控制台(Ctrl+O)中输入的命令则始终留在控制台。

**后台运行。****Alt+Shift+Enter** 在后台运行控制台中的命令行: 控制台会按**后台运行**中设置的时间显示(0.5 – 10 秒,默认 2 秒),然后面板自动回来。在此之前如果在控制台中按了键,它会保持在前台; 命令无论如何都会继续运行。

更改立即生效,对已打开的控制台也一样。

<!--save-output-->**命令 → 保存控制台输出...**把后台控制台(Ctrl+O)的回滚内容写入 UTF-8 文本文件; **清空控制台缓冲区**会擦除它,Shell 继续运行。

## 终端

**Ctrl+Shift+N** – 在单独的工作区标签页中新建终端: 选择 Shell 配置(cmd、PowerShell、WSL、已保存的 SSH 连接)。全屏程序(vim、mc、htop 等)在终端中的表现与普通控制台一样。

<!--profiles-->在配置列表中:

- **1-9, 0, A-Z** – 启动对应编号的配置(显示在行首的高亮字符)。
- **Ins** – 复制所选配置: 同一个 Shell,独立的设置。**Del** 删除副本(配置本身不能删除)。
- **Ctrl+Up / Ctrl+Down** – 移动配置; 顺序会被记住(设置文件夹中的 `shellprofiles.json`)。
- **F4** – 配置的按键模式。选择了对应配置时,该模式同样适用于后台控制台(Ctrl+O)。

模式:
- *自动* – 控制台中运行 mc、vim 等全屏程序时,按键交给程序;
- *终端* – 程序获得所有按键,包括 F1、F9 和 Alt+字母;
- *主机* – MTN2 窗口的按键优先。

在*自动*和*终端*模式下,窗口只保留用于离开控制台的按键: F11、Ctrl+O、切换标签页、Ctrl+Shift+N 和 Ctrl+Alt+O。
- **F6** – 所选 shell 或其副本的环境配置文件(参见 [环境配置文件](#环境配置文件))。

## 环境配置文件

**选项 → 环境配置文件...** 在编辑器中打开 `environment.json` 文件(首次使用时会创建并写入一个示例)。

配置文件是一份命名的 `NAME=值` 条目列表,会叠加到每个新 shell 的环境上:终端标签页和面板下方的控制台。已在运行的 shell 保持原有环境;保存文件之后启动的 shell 会看到更改。

```json
{
  "profiles": [
    { "name": "default", "vars": ["EDITOR=vim", "WORK=%TEMP%\\work", "OLD_VARIABLE="] },
    { "name": "proxy", "auto": false, "shells": ["pwsh"], "vars": ["HTTPS_PROXY=http://proxy:3128"] }
  ]
}
```

**条目。**
- 配置文件按文件中的顺序应用,条目按列表顺序应用,因此后面的条目能看到前面条目的结果。
- 值为空的条目(`OLD_VARIABLE=`)会删除该变量。
- `%NAME%` 在所有系统上都会被替换为变量的当前值;在 Linux 和 macOS 上 `$NAME` 和 `${NAME}` 同样有效。未设置的名称保持原样。
- 在 Windows 上比较名称时不区分大小写。

**哪些配置文件对 shell 生效**
- `default` – 对所有 shell 生效,最先应用。
- `auto`(默认开启)– 配置文件自动生效。设为 `"auto": false` 时,只对指定它的 shell 生效(见下)。
- `shells` – 该配置文件面向的 shell 配置:`pwsh`、`wsl`、`wsl:Ubuntu`,或副本的标识,如 `pwsh#2`。单写 `wsl` 也包括 `wsl:Ubuntu`,基础标识包括它的副本。为空或缺省 – 所有 shell。
- `off` – 设为 `true` 则完全关闭该配置文件,即使有 shell 指定了它。

<!--choice-->**为单个 shell 选择配置文件。** 在 shell 列表(**Ctrl+Shift+N**)中,**F6** 为所选 shell 或其副本打开环境配置文件的选择。这样的 shell 以 `default` 和所选配置文件启动;`(无)` 恢复为自动配置文件。列表中只有未关闭且不叫 `default` 的配置文件。

该文件包含在 **导出设置 / 导入设置** 中。

- **单词**把光标处的单词放入输入框, **选区**放入所选内容(没有选区时放入当前行; 多行选区则放入第一行)。开启**正则表达式**时,这两个按钮放入的文本会被转义。
- 找到的匹配项会被选中, **F3** / **Shift+F3** 从它继续。匹配不会跨越换行。
- 使用**正则表达式**时,模式是 PCRE 表达式,替换文本中 `$0` 表示整个匹配, `$1` ... `$9` 表示分组, `$$` 表示美元符号; 不使用该选项时,替换文本按原样使用。无法编译的模式会被报告,并且不进行搜索。

<!--replace-->**替换**
- 替换对话框中的**替换**逐个处理匹配项: 每一项都会被选中显示,并显示文本、其替换结果和所在的行,可回答**替换**(替换并转到下一个)、**全部**(不再询问,替换其余全部)、**跳过**或**取消**。
- 到达文本末尾而搜索是从中间开始的时,会提议从开头继续(反向搜索时从末尾继续)。
- 替换对话框中的**全部**一次性替换整个文本中的所有匹配。
- 两种方式都会在**全部**结束时显示替换了多少处,都可以用一次 **Ctrl+Z** 撤销,并把光标放回替换前的位置。

**记忆内容。**区分大小写、全字匹配和正则表达式会在多次运行之间被记住; **反向搜索**只在 MTN2 关闭前有效。

## 顶部菜单 (F9)

按 **F9** 或 **Alt** 打开菜单。
- 方向键移动, **Enter** 执行, **Esc** 关闭。
- 菜单项中突出显示(强调色)的字母可直接执行该项 – 与键盘布局无关: 子菜单打开时在其项目中查找该字母,否则在各个类别中查找。
- 项目的按键显示在项目右侧。当前模式下不可用的项目为灰色。
- 菜单超出窗口时会滚动: 右边框显示带 ▲ ▼ 的滚动条, 选中的项目始终可见, 鼠标滚轮移动选择。

按 **Shift+F9**(或 ≡ 菜单中的“查找命令...”)打开命令面板,用于搜索菜单项。

**搜索**
- 输入文字会缩小列表: 匹配菜单项名称、类别中的词以及常用同义词(例如输入 “shell” 可找到“后台控制台...”)。
- 查询文字显示在列表上方的输入框中; 查询词可包含 `?`(单个字符)和 `*`(任意多个字符)。
- 搜索也涵盖快捷键列: “F9”会找到快捷键中含 F9 的命令,“shift”会找到所有含 Shift 的快捷键,“ctrl+f”会找到含 Ctrl+F 的快捷键。
- 自定义搜索词写入设置文件夹中的 `aliases.json`: `{ "tmaCmdConsoleProfile": "bash, zsh" }` – 菜单项名称和以逗号分隔(或列表形式)的词。每次打开面板时都会重新读取该文件。

**按键**
- 方向键选择, **Enter** 执行, **Backspace** 删除, **Esc** 关闭。
- **Ctrl+K** 在所选命令处打开按键列表,以便更改它的按键; 关闭列表后面板会重新打开, 保留原来的搜索和命令, 并显示新按键(没有自己按键的命令会提示)。 对插件命令则打开单个按键的输入框(留空则命令没有按键; 输入插件自带的按键或点击**重置**即可恢复); 选择保存在设置文件夹的 `plugin-keys.json` 中。
- 面板自己的按键可在按键设置中更改(命令 `CommandPalette`)。

**列表内容。**列表中只有当前可用的项目, 最近执行过的排在前面。没有菜单项的命令(Ctrl+Enter、Alt+Shift+Enter 及其他面板按键)连同其快捷键列在“按键”类别中。

**按键提示。**程序进入新的状态时,只显示一次包含常用按键的简短通知。

**何时显示**
- 搜索之后、在压缩包中、在临时面板中、在工作区中、在 SFTP 或插件文件夹中、在回收站中。
- 选中文件时、在快速查看和信息面板中、有第二个面板标签或工作区时、有后台任务时。
- 在控制台和终端中、在查看器、十六进制视图、Markdown 和编辑器中、菜单打开时、输入命令时,以及用 Enter 启动控制台程序之后。
- 另有针对不常用按键的提示: 选中多个文件时、光标位于压缩包上时、在很长的文件夹中、多次切换文件夹之后、两个面板中有同名文件夹时,以及在编辑器中选中行时。

**工作方式。**按键取自当前的键位设置。已显示的提示会在重启后保留。在**选项 → 界面**中,复选框“显示按键提示”可关闭提示,按钮“重置提示”让它们重新显示; 关闭弹出通知时也不会显示提示。

## 用户菜单 (F2)

你自己的命令列表: 带热键的项目、嵌套的子菜单和分隔线。命令在面板控制台中、在活动面板的文件夹里运行; 用 **Ctrl+O** 查看其输出。

**两个菜单:**

- **主菜单** – 所有文件夹共用。
- **文件夹菜单** – 文件夹中的 `.mtn2menu.json` 文件。它适用于该文件夹及其所有下级文件夹; 如果多个层级都有这样的文件,则使用最近的一个。适合项目使用: 仓库根目录中的菜单在它的任何子文件夹中都可用。

**F2** 在有文件夹菜单时打开文件夹菜单,否则打开主菜单。在打开的菜单中按 **Shift+F2** 在文件夹菜单 ↔ 主菜单之间切换。为文件夹创建菜单: 按 F2,再按 Shift+F2(会打开该文件夹的空菜单),然后按 **Ins**。

**菜单中的按键:**

| 按键 | 作用 |
| --- | --- |
| Enter,项目热键,点击 | 运行命令或进入子菜单 |
| → | 进入子菜单 |
| ← / Esc | 上一级; 在顶层按 Esc 关闭菜单 |
| Ins | 在光标前添加项目 |
| F4 | 编辑项目 |
| Del | 删除项目(子菜单连同其内容一起删除) |
| Ctrl+↑ / Ctrl+↓ | 移动项目 |
| Shift+F2 | 文件夹菜单 ↔ 主菜单 |

<!--item-->**菜单项:** 热键(一个字符)、类型(命令 / 子菜单 / 分隔线)、标题和命令。如果标题为空,则显示命令本身。

<!--substitutions-->**命令中的替换:**

| 模式 | 替换为 |
| --- | --- |
| `!.!` | 光标处文件的名称(含扩展名) |
| `!` | 不含扩展名的文件名 |
| `!\` | 面板文件夹,末尾带 `\` |
| `!:` | 文件夹所在的驱动器(`C:`) |
| `!&` | 以空格分隔的所选名称(或光标处的名称); 含空格的名称会加引号 |
| `!@!` | 临时文件的路径,文件中列出所选项目的完整路径(每行一个,UTF-8) |
| `!?问题?答案!` | 用户的回答: 运行前会出现带问题和建议答案的窗口; 取消则取消命令 |
| `!#` | 后面的替换取自**非活动**面板 |
| `!^` | 后面的替换重新取自**活动**面板 |
| `!!` | 字符 `!` 本身 |

含空格的名称按原样替换 – 请自己加引号: `"!\!.!"`。

**示例:**

```
notepad.exe "!\!.!"                    用记事本打开文件
explorer.exe /select,"!\!.!"           在资源管理器中显示文件
certutil -hashfile "!.!" SHA256        校验和
fc "!.!" "!#!\!.!"                     与另一个面板中的同名文件比较
7z a "!?压缩包名称?backup!.7z" @!@!    打包所选内容,并询问压缩包名称
git commit -am "!?提交说明?!"          提交,并询问提交说明
```

命令在为控制台选定的 Shell(cmd、PowerShell、WSL)中运行 – 请按其语法编写命令。一行中的多条命令可以用 `&&` 连接(cmd、PowerShell 7)。

在主菜单被保存过一次之前,它显示的是示例。菜单文件也可以手工编辑 – 更改会在菜单下次打开时生效。

项目对话框中的**运行后**说明命令结束后程序去向何处: **与控制台选项一致**(**选项 → 控制台...**中的**命令结束后总是返回面板**复选框)、**返回面板**或**留在控制台**。

## 压缩包

- 在压缩包上按 **Enter** 把它作为文件夹打开; 在压缩包根目录按 **Ctrl+\\** 或进入 `..` 即可退出。
- **Ctrl+PgDn** 不管扩展名如何,都把文件作为压缩包打开: `.docx`、`.xlsx`、`.odt`(内部是 ZIP),或扩展名不常见的压缩包。格式由文件内容判断; 对不是压缩包的文件不会有任何反应。
- 在压缩包内按 **F5** 解压所选内容,把文件按 **F5** 复制到已打开的压缩包中则是添加。
- **Shift+F1** – 打包所选内容, **Shift+F2** – 解压。
<!--pack-->- 打包对话框以当前文件夹名作为默认压缩包名,并可选择类型:`zip` 或 `7z`。`7z` 压缩包可设置压缩级别、密码并加密文件名(`zip` 时这些字段不可用);可向已加密的 `7z` 压缩包添加文件或从中删除文件。
<!--password-->- 7z 等其他格式通过 7-Zip 插件处理(`7z.dll` 随程序提供; 你可以在 `plugins\mtn.7z\` 中换成自己的副本)。

**结束。**在后台运行过一段时间的任务结束时会弹出提示; 如果任务因错误停止,即使关闭了通知也会显示提示,点击该任务的标签块会打开错误信息。

### 字体和行距

**选项 → 字体 / 显示...**中的**行距(与终端相同)**复选框会让行高增加字号的 15%; 文字在行内保持居中,边框和高亮会拉伸到整个行高。默认关闭: 行高与字体的行高相同,屏幕上能容纳更多行。对于 Cascadia Mono 11 pt,不加行距是 17 像素,加行距是 19 像素 – 与 Windows Terminal 相同。

字号使用印刷点数,与 Windows Terminal 和 Windows 控制台相同: 6 到 24 pt,在 8 到 12 pt 之间以半点为步长。在 Windows 缩放 100% 时 1 pt = 4/3 像素: 10.5 pt 是 14 像素(以前的默认值), 11 pt 是 14.7 像素。

同一对话框中还有两个让文字更清晰的选项:
- **字号对齐设备像素**把字母大小取整为整数个物理屏幕像素。在 Windows 缩放 125% 或 150% 且使用小数字号(11 pt)时,笔画粗细会因此一致。单元格大小可能会略有变化。默认关闭。
- **文字对比度**(关、低、中、高)会补足淡淡的抗锯齿边缘: 深色背景上细而浅的文字读起来更扎实。默认关闭。
- **单元格宽度**和**单元格高度**为每个单元格增加 0 到 4 个物理像素。它们对字母相互挨着或行距太紧的字体有帮助。字母在单元格内保持居中,边框会完全填满。默认为 0。
- **备用字体**为主字体缺少的字符(如中日韩表意文字和符号)指定第二个字体族。输入字体族名称;留空或该字体族未安装时,由 Windows 自行选择。备用字体不改变单元格大小,单元格大小由主字体决定。

#### 为什么文字看起来和 Far 不同

Far 并不自己绘制文字: 绘制文字的是它所在的控制台窗口 – Windows Terminal 或经典的 Windows 控制台 – 使用其自己的字体和规则。在字体、大小和颜色相同的情况下, MTN2 和 Far 绘制的字母是一样的: 笔画粗细和抗锯齿一致。差异来自设置:
- **字体和大小。** Windows Terminal 默认使用 Cascadia Mono 11 pt。MTN2 使用"字体 / 显示"中的字体和大小(已安装则用 Cascadia Mono,否则用 Consolas; 10.5 pt)。 Ubuntu Mono 之类窄而细的字体看起来更细更淡,在蓝色背景上尤其如此。
- **行高。** Windows Terminal 在字体行高之外增加约 15% 的字号。在 MTN2 中这对应"行距"复选框; 不勾选时行更紧。经典 Windows 控制台根据字体的 Windows 度量取行高,可能再高 1–3 像素(Cascadia Mono 11 pt – 20 像素)。
- **颜色。** MTN2 的颜色来自其主题; Far 的来自自己的高亮和终端的配色方案。在默认主题中,普通文件是浅灰色; 在 Far 中通常是青色,在蓝色背景上对比度是两倍,所以文字看起来更粗。
- **抗锯齿。** MTN2 使用灰度抗锯齿。Windows Terminal 在配置的 `antialiasingMode` 为 `grayscale`(默认)时也是如此; 使用 `cleartype` 时字母会有彩色边缘。经典 Windows 控制台在 Windows 中开启 ClearType 时使用它。
- **Windows 缩放。**两者都以物理屏幕像素绘制文字,因此在 125% 和 150% 下同样清晰。

#### 何时一致

在以下情况下, MTN2 与 Windows Terminal 中的 Far 在单元格大小、笔画粗细和行高上一致:
- 字体相同(Windows Terminal 默认是 Cascadia Mono);
- 大小相同(Windows Terminal 默认是 11 pt);
- 开启了行距(与终端相同);
- Windows Terminal 配置使用 `grayscale` 抗锯齿;
- MTN2 的主题与 Far 的颜色相近。

对于经典 Windows 控制台(不使用 Windows Terminal 的 Far),两者不会完全一致: 它的行高和 ClearType 是它自己的。

### 通知

不会改变屏幕内容的命令会在右下角用简短通知自我确认; 它几秒后消失,不会占用按键。以下情况会出现通知:
- **Alt+Shift+Ins** / **Ctrl+Shift+Ins** – 已复制的路径 / 名称(或"没有可复制的内容");
- 在面板上按 **Ctrl+C** / **Ctrl+X**(**Ctrl+Ins** / **Ctrl+Del**) – 已放入剪贴板的文件;
- 在查看器 / 编辑器(没有选区时为当前行)、命令行和终端中复制文本;
- **Ctrl+R** – 面板已刷新;
- **Ctrl+Shift+O** – 控制台所转到的文件夹;
- **Ctrl+Alt+R** – 从回收站还原的项目;
- **Ctrl+Alt+D** – 添加到常用文件夹的文件夹;
- 按掩码选择(**小键盘 +/−**、**Ctrl+小键盘 +/−**、**Alt+小键盘 +/−**)没有改变任何内容时 – 以红色显示。

通知可在**选项 → 界面...**("显示弹出通知")中关闭。检查更新的通知是个例外: 它有自己的复选框(见[更新](#更新))。

## 更新

MTN2 可以自行更新: 它在 GitHub 上查找新版本,下载并安装,但只有在用户同意后才会进行。

### 更新流程

启动几秒后,每天一次,MTN2 会到 GitHub 检查新版本。如果有,它会询问: **更新**、**以后**或**跳过此版本**(被跳过的版本不会再次提示)。没有回答就不会下载或安装任何内容。

下载完成后(安装包会按 SHA-256 校验),MTN2 会提议现在**重启**或在**退出时**安装。复制任务运行期间,安装会等到退出。只会替换程序文件(包括随安装包提供的 `7z.dll`) – 设置和其他用户文件保持不变。

### 检查设置

**≡ → 检查更新...**(F9,然后选顶部菜单最左边的项目)显示已安装的版本,可立即检查(**立即检查**),并有两个复选框:

- **启动时检查更新** – 启动时每天一次。关闭后,MTN2 不会自行联网。
- **检查时显示通知** – 每次联网检查(启动时或点击**立即检查**)都会在右下角显示几秒钟的通知"正在 github.com 检查 MTN2 更新..."。

细节:
- 启动时的检查还会有第二行,说明如何关闭检查。
- 即使其他弹出通知已关闭也会显示,GitHub 一回应它就会消失。
- 对话框打开期间它被隐藏在对话框下面。

### 通过网络发送的内容

检查只是向 `api.github.com` 发出一次 HTTPS 请求,获取 `Laex/MTN2` 仓库的最新版本。请求中只有 `User-Agent` 头里的 MTN2 版本 – 没有文件名、路径或设置。更新本身是点击**更新**后从 GitHub 下载的发布包。

## 快捷键

内置按键集可以通过设置文件夹中的 `keymap.json` 文件(或通过**选项 → 快捷键...**)部分重新定义: 只列出更改过的操作,其余保持内置。**Ctrl+Alt+K** – 无需重启即可重新加载该文件。

除面板外,查看器和编辑器的命令也可以重新绑定。它们在 `keymap.json` 中的名称以如下前缀开头:
- `Doc` – 查看和编辑都适用: `DocHex`、`DocFind`、`DocEncoding`、`DocClose` 等;
- `Viewer` – 仅查看: `ViewerWrap`;
- `Markdown` – 渲染后的 Markdown: `MarkdownSource`;
- `Editor` – 仅编辑: `EditorSave`、`EditorUndo`、`EditorDeleteLine` 等。

同一个组合键在面板和文档中可以有不同含义 – Ctrl+H 在面板上显示隐藏文件,在文档中切换十六进制。范围较窄的含义会覆盖较宽的含义: 在渲染后的 Markdown 上 F4 切换源码,而不是十六进制。

全局命令在任何窗口都有效 – 面板、文档、终端:
- `Help` (F1)、`TopMenu` (F9)、`CommandPalette` (Shift+F9);
- `NextTab` / `PrevTab` (Ctrl+Alt+PgDn / Ctrl+Alt+PgUp);
- `AppConsoleToggle` (Ctrl+O)、`NewTerminal` (Ctrl+Shift+N)、`SelectConsoleProfile` (Ctrl+Alt+O);
- `AppQuit` (Alt+X)、`ZoomReset` (Ctrl+0)、`ReloadKeymap` (Ctrl+Alt+K);
- `ToggleMouse` (Ctrl+Shift+M,仅文本终端版本)。

**窗口自己绑定的组合键。**它仍归窗口所有:
- F10 在文档中关闭文档,只有在面板上才退出(`Quit`);
- 面板获得焦点时,面板上的 Esc 显示控制台(`ConsoleToggle`); 在命令行中它先清除命令行,再把焦点交还面板。

**全屏程序。**当控制台或终端中运行全屏程序时(配置的按键模式为*自动*或*终端*,见"终端"),控制台也会收到这些按键,但用于离开控制台的按键除外: F11、Ctrl+O、切换标签页、Ctrl+Shift+N 和 Ctrl+Alt+O。

**对话框。**对话框打开期间全局命令不会触发; `ZoomReset` 和 `ReloadKeymap` 始终触发。

在控制台 (Ctrl+O) 和终端中,名称以 `Shell…` 开头的命令可以重新绑定:
- `ShellHistory` (Alt+F8)、`ShellSelectAll` (Ctrl+A);
- `ShellCopyOrInterrupt` (Ctrl+C – 复制所选内容,没有选择时中断命令)、`ShellCopy` (Ctrl+Ins)、`ShellPaste` (Ctrl+V, Shift+Ins);
- `ShellFind` (Ctrl+Shift+F – 搜索输出)、`ShellFindNext` / `ShellFindPrev` (F3 / Shift+F3);
- 在控制台中还有 `ConsoleSyncDir` (Ctrl+Shift+O – 面板转到控制台的文件夹)。

其他按键都交给 Shell。

**设置 → 快捷键**按窗口对操作分组 – 全局、文件面板、查看器和编辑器、控制台和终端 – 并使用易读的名称; 编辑窗口中会显示 `keymap.json` 中的名称。底部的功能键标签、`A:All` 之类的提示以及顶部菜单中的快捷键都来自键位配置: 重新绑定后它们会显示新的按键。

一个操作可以有多个快捷键: 在编辑窗口中用 `;` 分隔列出,或者在 `keymap.json` 中写成单独的条目。除字母、数字和特殊键外,还可以分配 `/`、`,`、`.`、`'`、`=` 这些符号; 分号和主键盘区的减号写作 `Semicolon` 和 `Minus`(`-`、`+` 和 `*` 表示小键盘上的按键)。

修饰键必须完全匹配: Ctrl+Shift+A 不是 Ctrl+A。方向键、Home/End、输入以及查看器中的 `/` 不可配置。

### 标签页按键

所有标签页按键都是普通的键位操作,可以在 `keymap.json` 中重新绑定。面板标签页和工作区(顶行的标签页)是不同的东西,各有自己的操作:

| 内容 | `keymap.json` 中的操作 | 默认 |
| --- | --- | --- |
| 新建面板标签页 | `NewTab` | Ctrl+T |
| 下一个 / 上一个面板标签页 | `NextPanelTab` / `PrevPanelTab` | Ctrl+Tab / Ctrl+Shift+Tab |
| 关闭面板标签页 | `CloseTab` | Ctrl+W |
| 新建工作区 | `NewWorkspace` | Ctrl+Shift+W |
| 下一个 / 上一个工作区 | `NextTab` / `PrevTab` | Ctrl+Alt+PgDn / Ctrl+Alt+PgUp |

标签行中的 `[+]` 和 `[x]` 按钮以及顶部菜单项作用相同。

### 你自己的 `keymap.json` 和更新

设置文件夹中的 `keymap.json` 叠加在内置键位之上: 它列出的操作优先于内置的操作。
- **设置 → 快捷键**对话框只把更改过的操作写入文件,所以更新后其他按键会跟随内置键位。
- 早期版本保存的文件列出了所有操作,会冻结旧按键: 要获得新按键,请从中删除你需要的那些操作的行,或删除整个文件(如果其中有你自己的更改,请先备份)。
- 没有按键的操作写成空列表。

### Far 和 MC 习惯的示例

仓库里有两个示例 `keymap.json`：[`keymap.far.json` 和 `keymap.mc.json`](https://github.com/Laex/MTN2/tree/main/docs/keymap-presets)。把需要的那个以 `keymap.json` 为名复制到设置文件夹（或把其中的操作加到你自己的文件里），然后按 **Ctrl+Alt+K**。
- **Far：**面板中的 Esc 清空命令行，不再打开控制台（仍可用 Ctrl+O）。
- **MC：**Alt+. 显示隐藏文件，Ctrl+\ 打开文件夹列表，Alt+Enter 把文件名插入命令行，Alt+A 和 Alt+Shift+A 插入活动面板和另一面板的文件夹路径，属性改为 Ctrl+Shift+P。

### 保留按键

尚未占用,留给计划中的功能: **Shift+F3**(压缩包命令)、**F11**(插件菜单)、**Ctrl+Alt+Ins**(网络 UNC 路径)、**Ctrl+.**(宏录制)。自动检查会防止内置键位占用它们。

## 设置文件

设置文件夹是 `%APPDATA%\MTN2\`。如果 `MTN2.exe` 旁边有 `portable.dat` 文件,设置就保存在程序旁边(便携模式)。

| 文件 | 内容 |
| --- | --- |
| `session.json` | 窗口、面板和标签页的状态,主题,字体,语言 |
| `keymap.json` | 重新定义的按键 |
| `environment.json` | shell 的环境配置文件 |
| `aliases.json` | 命令面板的自定义搜索词 |
| `history.json` | 命令历史 |
| `folderhistory.json` | 文件夹历史 |
| `filehistory.json` | 文件历史 (Alt+F11) |
| `externaltools.json` | 外部查看器和编辑器 (Alt+F3 / Alt+F4) |
| `themes\*.theme.json` | 你自己的主题(设置 → 主题...) |
| `dialoghistory.json` | 对话框输入框历史 |
| `workspaces.json` | 已保存的工作区 |
| `sshconnections.json` | SSH/SFTP 连接 |
| `associations.json` | 文件关联 |
| `usermenu.json` | 主用户菜单 (F2) |
| `.mtn2menu.json`(位于任意文件夹) | 该文件夹及其下级文件夹的菜单 |
