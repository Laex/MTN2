# MTN2 – справка пользователя

[English](HELP.md) | **Русский** | [Deutsch](HELP.de.md) | [中文](HELP.zh.md)

Modern Terminal Navigator 2 – двухпанельный файловый менеджер в духе NDN / FAR Manager со встроенной консолью, терминалами, просмотрщиком и редактором.

Клавиши указаны для встроенного профиля; их можно переопределить (см. [Настройка клавиш](#настройка-клавиш)).

### Как пользоваться справкой

| Клавиша | Действие |
| --- | --- |
| Tab / Shift+Tab | следующая / предыдущая ссылка |
| Enter, щелчок по ссылке | перейти по ссылке |
| Backspace, Alt+← | вернуться назад |
| F1 | эта страница (содержание) |
| F7, Shift+F7 / Alt+F7 | поиск текста, следующее / предыдущее совпадение |
| ↑ ↓ PgUp PgDn Home End | прокрутка |
| Esc, F10 | закрыть справку |

## Настройка клавиш

Встроенный набор клавиш можно частично переопределить файлом `keymap.json` в папке настроек (или через **Настройки → Раскладка клавиш...**): указываются только изменённые действия, остальные остаются встроенными. **Ctrl+Alt+K** – перечитать файл без перезапуска.

Кроме панелей, настраиваются команды просмотрщика и редактора. Их имена в `keymap.json` начинаются с:
- `Doc` – общие для просмотра и правки: `DocHex`, `DocFind`, `DocEncoding`, `DocClose`…;
- `Viewer` – только просмотр: `ViewerWrap`;
- `Markdown` – просмотр Markdown: `MarkdownSource`;
- `Editor` – только правка: `EditorSave`, `EditorUndo`, `EditorDeleteLine`…

Одно и то же сочетание может означать разное в панелях и в документе – например, Ctrl+H показывает скрытые файлы в панели и переключает Hex в документе. Более узкое значение перекрывает общее: F4 в просмотре Markdown переключает исходный текст, а не Hex.

Глобальные команды работают в любом окне – в панелях, документе и терминале:
- `Help` (F1), `TopMenu` (F9), `CommandPalette` (Shift+F9);
- `NextTab` / `PrevTab` (Ctrl+Alt+PgDn / Ctrl+Alt+PgUp);
- `AppConsoleToggle` (Ctrl+O), `NewTerminal` (Ctrl+Shift+N), `SelectConsoleProfile` (Ctrl+Alt+O);
- `AppQuit` (Alt+X), `ZoomReset` (Ctrl+0), `ReloadKeymap` (Ctrl+Alt+K);
- `ToggleMouse` (Ctrl+Shift+M, только текстовая версия).

**Сочетание, занятое окном.** Оно остаётся за окном:
- F10 закрывает документ, а выходом из программы служит только в панелях (`Quit`);
- Esc в панелях показывает консоль (`ConsoleToggle`), когда фокус на панели; в командной строке он сначала очищает её, потом возвращает фокус панели.

**Полноэкранная программа.** Пока в консоли или терминале она работает (режим клавиш профиля «авто» или «терминал», см. раздел «Терминалы»), консоль получает и эти клавиши, кроме выхода из консоли: F11, Ctrl+O, переключения вкладок, Ctrl+Shift+N и Ctrl+Alt+O.

**Диалоги.** Пока открыт диалог, глобальные команды не срабатывают; `ZoomReset` и `ReloadKeymap` срабатывают всегда.

В консоли (Ctrl+O) и терминале настраиваются команды с именами на `Shell`:
- `ShellHistory` (Alt+F8), `ShellSelectAll` (Ctrl+A);
- `ShellCopyOrInterrupt` (Ctrl+C – копировать выделение, без выделения прервать команду), `ShellCopy` (Ctrl+Ins), `ShellPaste` (Ctrl+V, Shift+Ins);
- `ShellFind` (Ctrl+Shift+F – поиск по выводу), `ShellFindNext` / `ShellFindPrev` (F3 / Shift+F3);
- в консоли ещё `ConsoleSyncDir` (Ctrl+Shift+O – панель переходит в папку консоли).

Остальные клавиши уходят в оболочку.

В диалоге **Настройки → Раскладка клавиш** действия сгруппированы по окнам – глобальные, файловые панели, просмотр и редактор, консоль и терминал – и названы по-человечески; имя из `keymap.json` видно в окне изменения. Подписи F-клавиш внизу экрана, подсказки вида `A:All` и сочетания в верхнем меню берутся из раскладки: после переназначения они показывают новую клавишу.

На одно действие можно назначить несколько сочетаний: в окне изменения они перечисляются через `;`, в `keymap.json` – отдельными записями. Кроме букв, цифр и служебных клавиш, назначаются знаки `/`, `,`, `.`, `'`, `=`; точку с запятой и минус основного блока пишут словами `Semicolon` и `Minus` (`-`, `+` и `*` означают клавиши цифрового блока).

Модификаторы должны совпадать точно: Ctrl+Shift+A – не то же, что Ctrl+A. Стрелки, Home/End, набор текста и `/` в просмотрщике не настраиваются.

### Клавиши вкладок

Все клавиши вкладок – обычные действия раскладки и переназначаются в `keymap.json`. Вкладки панели и рабочие пространства (вкладки верхней строки) – разные вещи, у каждых свои действия:

| Что | Действие в `keymap.json` | По умолчанию |
| --- | --- | --- |
| Новая вкладка панели | `NewTab` | Ctrl+T |
| Следующая / предыдущая вкладка панели | `NextPanelTab` / `PrevPanelTab` | Ctrl+Tab / Ctrl+Shift+Tab |
| Закрыть вкладку панели | `CloseTab` | Ctrl+W |
| Новое рабочее пространство | `NewWorkspace` | Ctrl+Shift+W |
| Следующее / предыдущее рабочее пространство | `NextTab` / `PrevTab` | Ctrl+Alt+PgDn / Ctrl+Alt+PgUp |

Те же действия делают кнопки `[+]` и `[x]` в строках вкладок и пункты верхнего меню.

### Свой `keymap.json` и обновление

Файл `keymap.json` в папке настроек накладывается на встроенную раскладку: действия, которые в нём есть, побеждают встроенные.
- Диалог **Настройки → Раскладка клавиш** записывает в файл только изменённые действия, поэтому остальные сочетания после обновления программы подхватываются сами.
- Файл, сохранённый прежними версиями, содержит все действия и «замораживает» старые сочетания: чтобы получить новые, удалите из него строки нужных действий или весь файл (заранее сохраните копию, если в файле есть свои изменения).
- Действие без клавиш записывается пустым списком.

### Примеры для привычек Far и MC

В репозитории лежат три примера `keymap.json` – [`keymap.far.json`, `keymap.mc.json` и `keymap.tc.json`](https://github.com/Laex/MTN2/tree/main/docs/keymap-presets). Скопируйте нужный в папку настроек под именем `keymap.json` (или добавьте его действия в свой файл) и нажмите **Ctrl+Alt+K**.
- **Far:** Esc в панелях очищает командную строку и не открывает консоль (она по-прежнему на Ctrl+O).
- **MC:** Alt+. показывает скрытые файлы, Ctrl+\ открывает список папок, Alt+Enter вставляет имя файла в командную строку, Alt+A и Alt+Shift+A вставляют путь папки активной и второй панели, свойства переехали на Ctrl+Shift+P.
- **Total Commander:** Alt+F5 и Alt+F9 – упаковать и распаковать, Ctrl+A – выделить всё, Ctrl+M – переименование по правилам, Ctrl+P – вставить путь папки, Ctrl+Tab и Ctrl+Shift+Tab – переключение вкладок, Alt+Down – история папок. Раскладка по умолчанию уже следует привычкам Norton Commander.

### Зарезервированные сочетания

Пока не заняты и оставлены под будущие возможности: **Shift+F3** (команды архива), **F11** (меню плагинов), **Ctrl+Alt+Ins** (сетевые UNC-пути), **Ctrl+.** (запись макроса). Автоматическая проверка следит, чтобы встроенная раскладка их не занимала.

## Экран программы

Сверху вниз:
- **Верхнее меню** – категории Слева / Файлы / Правка / Команды / Настройки / Справа и часы. Открывается **F9**, **Alt** или щелчком.
- **Вкладки рабочих пространств** – наборы панелей и терминалов (см. [Вкладки и рабочие пространства](#вкладки-и-рабочие-пространства)).
- **Две файловые панели** – активная выделена рамкой; **Tab** переключает сторону. На нижней кромке панели – буквы дисков.
- **Командная строка** – приглашение с текущей папкой.
- **Строка F-клавиш** – подсказки действий для текущего режима; по ним можно щёлкать мышью. С зажатыми Shift / Ctrl / Alt строка показывает соответствующие действия. В окне шириной от 100 колонок слева от F-клавиш на панелях показана клавиша палитры команд.
- **Строка статуса** – сведения о панели; щелчок по секции открывает связанный диалог: сторона и свободное место – список дисков, путь – историю папок, режим колонок – меню режимов, элемент или выделение – свойства. В просмотре и редакторе: позиция – «Перейти к строке», кодировка – выбор кодировки, результат поиска – «Найти».

Под панелями живёт **консоль**: **Ctrl+O** (или **Esc**, когда фокус на панели) прячет панели и показывает вывод команд.

В заголовке окна стоит **[Администратор]**, если сам MTN2 запущен от имени администратора, и **[Помощник администратора]**, пока работает помощник администратора (см. [Операции с файлами](#операции-с-файлами)).

**Кнопки в диалогах** нажимаются, как настоящие: нажатая кнопка сдвигается вправо и закрывает свою тень.
- **Мышь.** Команда выполняется, когда кнопку мыши отпускают над той же кнопкой; если увести указатель в сторону и отпустить там, ничего не произойдёт.
- **Enter и пробел.** Держат кнопку нажатой, пока клавишу не отпустят, и команда выполняется при отпускании; **Esc**, нажатый в это время, поднимает кнопку без выполнения команды, и диалог остаётся открытым.
- **Выделенная буква и Y / N.** Вдавливают кнопку на мгновение, и она сразу срабатывает.
- В остальных случаях **Esc** закрывает диалог сразу.

**Горячие буквы в диалогах.** У кнопок, флажков и переключателей одна буква надписи выделена цветом (в некоторых темах – подчёркиванием).
- Нажатие этой буквы нажимает кнопку, переключает флажок или выбирает переключатель; если фокус в поле ввода, букву нажимают с Alt.
- Буква срабатывает и в другой раскладке: «Пропустить» с выделенной П нажимается и русской П, и латинской G на той же клавише.
- Кнопке по умолчанию (в угловых скобках) и кнопке отмены буква не нужна – для них есть Enter и Esc.

**F1** – справка по тому, что сейчас на экране (панели, просмотр, открытый диалог или меню); **F1** в самой справке – оглавление. **F10** – выход.

## Панели и навигация

| Клавиша | Действие |
| --- | --- |
| ↑ ↓ PgUp PgDn Home End | перемещение курсора |
| ← / → | в режиме «Кратко» – на колонку влево / вправо, в остальных режимах – в начало / конец списка (как Home / End) |
| Enter | войти в папку / архив, открыть файл (по [ассоциации](#ассоциации-файлов)); консольную программу – запустить во встроенной консоли (см. ниже) |
| Backspace | на уровень выше, как Enter на `..` (при пустой командной строке; иначе стирает символ в ней) |
| Ctrl+PgUp / Ctrl+PgDn | на уровень выше / войти в папку под курсором, как в Far; на файле Ctrl+PgDn открывает его как архив (см. [Архивы](#архивы)) |
| Shift+Enter | запустить файл или команду в отдельном окне ОС |
| Alt+Shift+Enter | запустить командную строку в фоне: консоль на короткое время показывает запуск, затем возвращаются панели; при пустой строке запускает консольную программу под курсором так же |
| Ctrl+Alt+Enter | запустить командную строку в новой вкладке терминала (оболочка фоновой консоли); при пустой строке запускает консольную программу под курсором в терминале вкладки панелей |
| Alt+Shift+F3 | показать элемент под курсором на соседней панели |
| Tab | переключить активную панель |
| Ctrl+\\ | в корень диска (из архива – выйти из архива) |
| Alt+← / Alt+→ | назад / вперёд по истории папок |
| Ctrl+U | поменять панели местами |
| Ctrl+] | пассивная панель := папка активной |
| Ctrl+[ | активная панель := папка пассивной |
| Ctrl+Alt+P | парные папки вкл. / выкл.: вход в подпапку (Enter, Ctrl+PgDn) или выход вверх (`..`, Ctrl+PgUp) в одной панели повторяется в другой, если там есть папка с таким именем (или родитель); обе панели должны показывать обычные локальные папки; настройка принадлежит вкладке и сохраняется между запусками |
| Ctrl+Alt+G | группировка строк: по типу, по дате, без неё (каждое нажатие – следующий режим) |
| Ctrl+F1 / Ctrl+F2 | скрыть / показать левую / правую панель |
| Ctrl+P | скрыть / показать неактивную панель |
| Ctrl+L | информационная панель (диск, память) на соседней стороне |
| Ctrl+H | показать / скрыть скрытые и системные файлы |
| Ctrl+R | обновить панель |
| Ctrl+Q | быстрый просмотр файла на соседней панели: картинка, текст, Markdown или hex |
| Alt+F10 | дерево папок диска поверх активной панели (см. ниже) |
| Alt+буква | быстрый поиск по имени в панели |

**Парные папки (Ctrl+Alt+P)** – пример: слева `D:\Work1`, справа `D:\Work2`, в обеих есть `src\Core`. При включённом режиме Enter на `src` в левой панели открывает `D:\Work1\src` и `D:\Work2\src` сразу, Enter на `Core` уходит на уровень глубже в обеих; `..` в одной панели поднимает обе. Если в другой панели папки с таким именем нет (например, в `v2` нет `docs`), она остаётся на месте. Удобно сравнивать две копии дерева папка за папкой.

**Группировка (Ctrl+Alt+G)** – строки сначала упорядочиваются по группам, а текущая сортировка действует внутри каждой группы; первая строка группы показывает её заголовок справа от имени, у остальных групп фон чуть подкрашен. По типу: папки, изображения, звук, видео, документы, архивы, программы, код и данные, прочее. По дате: сегодня, вчера, за 7 дней, за 30 дней, за год, старше, без даты. Пример: в папке загрузок дважды нажать Ctrl+Alt+G и отсортировать по размеру – файлы каждого дня идут вместе, самые крупные первыми. Режим хранится для каждой панели и сохраняется в сессии.

**Дерево папок (Alt+F10)** открывается поверх активной панели. Бывает открыто только над одной панелью.

**Открытие.** Показан корень диска, путь к текущей папке раскрыт, курсор на ней.

**Клавиатура**
- ↑ ↓ PgUp PgDn Home End – перемещение.
- → или `+` – раскрыть ветку (`[+]─`) или войти в неё.
- ← или `-` – свернуть ветку (`[-]─`) или подняться к родителю.
- Буква – к следующей папке на эту букву.
- Enter – открыть папку в активной панели и закрыть дерево.
- Esc или Alt+F10 – закрыть дерево; под ним снова видна та же панель.

**Соседняя панель.** Она переходит в папку под курсором, когда курсор остановился.

**Фокус**
- Tab или щелчок по другой панели переводят в неё фокус; дерево остаётся на месте, как панель дерева в Far.
- Tab или щелчок по рамке дерева возвращают фокус ему.

**Мышь.** Дерево работает как оглавление:
- щелчок по папке сразу показывает её в другой панели и переводит фокус туда;
- щелчок по `[+]` / `[-]` раскрывает или сворачивает ветку, не меняя фокуса;
- колесо прокручивает дерево, не двигая курсор.

**Слежение и фоновое чтение**
- Если в другой панели перешли в другую папку, дерево раскрывает путь к ней и ставит на неё курсор; для другого диска перестраивается.
- Папки читаются в фоне; если за это время панель под деревом перешла в другую папку, дерево закрывается.

**Быстрый просмотр (Ctrl+Q)** показывает на соседней панели файл под курсором: картинку, текст (кодировка определяется сама), оформленный Markdown или hex-дамп двоичного файла.
- Большие файлы читаются потоково.
- Колесо мыши над просмотром прокручивает его.
- Файлы на SFTP и крупные файлы внутри архивов не читаются при каждом движении курсора – для них показывается подсказка открыть файл по F3.
- Tab или повторное Ctrl+Q закрывает быстрый просмотр.

**Консольные программы** (`.exe` консольной подсистемы, `.bat`, `.cmd`, `.ps1`) по Enter запускаются не в отдельном окне Windows, а так, чтобы их вывод остался на экране:
- в фоновой консоли (Ctrl+O), если её оболочка – cmd, PowerShell или pwsh и в ней ничего не выполняется: как команда, набранная в командной строке;
- иначе (консоль WSL, Git Bash, SSH или занята другой командой) – в новой вкладке терминала с cmd, а для `.ps1` – с PowerShell; после завершения программы вкладка остаётся открытой.

С флажком **Программы из панелей – во вкладке-терминале** (**Команды → Фоновая консоль...**) любая консольная программа запускается во вкладке терминала, поэтому остальные вкладки остаются доступными, пока она работает.
- Первая программа, запущенная из вкладки панелей, открывает рядом вкладку терминала.
- Следующие набираются в оболочке этой вкладки (в папке файла), пока она свободна и в строке ввода ничего не набрано, иначе открывается новая вкладка.
- У оболочки вкладки свой профиль окружения (**F6** в списке оболочек) и своя история оболочки.

Оконные программы и документы открываются, как раньше, программой Windows. **Shift+Enter** по-прежнему запускает любой файл в отдельном окне.

Щелчок мышью ставит курсор, двойной щелчок – как Enter. Файлы можно перетаскивать мышью между панелями и в другие программы (и обратно).

## Выделение файлов

| Клавиша | Действие |
| --- | --- |
| Ins | выделить / снять и перейти ниже |
| Shift+стрелки, Shift+Home/End/PgUp/PgDn | выделять по ходу курсора |
| Shift+Серый + | выделить все файлы |
| Ctrl+M | вернуть выделение, которое было до последнего сброса (например, после копирования); повторное нажатие возвращает обратно |
| Серый + / Серый − | выделить / снять по маске (`*.txt`, `a*.*`) |
| Серый * | инвертировать выделение |
| Ctrl+Серый + / Ctrl+Серый − | выделить / снять файлы с тем же расширением, что под курсором |
| Shift+Серый − | снять выделение со всех файлов |
| Alt+Серый + / Alt+Серый − | выделить / снять файлы с тем же именем |

В диалоге выбора по маске флажок «Выделять папки» распространяет маску и на папки. Операции (копирование, удаление, …) работают с выделенными элементами, а если ничего не выделено – с элементом под курсором.

### Группы масок

<!--mask-groups-->В любой маске (выделение, фильтр панели, поиск, цветовые группы) запись `@Имя` подставляет именованный набор масок, например `@Images` или `*.log;@Documents`. Встроены группы Images, Audio, Video, Documents, Archives и Sources. Свои группы и замена встроенных – в файле `maskgroups.json` в папке настроек: `{ "groups": { "Logs": "*.log;*.out" } }`. Неизвестное имя остаётся обычным текстом маски. Пункт меню «Параметры» – «Группы масок...» открывает список, где группы добавляют, меняют и удаляют; диалог выбора по маске тоже умеет сохранить свою маску как группу. В поле маски диалога (выделение, фильтр, поиск) Ctrl+G сохраняет введённые маски как группу с именем по первой маске и ставит в поле `@Имя`.

### Наборы колонок

В меню режимов колонок после готовых режимов перечислены именованные наборы колонок. Выбранный набор задаёт колонки той панели, на которой он выбран; другая панель сохраняет свои, и каждая панель помнит свои колонки. Наборы лежат в файле `columnsets.json` в папке настроек; если файла нет, он создаётся с наборами Minimal, Dates и Technical, после чего это обычные наборы: их можно менять, переименовывать и удалять. Чтобы сохранить текущий выбор, в диалоге «Свои колонки» (Опции, Колонки) введите имя в поле «Сохранить как набор колонок»; диалог правит колонки активной панели. В том же диалоге виден список наборов: «Правка» загружает выбранный набор в флажки и поле имени (OK сохраняет изменения под этим именем), «Переименовать» даёт выбранному набору имя из поля, «Удалить» убирает его.

## Операции с файлами

| Клавиша | Действие |
| --- | --- |
| F3 | просмотр файла; на папках – подсчёт размера выделенных папок (Esc – отмена) |
| F4 | редактирование |
| Shift+F4 | создать файл |
| F5 | копировать |
| Shift+F5 | копия под другим именем в той же папке |
| F6 | переместить / переименовать |
| Shift+F6 | переименовать элемент под курсором |
| F7 | создать папку |
| Alt+F6 | создать ссылку (символьная ссылка, жёсткая ссылка, junction) |
| F8, Del | удалить в Корзину |
| Shift+F8, Shift+Del | удалить безвозвратно (затереть) |
| Ctrl+A | атрибуты, владелец и даты (создан / изменён / доступ) |
| Alt+Enter | окно «Свойства» Windows (для выделенных или элемента под курсором; только файлы и папки на диске) |
| Shift+F10, клавиша Menu | контекстное меню Windows (для выделенных или элемента под курсором) |
| Ctrl+Alt+C | сравнить файлы под курсорами обеих панелей или два отмеченных файла активной панели; в окне – размер, время изменения и вердикт по содержимому |
| Ctrl+Alt+H | контрольные суммы (MD5, SHA-1, SHA-256, SHA-512) выделенных файлов и папок; на файле `.md5` / `.sha1` / `.sha256` / `.sha512` – проверка по нему |
| Ctrl+Alt+M | групповое переименование выделенных элементов: маска имени и расширения, счётчик, замена текста, регистр букв |
| Ctrl+C / Ctrl+X / Ctrl+V | копировать / вырезать / вставить файлы через буфер обмена |
| Alt+Shift+Ins | скопировать полный путь в буфер обмена |
| Ctrl+Shift+Ins | скопировать только имя (без пути) в буфер обмена |
| Ctrl+Z | описание файла: строка ввода, текст сохраняется в `Descript.ion` рядом с файлом |

**Alt+Shift+Ins** и **Ctrl+Shift+Ins** берут выделенные элементы (по одному в строке), а без выделения – элемент под курсором; на `..` – текущую папку. Вставить результат можно где угодно по **Shift+Ins** / **Ctrl+V**. Копирование подтверждает короткое уведомление в правом нижнем углу (или сообщает, что копировать нечего); отключается в **Настройки → Интерфейс...**.

<!--export-list-->**Файлы → Сохранить список в файл...** записывает выделенные элементы (без выделения – элемент под курсором) в файл.

**В диалоге задаются**
- имя файла;
- формат – по расширению (`.md` – таблица Markdown, `.csv` – CSV, иначе выровненный текст), обычный текст, Markdown или CSV;
- поля: имя, полный путь, расширение, размер, даты изменения / создания / доступа, тип и атрибуты.

Строку заголовков можно отключить (у таблицы Markdown она есть всегда). Вместо размера у папок выводится `<DIR>`. Выбор запоминается между запусками; у пункта нет клавиши по умолчанию – её можно назначить в диалоге назначения клавиш (действие `ExportList`).

<!--attributes-->В диалоге **Ctrl+A** даты вводятся в формате даты системы, время – `чч:мм:сс` (секунды и время можно не указывать).
- Пустое поле – дата не меняется: так выглядят даты, которые у выделенных файлов различаются.
- **Текущее** ставит во все три поля текущее время, **Исходные** возвращает прочитанные значения.
- Флажок «Обрабатывать вложенные папки» действует и на даты.

В том же диалоге – остальные признаки файла: **Сжатый**, **Шифрованный**, **Не индексируется**, **Разреженный**, **Временный** и **Автономный** (для каждого: оставить / включить / выключить; сжатие, шифрование и разреженность выполняет файловая система, на томе без такой возможности будет ошибка).

**Корень диска.** Для корня диска (**F4** в списке дисков **Alt+F1** / **Alt+F2**) вверху показаны том (путь с GUID) и устройство; кнопка **Свойства Windows** открывает системное окно свойств.

**Контекстное меню Windows** – то же меню, что по правой кнопке мыши в Проводнике: «Открыть с помощью», «Отправить», пункты архиваторов, антивируса, систем контроля версий и т. п.

**Как открыть:** **Shift+F10** или клавиша **Menu** у строки курсора, меню **Файлы → Контекстное меню Windows** или удержание правой кнопки мыши на файле около секунды.

**На что действует**
- С клавиатуры и из меню – на выделенные элементы, а без выделения – на элемент под курсором (на `..` – на текущую папку).
- Удержание кнопки мыши открывает меню файла под мышью.

Доступно только для файлов и папок на диске: у архивов, SFTP, Корзины и результатов поиска меню Windows нет.

<!--copy-->Диалог копирования/перемещения позволяет: сохранить все временные метки, копировать только более новые файлы, копировать содержимое символьных ссылок, задать маску исключения. При конфликте имён программа спрашивает, что делать (заменить, пропустить, переименовать, для всех…).

<!--checksums-->**Контрольные суммы.** Расчёт идёт в фоне (Esc – отмена). В списке результата: **Копировать** – в буфер обмена, **Сохранить** – в `<файл>.sha256` (для одного файла) или `checksums.sha256` в папке панели. Проверка показывает для каждой строки `OK`, `FAILED` или `MISSING`. Понимаются строки `хеш *имя`, `хеш  имя` и `SHA256 (имя) = хеш`.

<!--multi-rename-->**Групповое переименование.** Маски имени и расширения понимают:
- `[N]` – старое имя без расширения;
- `[E]` – старое расширение;
- `[C]` – счётчик с заданными началом, шагом и числом цифр;
- `[Date]` и `[Time]` – дата (`2026-11-05`) и время (`14-30-07`) изменения; `[Year]`, `[Month]` и `[Day]` – части даты;
- `[Parent]` – имя папки; `[Size]` – размер в байтах;
- `[Dim]`, `[Camera]`, `[Artist]` и `[Title]` – значения колонок плагина метаданных (размер и камера снимка, исполнитель и название записи) в том виде, как их показывает панель; пока плагин не прочитал файл, они пусты;
- остальной текст остаётся как набран.

«Найти» и «Заменить» работают по новому имени и расширению, регистр букв выбирается из списка. При включённом «Регулярном выражении» «Найти» – шаблон, а «Заменить» может использовать `$1`, `$2`; неверный шаблон оставляет имена без изменений. Метки можно набирать в любом регистре; неизвестное значение пусто, а символы, недопустимые в имени, заменяются на `_`. Список под полями сразу показывает пары «старое -> новое».

**Ошибки.** Имя, которое пусто, недопустимо, встречается дважды или уже занято в папке (в том числе другим элементом набора), отмечается знаком `!`; пока такие есть, **Переименовать** не выполняется.

Выбрать можно только элементы одной папки. Переименование идёт заданием в фоне, как перемещение.

<!--admin-->**Защищённые папки.** Если копирование, перемещение, удаление, создание папки или переименование на локальном пути (например, в `C:\Program Files`) заканчивается ошибкой «Отказано в доступе», в окне ошибки появляется кнопка **Админ**, а создание папки и переименование спрашивают «Повторить с правами администратора?».

**Как это работает**
- После согласия Windows показывает обычный запрос UAC, и MTN2 запускает небольшой процесс-помощник с правами администратора.
- Упавший элемент и остаток задания выполняются в нём, в тех же окнах прогресса и ошибок.
- До подтверждения ничего с этими правами не выполняется.
- Пока помощник работает, в заголовке окна стоит **[Помощник администратора]** и показано уведомление; он завершается сам через две минуты без работы или при закрытии MTN2.

**Ограничения**
- Помощник только копирует, перемещает, удаляет, создаёт папки и сохраняет текст на локальных путях: запускать программы он не умеет, а говорить с ним может только запустивший его MTN2.
- Из архива кнопка **Админ** есть только при распаковке в локальную папку: архив читает сам MTN2, результат записывает помощник. Для остальных операций с архивами и виртуальными папками такого шага нет.

**MTN2 от имени администратора.** Если сам MTN2 запущен от имени администратора (правый щелчок, «Запуск от имени администратора»), в заголовке стоит **[Администратор]** и помощник не нужен; зато Windows блокирует перетаскивание из программ без повышенных прав, например из Проводника.

## Диски и особые места

**Alt+F1 / Alt+F2** – выбор диска для левой / правой панели. Под списком дисков – особые места (выбор цифрой, Enter или щелчком):
1. **Системные папки** – Рабочий стол, Документы, Загрузки и др.
2. **Корзина** – просмотр; **Ctrl+Alt+R** восстанавливает элемент, **F8** удаляет окончательно. Быстрый переход – **Ctrl+Alt+F8**.
3. **Временная панель** – если подключён плагин Temporary.
4. **Рабочий набор** – панель ссылок на файлы и папки (не копий): **F5** добавляет ссылку, **F8** убирает её, **F7** создаёт группу.

В списке после дисков идут сетевые ресурсы вида `\\сервер\ресурс`, в которых сейчас открыта одна из панелей или которые открывались недавно (до восьми). Enter открывает ресурс, ресурс активной панели отмечен звёздочкой.

**На диске**
- **F4** показывает атрибуты его корневой папки.
- **Del** на съёмном или оптическом диске или подключённом сетевом диске отключает его (извлекает носитель) после подтверждения; диск с открытыми файлами остаётся подключённым, программа сообщает причину.

**Ctrl+← / Ctrl+→** – предпросмотр соседнего диска на нижней кромке панели; переход – при отпускании Ctrl (Esc – отмена). Щелчок по букве диска – сразу переход. Для каждого диска запоминается последняя папка.

Команда **..** в системных папках и Корзине возвращает туда, откуда вы пришли.

## Вкладки и рабочие пространства

<!--panel-tabs-->**Вкладки панели** – у каждой стороны свои. Новую вкладку создаёт кнопка **[+]** после последней вкладки или двойной щелчок по пустому месту строки вкладок:

| Клавиша | Действие |
| --- | --- |
| Ctrl+T | новая вкладка |
| Ctrl+W | закрыть вкладку |
| Ctrl+Alt+T | закрепить или открепить вкладку (закреплённая выделена фоном акцентного цвета: переход в другую папку открывает новую вкладку, закрыть её нельзя) |
| Ctrl+Tab / Ctrl+Shift+Tab | следующая / предыдущая вкладка панели (в документе и терминале – рабочее пространство) |

<!--workspaces-->**Рабочие пространства** – вкладки верхней строки (**Ctrl+Shift+W** – новое, **Ctrl+Alt+PgDn** / **Ctrl+Alt+PgUp** – следующее и предыдущее). Каждое содержит свою пару панелей или терминал. Двойной щелчок по вкладке – переименовать; кнопка **[+]** сразу после последней вкладки создаёт новое.

<!--saved-->**Сохранённые рабочие пространства** – **Ctrl+Shift+D** (список, переход, удаление), **Ctrl+Alt+Shift+D** – сохранить текущее.

<!--findtows-->**Результаты поиска в рабочее пространство** – **Ctrl+Alt+F7** (меню **Команды**) добавляет в панель ссылок `ws:///` ссылки на отмеченные элементы активной панели, а если отметок нет – на все (например, результаты **Alt+F7**), и открывает её в соседней панели. Одинаковые имена получают номер, уже добавленные элементы не повторяются, элементы архивов и виртуальных схем пропускаются. Если рабочее пространство уже не пусто или есть сохранённые наборы, появится выбор: добавить в текущий набор, заменить его, создать новый набор или добавить в один из сохранённых; изменённый набор перед заменой сохраняется. Чтобы вернуться к набору позже, сохраните его **Ctrl+Alt+Shift+D**.

## Вид панели и сортировка

| Клавиша | Действие |
| --- | --- |
| Ctrl+\` | меню режимов колонок |
| Ctrl+Shift+F1 … F6 | режим: краткий, размер, дата, полный, создан, типы |

## Поиск и фильтры

| Клавиша | Действие |
| --- | --- |
| Alt+F7 | поиск файлов (маска, содержимое, подпапки, регистр, слова целиком, регулярные выражения, размер, дата изменения, атрибуты; календарь для дат – кнопка «…» или F9) |
| Ctrl+I | фильтр панели: диалог со списком готовых фильтров и строкой для своей маски; Enter или двойной щелчок по списку применяет фильтр, «Сбросить» снимает его |
| Ctrl+B | плоский вид: все файлы поддерева в одном списке |
| Alt+буква | быстрый поиск по имени |

### Быстрый поиск

Alt+буква открывает поле поиска в активной панели; следующие буквы дописываются в него, курсор встаёт на первый файл, имя которого начинается с набранного текста. Backspace стирает последний символ, Esc закрывает поле, Enter открывает файл под курсором. Стрелки Вверх и Вниз переходят к соседним файлам, любая другая клавиша или Ctrl-сочетание закрывает поиск и действует как обычно.

Параметры (Параметры – Интерфейс):

- **Не закрывать быстрый поиск после отпускания Alt** – поле остаётся открытым, пока не нажаты Esc или Enter;
- **Не закрывать пустой быстрый поиск** – пустое поле не закрывается после Backspace;
- **Фильтровать панель при быстром поиске** – кроме курсора, в панели остаются только подходящие файлы; поле при этом не закрывается после отпускания Alt, Esc или Enter возвращает все файлы, а курсор остаётся на том же файле;
- **Сохранять фильтр при переходе в другую папку** – Enter на папке или щелчок мышью переносят фильтр в новую папку, тогда его снимает только Esc;
- **Нечёткий фильтр** – подходят и имена, в которых набранные буквы встречаются по порядку, не обязательно подряд (`mnr` найдёт `main_readme.txt`); курсор встаёт на файл с совпадающим началом, а если такого нет, на первый в списке.

Результаты поиска открываются как панель – с ними работают обычные операции.

Esc во время поиска спрашивает «Остановить поиск?»: **Остановить** прекращает поиск, **Продолжить** (Esc) оставляет его работать.

- **Del** – убирает файл из истории.
- Набор текста фильтрует список по пути. Позиция в файле восстанавливается.

## Командная строка и консоль

Командная строка всегда под панелями: достаточно начать печатать. Команда выполняется во встроенной консоли, её вывод виден по **Ctrl+O**.

| Клавиша | Действие |
| --- | --- |
| Enter | выполнить команду; если введён путь к папке – перейти в неё, к файлу (в том числе имя, вставленное по Ctrl+Enter) – запустить его: консольную программу – во встроенной консоли, остальное – программой Windows. После этого фокус возвращается панели, и стрелки снова водят курсор |
| Ctrl+↓ / Ctrl+↑ | фокус в командную строку / обратно в панель |
| ↑ / ↓ (пока набирается команда) | история команд |
| Tab | дополнение: имя из панели, а если в слове есть `\`, `/` или `X:` – путь с диска (повторные нажатия перебирают варианты) |
| Ctrl+↓ / Alt+↓ (в строке с фокусом) | история команд списком: Enter – подставить, Del – удалить из истории, Esc – закрыть |
| Набор текста в строке | над строкой появляется список прежних команд, начинающихся с набранного текста; он не перехватывает клавиши: ↑ / ↓ выбирают запись, Enter подставляет её в строку (Enter без выбора выполняет строку), Del удаляет запись из истории, Esc закрывает список. Если включено **Не передавать фокус командной строке при наборе с клавиатуры** (Настройки → Интерфейс), набранное на панелях попадает в строку, не переводя в неё фокус (Пробел и Backspace – только если в строке уже есть текст): фокус переводят Ctrl+↓ или щелчок мышью |
| Ctrl+Enter | вставить имя элемента под курсором |
| Ctrl+F, Ctrl+Shift+Enter | вставить полный путь элемента |
| Alt+Shift+Enter | запустить командную строку в фоне: консоль на короткое время показывает запуск, затем возвращаются панели (**Параметры → Консоль...** ниже); при пустой строке запускает консольную программу под курсором так же |
| Ctrl+Alt+Enter | запустить командную строку в новой вкладке терминала: новая вкладка рабочего пространства с оболочкой фоновой консоли (cmd, PowerShell, WSL, ...), команда стартует там, вкладка остаётся открытой; при пустой строке запускает консольную программу под курсором в терминале вкладки панелей |
| Esc | по шагам: очистить строку → вернуть фокус панели → показать консоль. С пустой строкой первый шаг пропускается, при фокусе на панели сначала очищается оставшийся в строке текст, а при пустой строке Esc сразу показывает консоль |
| Ctrl+O | панели ↔ консоль |
| Ctrl+Shift+O | синхронизировать папку между активной панелью и консолью |
| Ctrl+Alt+O | выбрать оболочку фоновой консоли (cmd, PowerShell, WSL, …) |

<!--console-profile-->Тот же диалог – **Команды → Фоновая консоль...**.
- Флажок **Запускать оболочку при старте программы** по умолчанию выключен: оболочка стартует при первом **Ctrl+O** или первой команде из командной строки. Включённый флажок запускает оболочку вместе с программой.
- Флажок **Программы из панелей – во вкладке-терминале** отправляет консольные программы, запущенные по Enter в панели, во вкладки терминала, а не в эту консоль.

**В консоли:** **Ctrl+C** прерывает команду; **Esc** только прячет консоль, но не останавливает процесс. Колесо мыши прокручивает вывод. Текст выделяется мышью (см. [Работа с текстом и мышью](#работа-с-текстом-и-мышью)).

**Поиск по выводу** (консоль и терминал):
- **Ctrl+Shift+F** – ввести текст; совпадения подсвечены во всей истории, текущее выделено, как выделение мышью. Пустая строка в диалоге снимает поиск.
- **F3** / **Shift+F3** – следующее / предыдущее совпадение (по кругу), пока поиск задан и в окне не работает полноэкранная программа.
- В консоли с оболочкой cmd клавиши **↑** / **↓** листают общую историю команд (как Alt+F8), а **↓** после самой новой команды возвращает набранную строку.

**Вставка в консоль** (**Ctrl+V**, **Shift+Ins**): каждый перевод строки уходит оболочке как Enter, поэтому вставленные строки выполняются одна за другой, последняя тоже. Если включено **Подтверждать вставку нескольких строк**, программа сначала спрашивает.

**Параметры → Консоль...** задаёт:
- размер истории консоли и терминалов (1000 – 50 000 строк, по умолчанию 10 000);
- подтверждение вставки нескольких строк (выключено; в полноэкранных программах вроде vim подтверждения нет);
- удаление пробелов в концах строк при копировании и вставке;
- флажок **Всегда возвращаться в панели по завершении команды** (выключен). Если он включён, команда из командной строки под панелями возвращает в панели, как только оболочка снова показала приглашение; команда, набранная в фоновой консоли (Ctrl+O), всегда остаётся в консоли.

**Фоновый запуск.** **Alt+Shift+Enter** запускает командную строку в консоли в фоне: консоль показывается столько, сколько задано в поле **Фоновый запуск** (0,5 – 10 с, по умолчанию 2 с), и панели возвращаются сами. Клавиша, нажатая в консоли раньше, оставляет консоль на экране; команда продолжает выполняться в любом случае.

Изменения действуют сразу, в том числе на открытые консоли.

<!--save-output-->**Команды → Сохранить вывод консоли...** записывает историю фоновой консоли (Ctrl+O) в текстовый файл UTF-8, **Очистить буфер консоли** стирает её; оболочка продолжает работать.

## Терминалы

**Ctrl+Shift+N** – новый терминал в отдельной вкладке рабочего пространства: выбор профиля оболочки (cmd, PowerShell, WSL, сохранённые SSH-подключения). Полноэкранные программы (vim, mc, htop, …) работают в терминале так же, как в обычной консоли.

<!--profiles-->В списке профилей:

- **1–9, 0, A–Z** – запустить профиль с этим номером (номер выделен цветом в начале строки).
- **Ins** – сделать копию выбранного профиля: оболочка та же, настройки свои. **Del** удаляет копию (сам профиль удалить нельзя).
- **Ctrl+Вверх / Ctrl+Вниз** – переставить профиль; порядок запоминается (файл `shellprofiles.json` в папке настроек).
- **F4** – режим клавиш профиля. Режим действует и на фоновую консоль (Ctrl+O), если выбран её профиль.

Режимы:
- *авто* – клавиши получает программа, пока в консоли работает полноэкранное приложение, например mc или vim;
- *терминал* – программа в терминале получает все клавиши, в том числе F1, F9 и Alt+буква;
- *хост* – клавиши окна MTN2 всегда первые.

При режимах «авто» и «терминал» окну остаются только клавиши выхода: F11, Ctrl+O, переключение вкладок, Ctrl+Shift+N и Ctrl+Alt+O.
- **F6** – профиль окружения выбранной оболочки или её копии (см. [Профили окружения](#профили-окружения)).

## Профили окружения

**Настройки → Профили окружения...** открывает файл `environment.json` в редакторе (при первом обращении он создаётся с примером).

Профиль – именованный список записей `ИМЯ=значение`, которые накладываются на окружение каждой новой оболочки: вкладок-терминалов и консоли под панелями. Уже запущенные оболочки сохраняют своё окружение; оболочка, запущенная после сохранения файла, видит изменения.

```json
{
  "profiles": [
    { "name": "default", "vars": ["EDITOR=vim", "WORK=%TEMP%\\work", "OLD_VARIABLE="] },
    { "name": "proxy", "auto": false, "shells": ["pwsh"], "vars": ["HTTPS_PROXY=http://proxy:3128"] }
  ]
}
```

**Записи.**
- Профили применяются в порядке файла, записи – в порядке списка, поэтому следующая запись видит результат предыдущей.
- Запись с пустым значением (`OLD_VARIABLE=`) убирает переменную.
- `%ИМЯ%` заменяется текущим значением переменной во всех системах; в Linux и macOS работают также `$ИМЯ` и `${ИМЯ}`. Имя несуществующей переменной остаётся как написано.
- В Windows имена сравниваются без учёта регистра.

**Какие профили действуют на оболочку**
- `default` – действует на все оболочки, первым.
- `auto` (по умолчанию включено) – профиль применяется сам. При `"auto": false` – только к оболочке, которая его назначила (см. ниже).
- `shells` – профили оболочек, для которых предназначен профиль: `pwsh`, `wsl`, `wsl:Ubuntu`, идентификатор копии вроде `pwsh#2`. Короткое `wsl` охватывает и `wsl:Ubuntu`, а базовый идентификатор – его копии. Пусто или нет поля – все оболочки.
- `off` – `true` выключает профиль совсем, даже там, где он назначен.

<!--choice-->**Профиль для одной оболочки.** В списке оболочек (**Ctrl+Shift+N**) **F6** открывает выбор профиля окружения для выбранной оболочки или её копии. Такая оболочка запускается с `default` и выбранным профилем; `(нет)` возвращает автоматические профили. В списке только профили, которые не выключены и не называются `default`.

Файл входит в **экспорт и импорт настроек**.

## Просмотр и редактирование файлов

**F3** – просмотр, **F4** – редактирование, **F6** – переключение просмотр ↔ редактор без закрытия файла.

**Alt+F3** / **Alt+F4** – открыть файл под курсором внешним просмотрщиком / редактором. Команды задаются в **Настройки → Внешний просмотрщик/редактор...**; без них Alt+F3 открывает файл программой Windows, Alt+F4 – командой Windows «Изменить», а если её нет – Блокнотом. Только для файлов на диске.

| Клавиша | Действие |

| F7, Ctrl+F (в просмотре также `/`) | диалог поиска (см. ниже) |
| Shift+F7 / Alt+F7, F3 / Shift+F3 | следующее / предыдущее совпадение (при включённом **Обратном поиске** меняются местами) |
| Ctrl+F7 | поиск и замена (редактор): те же параметры и кнопки, плюс **Заменить** и **Все** |

| F8 | следующая кодировка; Shift+F8 – выбрать кодировку |
| F4 (в просмотре), Ctrl+H | HEX-режим (в HEX-режиме редактора байты можно править) |
| Ctrl+M | Markdown: оформленный вид ↔ исходный текст |
| Tab / Shift+Tab | Markdown: следующая / предыдущая ссылка |
| Enter, щелчок по ссылке | Markdown: открыть локальную ссылку (`other.md`, `other.md#раздел`, `#раздел`) в этом же окне; внешняя ссылка (`https://…`, `mailto:…`) открывается программой по умолчанию – после подтверждения |
| Backspace / Alt+← | Markdown: вернуться после перехода по локальной ссылке |
| F2 | сохранить (редактор) / перенос строк (просмотр; запоминается для файла вместе с позицией) |
| Ctrl+Shift+F | просмотр: следить за концом растущего файла (лог); выход – ещё раз та же клавиша, прокрутка вверх, Up, PgUp, Home, смена режима |
| Ctrl+S | сохранить |
| Ctrl+Z / Ctrl+Shift+Z | отменить / повторить |
| Ctrl+Y, Ctrl+D | удалить строку |
| Ctrl+K | удалить до конца строки |
| Ctrl+N | вставить пустую строку ниже |
| Ctrl+Alt+S / Ctrl+Alt+Shift+S | сортировать строки выделения (без выделения – всего файла) по возрастанию / по убыванию |
| Ctrl+Alt+U | удалить повторяющиеся строки |
| Ctrl+Alt+F | отформатировать текст по заданной ширине (абзацы разделяются пустыми строками) |
| Alt+→ / Alt+← | сдвинуть выделенные строки (без выделения – текущую) вправо / влево |
| Alt+Shift+стрелки (и Home / End / PgUp / PgDn), Alt+мышь | выделить прямоугольный блок – одни и те же столбцы нескольких строк; Del, Backspace, ввод текста и Ctrl+X / Ctrl+C / Ctrl+V действуют на каждую строку блока, скопированный блок вставляется блоком |
| Enter (в редакторе) | новая строка начинается с отступа строки, которую она продолжает (пробелы и табуляции слева от курсора); режим включается и выключается по **Ctrl+Alt+I**, в меню «Правка» и в настройках («Интерфейс») |

<!--bookmarks-->**Закладки.** **Ctrl+F2** ставит и снимает закладку на строке курсора, **Ctrl+Shift+F2** / **Ctrl+Alt+F2** переходят к следующей / предыдущей, **Ctrl+Alt+B** открывает список: Enter переходит на выбранную строку, Esc закрывает.

**Поле и совпадения**
- Кнопка **Слово** подставляет в поле слово под курсором, **Выделение** – выделенный текст (если выделения нет – текущую строку; у многострочного выделения – первую строку). При включённых **Регулярных выражениях** текст этих двух кнопок экранируется.
- Найденное совпадение выделяется, **F3** / **Shift+F3** продолжают поиск от него. Совпадение не пересекает границу строки.
- С **Регулярными выражениями** шаблон – выражение PCRE, а в замене `$0` – всё совпадение, `$1` ... `$9` – группы, `$$` – знак доллара; без этого параметра замена берётся как есть. Шаблон, который нельзя скомпилировать, сообщается ошибкой, поиск не выполняется.

<!--replace-->**Замена**
- **Заменить** в диалоге замены идёт по совпадениям по одному: каждое показано выделенным, с текстом, его заменой и строкой, в которой оно находится, и отвечается кнопками **Заменить** (заменить и перейти к следующему), **Все** (заменить остальные без вопросов), **Пропустить** или **Отмена**.
- Если дошли до конца текста, а поиск начался с середины, программа предлагает продолжить с начала (с конца при обратном поиске).
- **Все** в диалоге замены заменяет все совпадения во всём тексте сразу.
- Оба способа в режиме «Все» показывают в конце число замен, отменяются одним **Ctrl+Z** и возвращают курсор туда, где он был до замены.

**Что запоминается.** Регистр, слова целиком и регулярные выражения запоминаются между запусками; **Обратный поиск** – только до закрытия MTN2.

## Работа с текстом и мышью

Одинаково в просмотре и редакторе, в командной строке, в полях диалогов и в консолях.

**Словом** считаются буквы любого алфавита, цифры и `_`. Всё остальное – пробелы, знаки препинания, `\`, `/`, `.`, `:` – **разделители**.

| Действие | Результат |
| --- | --- |
| Ctrl+← / Ctrl+→ | к началу слова / к концу слова (до следующего разделителя) |
| Ctrl+Shift+← / Ctrl+Shift+→ | то же с выделением; шаг назад снимает выделение с пройденной части |
| Shift+стрелки, Shift+Home/End | выделение |
| Щелчок | поставить курсор |
| Двойной щелчок | выделить слово (на разделителе – серию одинаковых символов) |
| Следующий быстрый щелчок | выделить всю строку |
| Shift+щелчок | расширить или сузить выделение до места щелчка |
| Протягивание мышью | выделение (просмотр, редактор, консоль) |
| Alt+протягивание мышью | прямоугольный блок (просмотр, редактор) |
| Ctrl+C / Ctrl+Ins, Ctrl+X / Shift+Del, Ctrl+V / Shift+Ins | буфер обмена |
| Ctrl+A | выделить всё |

В панелях при непустой командной строке Ctrl+Shift+←/→ работают в командной строке.

<!--mouse-->**Текстовая версия (mtn2-tui).** Программа забирает у терминала мышь, поэтому протягивание выделяет текст внутри MTN2, а в буфер он попадает через терминал (управляющая последовательность, которую часть терминалов, например PuTTY по умолчанию, игнорирует; внутри tmux и на рабочем столе MTN2 заполняет ещё буфер tmux и системный буфер обмена).

Чтобы выделять средствами самого терминала:
- держите **Shift** при протягивании;
- или выключите мышь клавишей **Ctrl+Shift+M** (**Настройки → Мышь терминала: вкл/выкл**); та же клавиша включает её обратно.

Параметр `--no-mouse` запускает программу с выключенной мышью.

**История полей ввода.** У полей со стрелкой **↓** в правом конце программа помнит последние 20 значений. Это маски выделения, поиск файлов (маска и текст), путь и исключения при копировании/переносе, цель ссылки, создание папки и файла, поиск и замена в редакторе, запросы меню пользователя.

**Работа со списком.** **Ctrl+↓** / **Alt+↓** или щелчок по стрелке раскрывают список:
- **Enter** – подставить;
- **Del** – удалить из истории;
- **Esc** – закрыть список.

Значение попадает в историю при подтверждении диалога.

## Верхнее меню (F9)

**F9** или **Alt** открывает меню.
- Стрелки – перемещение, **Enter** – выполнить, **Esc** – закрыть.
- Подсвеченная (акцентная) буква пункта выполняет его сразу – в любой раскладке клавиатуры: при открытом подменю буква ищется среди его пунктов, иначе – среди категорий.
- Справа от пунктов показаны их клавиши. Недоступные в текущем режиме пункты – серые.
- Если меню не помещается в окно, оно прокручивается: на правой границе видна полоса со стрелками ▲ ▼, выбранный пункт всегда в поле зрения, колесо мыши двигает выбор.

**Shift+F9** (или пункт «Найти команду...» в меню ≡) открывает палитру команд – поиск по пунктам меню.

**Поиск**
- Набор текста сужает список: ищутся слова из названия пункта, названия категории и привычных синонимов («shell» или «оболочка» найдут «Фоновая консоль...»; «фк» найдёт её по первым буквам слов).
- Запрос виден в поле над списком; в слове запроса допустимы `?` (один символ) и `*` (любая цепочка символов).
- Поиск идёт и по колонке сочетаний: «F9» найдёт команды, у которых в сочетании есть F9, «shift» – все сочетания с Shift, «ctrl+f» – сочетания, содержащие Ctrl+F.
- Свои слова для поиска добавляются в файл `aliases.json` в папке настроек: `{ "tmaCmdConsoleProfile": "bash, zsh" }` – имя пункта и слова через запятую или списком. Файл перечитывается при каждом открытии палитры.

**Клавиши**
- Стрелки – выбор, **Enter** – выполнить, **Backspace** – стереть, **Esc** – закрыть.
- **Ctrl+K** – открыть список клавиш на выбранной команде, чтобы изменить её клавишу; после закрытия списка палитра открывается снова с тем же запросом и той же командой, а новая клавиша уже видна (у команды без собственной клавиши появится сообщение об этом). У команды плагина вместо списка открывается поле для одной клавиши (пустое поле оставляет команду без клавиши; клавишу плагина возвращает её ввод или кнопка **Сбросить**); выбор хранится в `plugin-keys.json` в папке настроек.
- Клавишу самой палитры можно сменить в раскладке (команда `CommandPalette`).

**Что в списке.** Только пункты, доступные сейчас; выполненные недавно идут первыми. Команды без пункта меню (Ctrl+Enter, Alt+Shift+Enter и другие клавиши панелей) показаны в категории «Клавиши» вместе со своими сочетаниями.

**Подсказки о клавишах.** Когда программа попадает в новое состояние, она один раз за всё время показывает короткое уведомление с полезными клавишами.

**Когда показываются**
- После поиска, в архиве, во временной панели, в рабочем пространстве, в папке SFTP или плагина, в Корзине.
- При выделении файлов, в быстром просмотре и информационной панели, при второй вкладке панели или рабочем пространстве, при фоновых заданиях.
- В консоли и терминале, в просмотре, hex-режиме, Markdown и редакторе, при открытом меню, при наборе команды и после запуска консольной программы по Enter.
- Отдельные подсказки о редких сочетаниях: при нескольких выделенных файлах, на архиве под курсором, в длинной папке, после долгих переходов по папкам, при одноимённых папках на панелях и при выделенных строках в редакторе.

**Как работают.** Клавиши берутся из текущей раскладки. Показанные подсказки запоминаются между запусками. В **Параметры → Интерфейс** подсказки отключаются флажком «Показывать подсказки о клавишах», а кнопка «Сбросить подсказки» делает их снова новыми; при выключенных всплывающих уведомлениях подсказок тоже нет.

## Меню пользователя (F2)

Собственный список команд: пункты с горячими клавишами, вложенные подменю и разделители. Команда выполняется в консоли панели, в папке активной панели; её вывод виден по **Ctrl+O**.

**Два меню:**

- **Главное** – общее для всех папок.
- **Меню папки** – файл `.mtn2menu.json` в папке. Действует на эту папку и на все вложенные; если такие файлы есть на нескольких уровнях, берётся ближайший. Удобно для проектов: меню в корне репозитория доступно в любой его подпапке.

**F2** открывает меню папки, если оно есть, иначе главное. **Shift+F2** в открытом меню переключает меню папки ↔ главное. Чтобы создать меню для папки: F2, затем Shift+F2 (откроется пустое меню этой папки) и **Ins**.

**Клавиши в меню:**

| Клавиша | Действие |
| --- | --- |
| Enter, горячая клавиша пункта, щелчок | выполнить команду или войти в подменю |
| → | войти в подменю |
| ← / Esc | на уровень выше; Esc на верхнем уровне закрывает меню |
| Ins | добавить пункт перед курсором |
| F4 | изменить пункт |
| Del | удалить пункт (подменю – вместе с содержимым) |
| Ctrl+↑ / Ctrl+↓ | переставить пункт |
| Shift+F2 | меню папки ↔ главное |

<!--item-->**Пункт меню:** горячая клавиша (один символ), тип (команда / подменю / разделитель), название и команда. Если название не задано, показывается сама команда.

<!--substitutions-->**Подстановки в команде:**

| Запись | Заменяется на |
| --- | --- |
| `!.!` | имя файла под курсором с расширением |
| `!` | имя файла без расширения |
| `!\` | папку панели с завершающим `\` |
| `!:` | диск папки (`C:`) |
| `!&` | выделенные имена через пробел (или имя под курсором); имена с пробелами – в кавычках |
| `!@!` | путь к временному файлу со списком полных путей выделенных элементов (по одному в строке, UTF-8) |
| `!?Вопрос?ответ!` | ответ пользователя: перед запуском появится окно с вопросом и предложенным ответом; отмена отменяет команду |
| `!#` | дальнейшие подстановки берутся с **пассивной** панели |
| `!^` | дальнейшие подстановки – снова с **активной** панели |
| `!!` | сам символ `!` |

Имена с пробелами подставляются как есть – берите их в кавычки сами: `"!\!.!"`.

**Примеры:**

```
notepad.exe "!\!.!"                    открыть файл в Блокноте
explorer.exe /select,"!\!.!"           показать файл в Проводнике
certutil -hashfile "!.!" SHA256        контрольная сумма
fc "!.!" "!#!\!.!"                     сравнить с одноимённым файлом на другой панели
7z a "!?Имя архива?backup!.7z" @!@!    упаковать выделенное, спросив имя архива
git commit -am "!?Сообщение коммита?!" коммит с вопросом о сообщении
```

Команда выполняется той оболочкой, которая выбрана для консоли (cmd, PowerShell, WSL), – пишите команды в её синтаксисе. Несколько команд в одной строке можно объединить через `&&` (cmd, PowerShell 7).

Пока главное меню ни разу не сохранено, в нём показываются примеры. Файлы меню можно править и вручную – изменения видны при следующем открытии меню.

**После запуска** в окне пункта задаёт, куда попадёт программа по завершении команды: **Как в настройках консоли** (флажок **Всегда возвращаться в панели** в **Параметры → Консоль...**), **Вернуться в панели** или **Остаться в консоли**.

## Архивы

- **Enter** на архиве открывает его как папку; **Ctrl+\\** или `..` в корне архива – выход.
- **Ctrl+PgDn** открывает файл как архив, какое бы у него ни было расширение: например, `.docx`, `.xlsx` или `.odt` (внутри это ZIP) либо архив с нестандартным расширением. Формат определяется по содержимому файла; если это не архив, ничего не происходит.
- **F5** из архива распаковывает выделенное, **F5** в открытый архив – добавляет.
- **Shift+F1** – упаковать выделенное, **Shift+F2** – распаковать.
<!--pack-->- Окно упаковки предлагает имя архива по имени текущей папки и позволяет выбрать тип: `zip` или `7z`. Для `7z` можно выбрать степень сжатия, задать пароль и зашифровать имена файлов (для `zip` эти поля недоступны); к зашифрованному архиву `7z` можно дописывать файлы и удалять их из него.
<!--password-->- Формат 7z и другие – через плагин 7-Zip (`7z.dll` входит в комплект; его можно заменить своим в `plugins\mtn.7z\`).
- Для зашифрованных архивов программа спросит пароль: при входе, если зашифрованы имена файлов, иначе – при первом просмотре или копировании зашифрованного файла. Неверный пароль спрашивается снова, верный запоминается до конца сеанса.

## Синхронизация и сравнение

<!--dir-sync-->- **Ctrl+Alt+S** – синхронизация папок активной и пассивной панели: односторонняя или двусторонняя; флажок пробного прогона показывает, что будет сделано, ничего не меняя.
- В окне синхронизации каждое отличие – строка списка с действием: `->` копирует вправо, `<-` влево, `--` пропускает; конфликты сначала пропущены. Кнопки **Вправо**, **Влево** и **Пропустить** задают действие выбранной строки (ручной выбор отмечен `*`), **Сбросить** возвращает автоматическое, а **Только пропущенные** оставляет строки, по которым ещё нет решения. Пропущенные отличия остаются открытыми до следующей синхронизации.
<!--compare-files-->- **Ctrl+Alt+C** – сравнить файлы под курсорами обеих панелей или два отмеченных файла активной панели; в окне – размер, время изменения и вердикт по содержимому. Если отмечено два файла или больше, сравниваются одноимённые файлы (отметки на обеих панелях – только отмеченные; на одной – одноимённые ищутся на другой панели) и в списке для каждой пары показано «одинаковые» или «различаются»; Enter на паре открывает различия. Папки пропускаются.
  Для текстовых файлов окно сравнения и слияния занимает весь экран: две колонки с номерами строк, различия отмечены посередине, а изменившаяся часть строки подсвечена (`~` изменено, `<` только слева, `>` только справа). **Ctrl+↓** и **Ctrl+↑** (или **Tab** и **Shift+Tab**) переходят между различиями, **Ctrl+←** и **Ctrl+→** сдвигают длинные строки, **→** копирует различие слева направо, **←** – справа налево, **Ctrl+Z** отменяет копирование, **Ctrl+S** записывает изменённые файлы с прежними кодировкой и переводами строк. **Esc** закрывает окно; при несохранённых изменениях нужно нажать его ещё раз, чтобы закрыть без сохранения. Двоичные, очень большие (больше 16 МБ или 60000 строк) и одинаковые файлы показываются прежним окном со сводкой.
<!--compare-folders-->- **Ctrl+Shift+C** – сравнить папки: на обеих панелях выделяются файлы, которых нет на другой стороне, и более новые из одноимённых; при одинаковом времени, но разном размере – оба.

Подробности сравнения:
- Папки выделяются, только если их нет на другой стороне.
- Сравниваются текущие списки панелей, без вложенных папок, поэтому работает и в архивах, и на SFTP.
- Диалог спрашивает, что считать отличием: время, размер, содержимое.
- Содержимое сравнивается байт в байт только у файлов одинакового размера на диске и считается в фоне (Esc прерывает).

## Фоновые задания

<!--job-list-->Копирование, перемещение и удаление выполняются в фоне. Окно прогресса можно отправить в фон; **Ctrl+Shift+J** – список заданий (прогресс, отмена).

<!--stop-->Прервать задание из окна прогресса можно кнопкой **Отмена**, клавишей **Esc** или щелчком вне окна; то же делают кнопки «Отмена» и «Отменить все» в списке заданий.

Сначала появляется вопрос «Прервать текущую операцию?»:
- **Прервать** останавливает задание;
- **Продолжить** (кнопка по умолчанию, она же Esc) возвращает прежнее окно.

После «Прервать» окно прогресса закрывается сразу, а задание заканчивает остановку само: пока оно не заметило отмену, оно остаётся в списке заданий, но без плашки.

Кнопки диалога нажимаются клавишами **Enter** и **Пробел**: кнопка выглядит нажатой, пока клавиша удерживается, и срабатывает при её отпускании. Esc до отпускания клавиши поднимает кнопку без действия.

<!--queue-->**Очередь, пауза и скорость.** Задания копирования и перемещения, затрагивающие один и тот же диск, выполняются по очереди; остальные ждут в очереди (`..`). В списке заданий (**Ctrl+Shift+J**) для выбранного задания:
- **Пауза** останавливает идущее копирование на следующем блоке (плашка `||`, состояние «пауза») или не даёт запуститься задаче из очереди; задание на паузе занимает диск, пока его не продолжат или не отменят;
- **Вверх** и **Вниз** меняют порядок запуска заданий из очереди;
- **Скорость** переключает ограничение скорости копирования: без ограничения, 1, 5, 20 и 100 МБ/с (показано в столбце состояния). Ограничение действует при копировании между локальными папками.

<!--errors-->Когда копирование, перемещение или удаление останавливается с ошибкой, окно ошибки предлагает **Повторить**, **Пропустить**, **Пропустить всё**, **Отмена** и, для «Отказано в доступе» на локальном пути, **Админ**: он повторяет этот элемент и остаток задания через помощника администратора (см. [Операции с файлами](#операции-с-файлами)).

Задания в фоне показаны справа в строке вкладок: по плашке на каждое, а в конце – кнопка со списком.

**Плашка**
- На плашке значок операции и ход выполнения: `»` копирование, `►` перемещение, `▼` в корзину, `‼` удаление, `■` упаковка, `□` распаковка.
- Вместо процента бывает `..` (ждёт очереди), `?` (ждёт ответа на вопрос) и `!` (ошибка).
- Щелчок по плашке возвращает именно это задание: его окно прогресса, вопрос или сообщение об ошибке.
- Кнопка `[≡N]` открывает список заданий.
- Пока фоновых заданий нет, справа ничего не показывается, и это не зависит от строки статуса.

**Завершение.** Когда задача, какое-то время работавшая в фоне, завершается, об этом сообщает уведомление; если она остановилась с ошибкой, уведомление показывается даже при выключенных уведомлениях, а щелчок по плашке задачи открывает ошибку.

## Настройки

Меню **Настройки** (F9):
<!--theme-->- **Тема...** – выбор оформления; меняется сразу.

**Настроить...** открывает редактор выбранной темы: разделы (цвета окон, диалогов, кнопок, курсора, панелей и других элементов, Markdown, стили текста, символы, рамки) со значениями.
- **Enter** на строке правит значение: цвет вводят как `#RRGGBB` или выбирают по **F9** / кнопкой **[...]**.
- **Унаследовать** возвращает значение базовой темы; строки со звёздочкой заданы самой темой.
- Цвет можно задать значением `#RRGGBB`, ссылкой на другую роль темы (`@cursor.bg`) или именем из палитры.
- Раздел **Основа** – темы, на которые опирается эта (несколько через `;`, поздние перекрывают ранние).
- Изменения видны сразу.

**Сохранение**
- **Сохранить** записывает тему в файл. Встроенные темы только для чтения: копия встроенной темы сохраняется под новым именем (файл в папке `themes` папки настроек), свою тему **Сохранить** обновляет на месте.
- **Сохранить как...** записывает тему под другим именем.
- **Создать...** делает новую тему с нуля («пустая») или на основе любой другой.
- **Удалить** убирает свою тему.

Если тема из сохранённой сессии не найдена, программа сообщает об этом и включает классическую тему Far.
<!--display-->- **Шрифт / экран...** – шрифт, кегль, масштаб, мигание и вид курсора, значки файлов в панели, **межстрочный интервал** (см. ниже), **тени** и вид **отмеченных файлов**; всё применяется без перезапуска.

**Тени и отмеченные файлы**
- **Тени** окон и кнопок: «Классические», «Мягкие» или «Нет»; вместе с ними ослабляется или пропадает затемнение фона под диалогом.
- **Отмеченные файлы:** «Цвет текста» – только цвет букв, как в Far; «Фон строки» – ещё и полоса фона по всей строке.
<!--interface-->- **Интерфейс...** – язык интерфейса, уведомления, видимость строк окна, перетаскивание, меню по Alt, автоотступ и ещё несколько флажков; всё применяется без перезапуска.

**Что задаётся**
- **Язык интерфейса** (English / Русский / Deutsch / 简体中文) и всплывающие уведомления.
- **Заголовок окна, строки меню, функциональных клавиш и статуса.** Скрытая строка отдаётся панелям.
- **Перетаскивание файлов мышью** (можно выключить), **меню по одиночному нажатию Alt** (можно выключить), курсор в неактивной панели, **вертикальные линии между колонками** (режимы «Полный» и «Свои колонки»; в кратком они есть всегда, по умолчанию выключены), **автоотступ в редакторе по Enter** (можно выключить) и **фильтрация панели при быстром поиске** (Alt+буква: кроме перемещения курсора скрываются файлы, имена которых начинаются не с набранного текста; поле поиска остаётся открытым после отпускания Alt, фильтр снимают Esc или Enter; параметр «Нечёткий фильтр» оставляет и имена, в которых набранные буквы встречаются по порядку, не обязательно подряд; параметр «Сохранять фильтр при переходе в другую папку» переносит фильтр в папку, открытую по Enter или щелчком, и тогда его снимает только Esc; по умолчанию выключено).

**Скрытые строки окна**
- При скрытой строке меню F9 показывает её поверх верхней строки, пока меню открыто.
- При скрытом заголовке окна кнопки **[_] [□] [x]** переезжают в правый край строки меню, а если скрыта и она, то строки вкладок.
- Название окна выводится в свободном месте строки вкладок; окно перетаскивается за свободные места строки меню и вкладок и меняет размер за края.
- Правый щелчок по свободному месту строки вкладок открывает верхнее меню, как F9.

**Флажки выделения и размеров**
- **«Выделять и папки»** включает папки в Shift+Серый + / Shift+Серый − и в выделение по расширению (по умолчанию – только файлы, как в Far).
- **«Точный размер в байтах»** показывает размеры в нижней рамке панели (итог папки или выделенного, размер элемента под курсором) и в строке статуса точным числом байт с разделителем групп разрядов, принятым в системе (`1 234 567`), а не как `1.2 M`; если число не помещается, остаётся короткая запись. Колонка «Размер» в списке файлов не меняется.

**Vim-клавиши на панели.** Флажок **«Vim-клавиши на панели»** (по умолчанию выключен) включает на панели, пока командная строка пуста:
- **j / k** – курсор вниз и вверх;
- **h** – в родительскую папку; **l** – открыть;
- **g / G** – первая и последняя строка;
- **/** – быстрый поиск; **:** – перейти в командную строку.
<!--columns-->- **Колонки...** – состав колонок режима «Свой».
<!--console-->- **Консоль...** – размер истории консоли и терминалов, подтверждение вставки нескольких строк, удаление пробелов в концах строк при копировании и вставке, возврат в панели по завершении команды из командной строки (подробнее – в справке о командной строке).
<!--save-settings-->- **Сохранить настройки** – записывает настройки, панели и вкладки в файл настроек сразу, а не только при закрытии программы; уведомление подтверждает запись или называет причину ошибки. Параметры, изменённые в диалогах, применяются сразу; этот пункт гарантирует, что они лежат на диске, например перед копированием папки настроек.
<!--settings-file-->- **Экспорт настроек... / Импорт настроек...** – настройки одним zip-файлом.

**Что входит.** Сессия и параметры отображения, клавиши, меню пользователя, ассоциации, избранные папки, список SSH-подключений, рабочие пространства, собственные темы; истории не входят.

**Как работает**
- Поле имени файла – поле ввода со списком ↓ ранее использованных файлов; по умолчанию это `mtn2-settings.zip` в папке активной панели.
- Перед импортом прежние файлы сохраняются в `settings-backup.zip` в папке настроек.
- Новые настройки вступают в силу после перезапуска MTN2.
<!--location-->- **Расположение настроек...** – выбор места хранения настроек: папка пользователя (основной режим) или рядом с программой (портативный режим, файл `portable.dat`).

**Что показывает диалог.** Оба места, сколько файлов переносится и что мешает: нет прав на запись в папку программы, папка программы общая для всех пользователей, файлы в месте назначения будут заменены (они остаются как `*.before-switch`).

**Перенос**
- Сессия, истории, клавиши, настройки плагинов и ваши темы переносятся вместе, старые копии удаляются.
- Изменение действует сразу, перезапуск не нужен. При любой ошибке остаётся прежнее место.
- Языки и поставляемые темы в `resource\` всегда остаются у программы.
<!--color-coding-->- **Цветовая разметка...** – цвета строк по маскам имён и, при желании, по размеру, возрасту и атрибутам (поле **Условие**: термы вида `size>10M`, `age<7d`, `+H`, `-R`; буквы H скрытый, R только чтение, S системный, A архивный, C сжатый, E зашифрованный, L ссылка; `age<7d` – изменён меньше 7 дней назад); они хранятся в теме, поэтому правка при встроенной теме сохраняется в новую тему (программа спрашивает имя). **F9** на поле цвета или щелчок по кнопке **[...]** у его правого края (на ней цвет поля) открывает выбор цвета (см. ниже).
  Примеры условий (группа применяется, только если подходят и маска, и условие):
  - `size>100M` – файлы крупнее 100 МБ, например с маской `*.log`, чтобы выделить большие журналы.
  - `size>0 size<4K` – небольшие непустые файлы.
  - `age<1d` – изменены за последние сутки; `age<90m` – за последние 90 минут.
  - `age>30d` – не менялись больше месяца (приглушить устаревшие файлы); `age>2w` – старше двух недель.
  - `+H` – только скрытые; `+HS` – скрытые и системные; `-R` – все, кроме файлов «только чтение».
  - `size>1G age>90d -R` – крупные, старые и доступные для записи: должны выполняться все три условия (кандидаты на очистку).
  - У папки нет размера, поэтому группа с условием по размеру папки не затрагивает; условия только по атрибутам или возрасту работают и для папок. Группы проверяются сверху вниз, побеждает первая подошедшая, поэтому узкую группу (`*.log` + `size>100M`) ставьте выше общей (`*.log`).
- **Раскладка клавиш...** – просмотр и изменение клавиш.
<!--plugins-->- **Плагины...** – установленные плагины. По умолчанию все плагины включены.

**Управление**
- **Пробел** на строке включает или выключает плагин (`[x]` – включён, `[ ]` – выключен); выбор применяется по **ОК** и запоминается между запусками, **Отмена** его отбрасывает.
- Кнопка **Разрешения...** открывает диалог: можно разрешить плагину заменять встроенные обработчики (`[replaces .zip: on]`) и то, что он просит в манифесте, например читать файлы через программу (`[needs vfs.read: on]`).
- **Ctrl+Вверх** и **Ctrl+Вниз** меняют порядок загрузки плагинов (он важен при равных приоритетах и действует со следующего запуска).
- **Сведения** показывает, для чего плагин нужен и что он добавил (команды, клавиши, типы файлов, схемы), а при наличии – открывает его справку.
- **Добавить...** устанавливает плагин из папки или файла `.zip` (в нём должен быть `plugin.json`; имя папки берётся из `id`). Установленный плагин выключен: включите его пробелом и нажмите **ОК**. Плагин с тем же `id` заменяется после подтверждения; загруженный плагин работает в старой версии до следующего запуска. Архив с путями за пределами папки плагина отклоняется.
- **Удалить** стирает папку выбранного плагина после подтверждения. Если файлы плагина заняты (он загружен), выключите его, перезапустите программу и повторите.
<!--external-tools-->- **Внешний просмотрщик/редактор...** – команды для Alt+F3 / Alt+F4; `%1` – путь к файлу (без `%1` путь дописывается в конец), например `"C:\Program Files\Notepad++\notepad++.exe" %1`.
- **Профили окружения...** – переменные, накладываемые на окружение новых оболочек; см. [Профили окружения](#профили-окружения).
<!--markdown-colors-->- **Цвета Markdown...** – цвета Markdown-просмотра (F3 на файле `.md`): цвет текста и фона (`#RRGGBB`) и **начертание** для каждого элемента.

**Элементы и начертание**
- Элементы: заголовки, жирное, курсив, зачёркнутое, код, цитаты, маркеры списков, линии, ссылки, таблицы.
- Начертание выбирается из списка: Тема, Обычный, Жирный, Курсив, Жирный курсив, Подчёркнутый, Зачёркнутый и сочетания.
- Пустое поле и пункт **«Тема»** в списке начертаний оставляют цвет и начертание темы; **«Обычный»** выключает начертание элемента (например, подчёркивание ссылок).
- **F9** на поле или щелчок по его кнопке **[...]** открывает выбор цвета.
- Строка **«Текст и документ»** задаёт цвет текста и фон всего Markdown-просмотра (только для Markdown, остальные файлы остаются в цветах темы); элементы без собственного фона берут его.
- Образец рядом со строкой рисуется её цветами и начертанием.

**Импорт из Obsidian...** берёт цвета из темы Obsidian (`theme.css`, например `<хранилище>\.obsidian\themes\<тема>\theme.css`).
- **Тёмная** или **светлая** палитра выбирается в диалоге импорта.
- Полученные цвета и начертания (жирность, курсив и подчёркивание, которые тема задаёт заголовкам, жирному, ссылкам, цитатам и заголовкам таблиц) заменяют значения в полях и списках (сохраняются только по ОК).

**Сбросить** очищает все поля и ставит всем начертаниям **«Тема»**, так что действуют цвета и начертания темы.

**Где хранятся.** В активной теме: у встроенной темы программа спрашивает имя новой темы, свою тему обновляет на месте; в поля попадают только значения, которые задаёт сама тема (остальное наследуется).
- **Масштаб**: Ctrl+колесо мыши, **Ctrl+0** – сброс.

<!--color-picker-->### Выбор цвета

В окне выбора цвета:
- сетка образцов (по горизонтали оттенки, по вертикали от светлых к тёмным; нижняя строка серая);
- ползунки **H, S, L** (оттенок, насыщенность, яркость) и **R, G, B**;
- поле **Hex** с двумя образцами: цвет, который **был** при открытии, и цвет **сейчас**.

**Клавиши**
- **Вверх / Вниз** переключают сетку, ползунки и поле hex.
- **Влево / Вправо** двигаются по сетке или меняют ползунок на 1 (**Shift** – на 10, **PgUp / PgDn** – на 10, **Home / End** – до краёв).

**Мышь.** Щелчок выбирает образец или ставит ползунок; щелчок по образцу **was** возвращает исходный цвет.

Сетка строится с текущей насыщенностью, поэтому ползунок **S** делает её бледнее или ярче. **Выбрать** принимает цвет, **Цвет темы** очищает поле, и снова действует цвет темы.

### Шрифт и межстрочный интервал

Флажок **«Межстрочный интервал (как в терминале)»** в **Настройки → Шрифт / экран...** делает строки выше на 15% кегля; текст остаётся по центру строки, рамки и выделение растягиваются на всю её высоту. По умолчанию флажок снят: строки высотой в строку шрифта, и на экране помещается больше строк. Для Cascadia Mono 11 пт это 17 пикселей без интервала и 19 с интервалом – столько же, сколько в Windows Terminal.

Кегль задаётся в типографских пунктах, как в Windows Terminal и консоли Windows: от 6 до 24 пт, от 8 до 12 пт – с шагом 0,5. При масштабе Windows 100% 1 пт = 4/3 пикселя: 10,5 пт – 14 пикселей (прежний размер по умолчанию), 11 пт – 14,7 пикселя.

Два параметра в том же окне делают текст чётче:
- **«Размер шрифта в целых пикселях»** округляет размер букв до целого числа физических пикселей экрана. При масштабе Windows 125% и 150% и дробных размерах (11 пт) штрихи получаются одной толщины. Размер клетки при этом может немного измениться. По умолчанию выключено.
- **«Контраст текста»** (нет, слабый, средний, сильный) дорисовывает бледную кайму сглаживания: тонкий светлый текст на тёмном фоне читается плотнее. По умолчанию выключено.
- **«Ширина клетки» и «Высота клетки»** добавляют к каждой клетке от 0 до 4 физических пикселей. Помогают шрифту, у которого буквы слипаются или строки лежат слишком плотно. Буквы остаются по центру клетки, рамки заполняют её целиком. По умолчанию 0.
- **«Запасной шрифт»** – второе семейство шрифтов для символов, которых нет в основном: иероглифов, значков. Введите название семейства; пустое поле или семейство, которого нет в системе, оставляют подбор за Windows. Размер клетки запасной шрифт не меняет: он берётся из основного.

#### Почему текст выглядит не так, как в Far

Far сам текст не рисует: это делает окно консоли, в котором он запущен, – Windows Terminal или классическая консоль Windows – своим шрифтом и по своим правилам. Если сравнить MTN2 и Far с одинаковыми шрифтом, кеглем и цветами, начертание совпадает: толщина штрихов и сглаживание одни и те же. Различия дают настройки:
- **Шрифт и кегль.** В Windows Terminal по умолчанию Cascadia Mono 11 пт. В MTN2 – шрифт и кегль из «Шрифт / экран» (по умолчанию Cascadia Mono, если он установлен, иначе Consolas; кегль 10,5 пт). Узкие и светлые шрифты, например Ubuntu Mono, выглядят тоньше и бледнее, особенно на синем фоне.
- **Высота строки.** Windows Terminal добавляет к строке шрифта около 15% кегля. В MTN2 это делает флажок «Межстрочный интервал»; без него строки плотнее. Классическая консоль Windows берёт высоту строки из метрик шрифта Windows, и она бывает ещё на 1–3 пикселя выше (Cascadia Mono 11 пт – 20 пикселей).
- **Цвета.** Цвета задаёт тема MTN2, а в Far – его собственная раскраска и цветовая схема терминала. В теме по умолчанию обычные файлы светло-серые, в Far – обычно бирюзовые; у бирюзового на синем контраст вдвое выше, и текст кажется жирнее.
- **Сглаживание.** MTN2 сглаживает текст оттенками серого. Windows Terminal делает так же, если в профиле `antialiasingMode` = `grayscale` (как по умолчанию); с `cleartype` у букв появляется цветная кайма. Классическая консоль Windows использует ClearType, если он включён в Windows.
- **Масштаб Windows.** Оба рисуют текст в физических пикселях экрана, поэтому при 125% и 150% чёткость одинаковая.

#### Когда совпадает

Текст MTN2 совпадает с Far в Windows Terminal по размеру клетки, толщине штрихов и высоте строки, если:
- выбран тот же шрифт (для Windows Terminal по умолчанию – Cascadia Mono);
- тот же кегль (для Windows Terminal по умолчанию – 11 пт);
- включён «Межстрочный интервал (как в терминале)»;
- в профиле Windows Terminal сглаживание `grayscale`;
- цвета темы MTN2 и Far близки.

С классической консолью Windows (Far без Windows Terminal) полного совпадения не будет: высота строки и ClearType там свои.

### Уведомления

Команды, после которых на экране ничего не меняется, подтверждают себя коротким уведомлением в правом нижнем углу; оно исчезает через несколько секунд и не перехватывает клавиши. Уведомления появляются для:
- **Alt+Shift+Ins** / **Ctrl+Shift+Ins** – скопированный путь / имя (или «Нечего копировать»);
- **Ctrl+C** / **Ctrl+X** (**Ctrl+Ins** / **Ctrl+Del**) на панели – файлы, помещённые в буфер обмена;
- копирования текста в просмотрщике / редакторе (без выделения – текущая строка), в командной строке и в терминале;
- **Ctrl+R** – панель обновлена;
- **Ctrl+Shift+O** – папка, в которую перешла консоль;
- **Ctrl+Alt+R** – элемент, восстановленный из корзины;
- **Ctrl+Alt+D** – папка, добавленная в избранные;
- выделения по маске (**серый +/−**, **Ctrl+серый +/−**, **Alt+серый +/−**), которое ничего не изменило, – красным.

Уведомления отключаются в **Настройки → Интерфейс...** («Показывать всплывающие уведомления»). Исключение – уведомление о проверке обновлений: у него свой флажок (см. [Обновления](#обновления)).

## Обновления

MTN2 умеет обновляться сам: находит новую версию на GitHub, скачивает её и устанавливает, но только с согласия пользователя.

### Как проходит обновление

Через несколько секунд после запуска MTN2 раз в сутки проверяет на GitHub, не вышла ли новая версия. Если вышла, программа спрашивает: **Обновить**, **Позже** или **Пропустить версию** (о пропущенной версии больше не напомнит). Без согласия ничего не скачивается и не устанавливается.

После загрузки (архив проверяется по контрольной сумме SHA-256) предлагается **Перезапустить** сейчас или установить обновление **При выходе**. Если идут фоновые копирования, установка откладывается до выхода. Заменяются только файлы программы (в том числе `7z.dll`, который входит в пакет) – настройки и другие файлы пользователя остаются как есть.

### Настройка проверки

Меню **≡ → Обновления...** (F9, затем самый левый пункт верхнего меню) показывает установленную версию, проверяет обновления сразу (**Проверить**) и содержит два флажка:

- **Проверять обновления при запуске** – раз в сутки при старте. Если флажок снят, MTN2 сам в сеть не выходит.
- **Показывать уведомление о проверке** – при каждой проверке, которая выходит в сеть (при запуске или по кнопке **Проверить**), в правом нижнем углу на несколько секунд появляется уведомление «Проверка обновлений MTN2 на github.com...».

Подробности:
- У проверки при запуске в уведомлении есть вторая строка – как проверку отключить.
- Уведомление показывается, даже если остальные всплывающие уведомления выключены, и исчезает, как только GitHub ответил.
- Пока открыт диалог, уведомление скрыто под ним.

### Что уходит в сеть

Проверка – это один HTTPS-запрос к `api.github.com` за описанием последнего выпуска репозитория `Laex/MTN2`. В запросе нет ничего, кроме версии MTN2 в заголовке `User-Agent`: ни имён файлов, ни путей, ни настроек. Скачивание обновления – загрузка архива выпуска с GitHub после ответа **Обновить**.

## Настройка клавиш

Встроенный набор клавиш можно частично переопределить файлом `keymap.json` в папке настроек (или через **Настройки → Раскладка клавиш...**): указываются только изменённые действия, остальные остаются встроенными. **Ctrl+Alt+K** – перечитать файл без перезапуска.

Кроме панелей, настраиваются команды просмотрщика и редактора. Их имена в `keymap.json` начинаются с:
- `Doc` – общие для просмотра и правки: `DocHex`, `DocFind`, `DocEncoding`, `DocClose`…;
- `Viewer` – только просмотр: `ViewerWrap`;
- `Markdown` – просмотр Markdown: `MarkdownSource`;
- `Editor` – только правка: `EditorSave`, `EditorUndo`, `EditorDeleteLine`…

Одно и то же сочетание может означать разное в панелях и в документе – например, Ctrl+H показывает скрытые файлы в панели и переключает Hex в документе. Более узкое значение перекрывает общее: F4 в просмотре Markdown переключает исходный текст, а не Hex.

Глобальные команды работают в любом окне – в панелях, документе и терминале:
- `Help` (F1), `TopMenu` (F9), `CommandPalette` (Shift+F9);
- `NextTab` / `PrevTab` (Ctrl+Alt+PgDn / Ctrl+Alt+PgUp);
- `AppConsoleToggle` (Ctrl+O), `NewTerminal` (Ctrl+Shift+N), `SelectConsoleProfile` (Ctrl+Alt+O);
- `AppQuit` (Alt+X), `ZoomReset` (Ctrl+0), `ReloadKeymap` (Ctrl+Alt+K);
- `ToggleMouse` (Ctrl+Shift+M, только текстовая версия).

**Сочетание, занятое окном.** Оно остаётся за окном:
- F10 закрывает документ, а выходом из программы служит только в панелях (`Quit`);
- Esc в панелях показывает консоль (`ConsoleToggle`), когда фокус на панели; в командной строке он сначала очищает её, потом возвращает фокус панели.

**Полноэкранная программа.** Пока в консоли или терминале она работает (режим клавиш профиля «авто» или «терминал», см. раздел «Терминалы»), консоль получает и эти клавиши, кроме выхода из консоли: F11, Ctrl+O, переключения вкладок, Ctrl+Shift+N и Ctrl+Alt+O.

**Диалоги.** Пока открыт диалог, глобальные команды не срабатывают; `ZoomReset` и `ReloadKeymap` срабатывают всегда.

В консоли (Ctrl+O) и терминале настраиваются команды с именами на `Shell`:
- `ShellHistory` (Alt+F8), `ShellSelectAll` (Ctrl+A);
- `ShellCopyOrInterrupt` (Ctrl+C – копировать выделение, без выделения прервать команду), `ShellCopy` (Ctrl+Ins), `ShellPaste` (Ctrl+V, Shift+Ins);
- `ShellFind` (Ctrl+Shift+F – поиск по выводу), `ShellFindNext` / `ShellFindPrev` (F3 / Shift+F3);
- в консоли ещё `ConsoleSyncDir` (Ctrl+Shift+O – панель переходит в папку консоли).

Остальные клавиши уходят в оболочку.

В диалоге **Настройки → Раскладка клавиш** действия сгруппированы по окнам – глобальные, файловые панели, просмотр и редактор, консоль и терминал – и названы по-человечески; имя из `keymap.json` видно в окне изменения. Подписи F-клавиш внизу экрана, подсказки вида `A:All` и сочетания в верхнем меню берутся из раскладки: после переназначения они показывают новую клавишу.

На одно действие можно назначить несколько сочетаний: в окне изменения они перечисляются через `;`, в `keymap.json` – отдельными записями. Кроме букв, цифр и служебных клавиш, назначаются знаки `/`, `,`, `.`, `'`, `=`; точку с запятой и минус основного блока пишут словами `Semicolon` и `Minus` (`-`, `+` и `*` означают клавиши цифрового блока).

Модификаторы должны совпадать точно: Ctrl+Shift+A – не то же, что Ctrl+A. Стрелки, Home/End, набор текста и `/` в просмотрщике не настраиваются.

### Клавиши вкладок

Все клавиши вкладок – обычные действия раскладки и переназначаются в `keymap.json`. Вкладки панели и рабочие пространства (вкладки верхней строки) – разные вещи, у каждых свои действия:

| Что | Действие в `keymap.json` | По умолчанию |
| --- | --- | --- |
| Новая вкладка панели | `NewTab` | Ctrl+T |
| Следующая / предыдущая вкладка панели | `NextPanelTab` / `PrevPanelTab` | Ctrl+Tab / Ctrl+Shift+Tab |
| Закрыть вкладку панели | `CloseTab` | Ctrl+W |
| Новое рабочее пространство | `NewWorkspace` | Ctrl+Shift+W |
| Следующее / предыдущее рабочее пространство | `NextTab` / `PrevTab` | Ctrl+Alt+PgDn / Ctrl+Alt+PgUp |

Те же действия делают кнопки `[+]` и `[x]` в строках вкладок и пункты верхнего меню.

### Свой `keymap.json` и обновление

Файл `keymap.json` в папке настроек накладывается на встроенную раскладку: действия, которые в нём есть, побеждают встроенные.
- Диалог **Настройки → Раскладка клавиш** записывает в файл только изменённые действия, поэтому остальные сочетания после обновления программы подхватываются сами.
- Файл, сохранённый прежними версиями, содержит все действия и «замораживает» старые сочетания: чтобы получить новые, удалите из него строки нужных действий или весь файл (заранее сохраните копию, если в файле есть свои изменения).
- Действие без клавиш записывается пустым списком.

### Примеры для привычек Far и MC

В репозитории лежат три примера `keymap.json` – [`keymap.far.json`, `keymap.mc.json` и `keymap.tc.json`](https://github.com/Laex/MTN2/tree/main/docs/keymap-presets). Скопируйте нужный в папку настроек под именем `keymap.json` (или добавьте его действия в свой файл) и нажмите **Ctrl+Alt+K**.
- **Far:** Esc в панелях очищает командную строку и не открывает консоль (она по-прежнему на Ctrl+O).
- **MC:** Alt+. показывает скрытые файлы, Ctrl+\ открывает список папок, Alt+Enter вставляет имя файла в командную строку, Alt+A и Alt+Shift+A вставляют путь папки активной и второй панели, свойства переехали на Ctrl+Shift+P.
- **Total Commander:** Alt+F5 и Alt+F9 – упаковать и распаковать, Ctrl+A – выделить всё, Ctrl+M – переименование по правилам, Ctrl+P – вставить путь папки, Ctrl+Tab и Ctrl+Shift+Tab – переключение вкладок, Alt+Down – история папок. Раскладка по умолчанию уже следует привычкам Norton Commander.

### Зарезервированные сочетания

Пока не заняты и оставлены под будущие возможности: **Shift+F3** (команды архива), **F11** (меню плагинов), **Ctrl+Alt+Ins** (сетевые UNC-пути), **Ctrl+.** (запись макроса). Автоматическая проверка следит, чтобы встроенная раскладка их не занимала.

## Файлы настроек

Папка настроек – `%APPDATA%\MTN2\`. Если рядом с `MTN2.exe` лежит файл `portable.dat`, настройки хранятся рядом с программой (переносной режим).

| Файл | Содержимое |
| --- | --- |
| `session.json` | состояние окна, панелей и вкладок, тема, шрифт, язык |
| `keymap.json` | переопределённые клавиши |
| `environment.json` | профили окружения для оболочек |
| `aliases.json` | свои слова для поиска в палитре команд |
| `history.json` | история команд |
| `folderhistory.json` | история папок |
| `filehistory.json` | история файлов (Alt+F11) |
| `externaltools.json` | внешний просмотрщик и редактор (Alt+F3 / Alt+F4) |
| `themes\*.theme.json` | ваши темы (Настройки → Тема...) |
| `dialoghistory.json` | история полей ввода в диалогах |
| `workspaces.json` | сохранённые рабочие пространства |
| `sshconnections.json` | SSH/SFTP-подключения |
| `associations.json` | ассоциации файлов |
| `usermenu.json` | главное меню пользователя (F2) |
| `.mtn2menu.json` (в любой папке) | меню этой папки и вложенных |
