# Языковые пакеты

[English](LANGUAGE_PACKS.md) | **Русский**

В `MTN2.exe` встроен только английский. Любой другой язык интерфейса – папка (языковой пакет) рядом с программой, поэтому язык можно добавить, заменить или убрать без пересборки. Пакету не нужно входить в репозиторий или в релиз: достаточно распаковать его в `resource\`.

## Состав

```
MTN2.exe
resource\
  uk\                  <- языковой пакет, имя папки – код языка
    locale.json        <- обязательно: версия пакета и отображаемое имя
    strings.json       <- обязательно: ключ -> переведённый текст
    help\              <- необязательно: темы F1 (Markdown)
      index.md
      ...
```

В Linux та же папка – `resource/<код>/` рядом с программой.

## Имя папки

- Строчными буквами, код языка в стиле BCP 47: `uk`, `pl`, `pt-br`. Программа приводит искомое имя к нижнему регистру, поэтому в Linux папка с заглавными буквами не находится.
- При первом запуске язык берётся из языка интерфейса ОС: `uk-UA` пробуется целиком, затем сокращается до `uk`. Папка `ua` (код страны, а не языка) работает как пакет, но автоматически не выбирается никогда.

## locale.json

```json
{
  "version": 1,
  "name": "Українська"
}
```

- `version` – обязательно, JSON-**число** (`1`, а не `"1"`): версия набора ключей, под которую написан пакет. Взять её из поставляемых пакетов (`resource\de\locale.json`); актуальное значение хранится в репозитории в `src/resource.version`.
  - равна значению программы – пакет применяется;
  - меньше – пакет применяется, недостающие ключи показываются по-английски;
  - больше – пакет игнорируется и в списке языков не предлагается.
- `name` – имя в списке языков. Без него в списке показывается имя папки заглавными буквами (`UK`).

Пакет без `locale.json` или с нечитаемым `locale.json` игнорируется.

## strings.json

Файл в UTF-8 (BOM допустим). Ключи – те же, что в шаблоне [`src/strings/en.json`](../src/strings/en.json) (каждый ключ рядом с английским текстом; скопировать и перевести значения). Две равнозначные формы:

```json
{ "dialogs": { "DIALOG_ABOUT": { "$title": "Про MTN2" } } }
```

```json
{ "dialogs.DIALOG_ABOUT.$title": "Про MTN2" }
```

Правила:

- Отсутствующий ключ остаётся английским; неполный перевод допустим. Неизвестные ключи и значения, не являющиеся строками, пропускаются.
- Файл с неверным JSON программу не останавливает: пакет в списке есть, но все тексты остаются английскими. Синтаксис проверять в редакторе или командой `python -m json.tool strings.json`.
- Заполнители (`%s`, `%d`, `%1`, `{0}`) сохранять в том же количестве, что и в английском тексте; перевод с неподходящими заполнителями заменяется английским текстом.
- `&` перед буквой задаёт горячую клавишу пункта меню и работает в любой раскладке; в переводах пунктов меню его сохранять.
- Заголовки многоколоночных списков (ключи `*Header` и `header`) выровнены по строкам данных, которые программа расставляет сама: каждая колонка должна начинаться с того же смещения, что и в английском тексте, и помещаться до следующей.
- Необязательные ключи `menu.alias.<действие>` добавляют слова вашего языка для поиска в палитре команд (Shift+F9).
- Ключи, начинающиеся с `//`, – свободные комментарии.

## help\

Темы F1 – файлы Markdown; образец состава – [`bin/win64/resource/en/help`](../bin/win64/resource/en/help) (`index.md` – титульная страница с содержанием). Если в пакете нет `help\index.md`, F1 показывает всю справку по-английски. Справка необязательна: пакет можно выпустить только со строками интерфейса, а справку добавить позже.

## Установка и проверка

1. Скопировать папку (например, `uk`) в `resource\` рядом с `MTN2.exe`.
2. Выбрать язык в настройках; смена применяется без перезапуска. Только что скопированная папка находится при следующем открытии списка языков.
3. `MTN2.exe --self-check` печатает по строке на каждый файл пакета: `OK` – пакет применим, `WARN` – `version` меньше текущей, `FAIL` – нет или неверен `locale.json`, `version` больше текущей, нет `strings.json`. Без `help\index.md` тоже выводится `FAIL`: эта строка значит только «нет переведённой справки», сам пакет работает. `strings.json` проверка не разбирает.

## Распространение пакета

Достаточно архива с папкой пакета (`uk\locale.json`, `uk\strings.json`, при желании `uk\help\`): получатель распаковывает его в `resource\`. Плагины переводятся отдельно, пакетами `plugins\<id>\resource\<код>\` того же устройства ([PLUGIN_DEVELOPMENT.ru.md](PLUGIN_DEVELOPMENT.ru.md)).

Пакет можно и добавить в репозиторий (`bin/win64/resource/<код>/`), тогда он будет поставляться с программой; язык сначала согласуйте в issue, чтобы не дублировать работу.
