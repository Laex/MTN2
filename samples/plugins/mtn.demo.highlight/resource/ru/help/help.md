# Цвета синтаксиса (Rust)

Раскрашивает текст в стиле конфигурационных файлов в просмотрщике (F3) и редакторе (F4).

## Как пользоваться

Нажимать ничего не нужно: откройте файл `.json`, `.ini`, `.cfg`, `.conf`, `.toml`, `.yaml` или `.yml`. Строки, числа, константы (`true`, `false`, `null`, `yes`, `no`, `on`, `off`), ключи, `[разделы]` и комментарии (`;`, `#`, `//`) получат свои цвета. Цвета принадлежат программе и следуют теме: для тёмного и светлого фона подбираются свои наборы.

## Для авторов

Исходник: `samples/plugins/mtn.demo.highlight/src/lib.rs`. Плагин регистрирует обработчик через `register_highlighter`. Для каждой строки, которую рисует просмотрщик или редактор, хост вызывает его с текстом строки (UTF-8) и местом под отрезки из трёх чисел: начало (смещение в байтах), длина (в байтах) и класс (комментарий, строка, число, ключевое слово, тип, функция, оператор, препроцессор, константа, ключ, ошибка). Хост запоминает ответ по тексту строки. См. `docs/PLUGIN_DEVELOPMENT.md`.
