# Просмотр JSON (Go)

**F3** на файле `.json` показывает его с отступами. Файл, который не является корректным JSON, открывается как обычно.

## Как пользоваться

- Поставьте курсор на файл `.json` и нажмите **F3**.
- **Ctrl+Alt+F9** (*GoInfo*) показывает версию среды Go и использование памяти.
- **Параметры > Плагины... > Настройки** задают ширину отступа (от 1 до 8 пробелов, по умолчанию 2).

## Для авторов

Исходник: `samples/plugins/mtn.demo.go`. Нативная DLL, собранная через cgo; `keepLoaded` включён, потому что среду Go нельзя выгрузить.
