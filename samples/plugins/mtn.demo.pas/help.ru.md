# Быстрые заметки (Delphi)

**Ctrl+Alt+F8** (*Note* в строке клавиш) спрашивает строку текста и добавляет её с датой и временем в файл заметок. В строке состояния показано **Notes: N** – число заметок в файле.

## Как пользоваться

- Нажмите **Ctrl+Alt+F8**, введите заметку, нажмите OK.
- **Параметры > Плагины... > Настройки** выбирают другой файл заметок. Пусто – `mtn2-notes.txt` в папке пользователя.

## Для авторов

Исходник: `samples/plugins/mtn.demo.pas/NotesPlugin.dpr`. Показывает команду с клавишей, диалог с полем ввода, сегмент статуса и диалог настроек.
