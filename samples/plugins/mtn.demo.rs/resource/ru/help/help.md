# Просмотр CSV таблицей (Rust)

**F3** на файле `.csv` показывает выровненную таблицу вместо сырого текста. Разделитель (запятая, точка с запятой или табуляция) выбирается по первой строке; поля в кавычках понимаются.

## Как пользоваться

- Поставьте курсор на файл `.csv` и нажмите **F3**.
- **F4** открывает обычный редактор: правку плагин не трогает.
- Файлы больше 4 МБ и файлы, которые не удалось прочитать, открываются как обычно.

Таблица записывается в текстовый файл во временной папке и показывается во встроенном просмотрщике.

## Для авторов

Исходник: `samples/plugins/mtn.demo.rs/src/lib.rs`. Провайдер открытия файлов с ответом-редиректом.
