# Безопасное удаление (Go, WASM)

Блокирует **Shift+Del** (безвозвратное удаление) и команду **Wipe** и сообщает об этом в диалоге. Обычное **F8 / Del** (в корзину) не затрагивается. В строке состояния показано **Safe delete: on**.

Чтобы снова разрешить безвозвратное удаление, выключите плагин в **Параметры > Плагины...**.

## Для авторов

Исходник: `samples/plugins/mtn.demo.go.wasm/main.go`. Модуль WebAssembly, собранный с `GOOS=wasip1`; в `plugin.json` нужно `"wasi": true`.
