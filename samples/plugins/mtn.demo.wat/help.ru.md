# Счётчик (WAT)

**Ctrl+Alt+F7** (*Count* в строке клавиш) прибавляет единицу к счётчику. В строке состояния показано **Count: N**. Счётчик начинается с нуля при каждом запуске MTN2.

## Для авторов

Исходник: `samples/plugins/mtn.demo.wat/plugin.wat`, модуль WebAssembly, написанный вручную в текстовом виде; хост собирает его при загрузке плагина.
