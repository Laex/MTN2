# Инструменты для текста (C++)

Небольшие инструменты для текста, открытого в редакторе (F4) и просмотрщике (F3).

## Как пользоваться

Откройте текстовый файл и нажмите:

- **Ctrl+Shift+U** – выделенный текст в верхний регистр; **Ctrl+Shift+L** – в нижний.
- **Ctrl+Shift+S** – отсортировать строки выделения (или всего документа, если ничего не выделено) без учёта регистра.
- **Ctrl+Shift+R** – удалить повторяющиеся строки выделения (или всего документа), оставляя первую из каждых.
- **Ctrl+Shift+T** – включить или выключить **прибирание при сохранении**. Пока оно включено, в строке состояния панелей виден текст **Tidy on save**, а каждое сохранение в редакторе (F2) сначала убирает пробелы в конце строк и добавляет перевод строки в конце текста. Выбор запоминается между запусками.

Каждое изменение – один шаг отмены (Ctrl+Z). В просмотрщике (только чтение) инструменты предлагают сначала нажать F4.

## Для авторов

Исходник: `samples/plugins/mtn.demo.texttools/plugin.cpp`. Плагин читает документ через `doc_get_text`, меняет через `doc_replace`, сохраняет курсор через `doc_info` / `doc_set_cursor` и перехватывает встроенную команду `EditorSave` (перехватчик отвечает 0, поэтому сохранение продолжается). См. `docs/PLUGIN_DEVELOPMENT.md`, раздел «Документы, панели и буфер обмена».
