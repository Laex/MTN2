带真实终端的双面板文件管理器

Modern Terminal Navigator 2：沿用 DOS Navigator 和 Far Manager 熟悉的按键，提供标签页、基于 ConPTY 的控制台、查看器、编辑器和插件。界面是文本式的，窗口则是普通窗口。

下载 源代码

Windows x64 和 Linux x86-64 · 免费，MPL-2.0 · 无需安装程序和管理员权限

功能

面板与标签页

双面板带标签页，Brief 和 Full 显示模式，快速搜索，实时过滤，目录比较，收藏文件夹，支持超长路径。

真实的终端

基于 ConPTY 的控制台：cmd、PowerShell、Git Bash、WSL、SSH。支持 ANSI/VT，TUI 程序使用的备用屏幕，以及终端工作区。

压缩包当作文件夹

zip 和 7z 像普通目录一样打开。通过 SSH 的 SFTP 作为虚拟文件系统挂载。

查看器与编辑器

文本、十六进制、大文件流式读取，带表格的 Markdown 预览，Ctrl+Q 快速查看，编辑器的语法高亮由插件提供。

后台任务

复制、移动和删除作为带进度的任务运行，进度也显示在任务栏按钮上。支持回收站、校验和、目录同步。

键盘优先

按键布局接近 Far Manager，可通过 keymap.json 完全自定义。F2 为用户菜单。

主题

Far Classic、Total Commander、Dracula、Nord、Solarized、High Contrast。可在主题编辑器中制作自己的主题，主题就是普通的 JSON 文件。

插件

原生 DLL 和 WebAssembly：自定义文件系统、面板、命令、菜单项、按键绑定和语法高亮。

Unicode 与语言

中日韩字符与其他终端一样占两列。界面提供英语、俄语和德语，切换语言无需重启。

Linux

mtn2-tui 占满整个终端，可通过 SSH 和 tmux 使用。mtn2-sdl 在 X11 和 Wayland 下用 SDL2 显示同样的窗口。

便携

单个文件夹，不写注册表。便携版把设置保存在 MTN2.exe 旁边。

隐私

没有遥测，没有云功能。唯一的网络请求是在 GitHub 上检查更新，可以关闭。

开始使用

  1. 下载：从 Releases 页面获取压缩包：win64.zip（设置保存在 %APPDATA%\MTN2）、win64-portable.zip（全部放在程序旁边）、linux-x64.tar.gz 或 .deb。
  2. 解压：解压到任意文件夹并运行 MTN2.exe。在 Linux 上：./mtn2/install.sh 或 sudo apt install ./MTN2-*-linux-x64.deb，然后运行 mtn2。
  3. 按 F1：帮助介绍按键和设置。之后程序会自行更新（≡ → 更新），安装前总会先询问。

首次运行时，Windows SmartScreen 可能提示未知发布者：点击“更多信息”→“仍要运行”。下载文件通过 SHA-256 校验，详见 FAQ（英文）。
