Ein Zwei-Fenster-Dateimanager mit echtem Terminal

Modern Terminal Navigator 2: die vertrauten Tasten von DOS Navigator und Far Manager, Tabs, eine ConPTY-Konsole, Viewer, Editor und Plugins. Die Oberfläche ist textbasiert, das Fenster ein normales.

Herunterladen Quellcode

Windows x64 und Linux x86-64 · Kostenlos, MPL-2.0 · Ohne Installer und Administratorrechte

Funktionen

Fenster und Tabs

Zwei Fenster mit Tabs, Brief- und Full-Modus, Schnellsuche, Live-Filter, Ordnervergleich, Favoriten, lange Pfade.

Ein echtes Terminal

Konsole auf ConPTY: cmd, PowerShell, Git Bash, WSL, SSH. ANSI/VT, alternativer Bildschirm für TUI-Programme, Terminal-Arbeitsbereiche.

Archive als Ordner

zip und 7z öffnen sich wie gewöhnliche Verzeichnisse. SFTP über SSH wird als virtuelles Dateisystem eingebunden.

Viewer und Editor

Text, Hex, große Dateien als Stream, Markdown-Vorschau mit Tabellen, Schnellansicht mit Strg+Q, Editor mit Syntaxhervorhebung per Plugin.

Hintergrundaufgaben

Kopieren, Verschieben und Löschen laufen als Aufgaben mit Fortschritt, auch auf der Taskleistenschaltfläche. Papierkorb, Prüfsummen, Ordnersynchronisation.

Tastatur zuerst

Die Tastenbelegung ähnelt Far Manager und lässt sich über keymap.json vollständig ändern. Benutzermenü auf F2.

Themen

Far Classic, Total Commander, Dracula, Nord, Solarized, High Contrast. Eigene Themen entstehen im Themen-Editor, es sind einfache JSON-Dateien.

Plugins

Native DLLs und WebAssembly: eigene Dateisysteme, Fenster, Befehle, Menüpunkte, Tastenbelegungen und Hervorhebung.

Unicode und Sprachen

CJK-Zeichen belegen zwei Spalten wie in anderen Terminals. Die Oberfläche gibt es auf Englisch, Russisch und Deutsch, der Wechsel erfolgt ohne Neustart.

Linux

mtn2-tui füllt das ganze Terminal und läuft über SSH und in tmux. mtn2-sdl zeigt dasselbe Fenster in SDL2 unter X11 und Wayland.

Portabel

Ein Ordner, keine Registry-Einträge. Die portable Version legt ihre Einstellungen neben MTN2.exe ab.

Datenschutz

Keine Telemetrie, keine Cloud-Funktionen. Die einzige Netzwerkanfrage ist die Update-Prüfung auf GitHub, sie lässt sich abschalten.

Erste Schritte

  1. Laden Sie ein Archiv von der Seite Releases herunter: win64.zip (Einstellungen in %APPDATA%\MTN2), win64-portable.zip (alles neben dem Programm), linux-x64.tar.gz oder .deb.
  2. Entpacken Sie es in einen beliebigen Ordner und starten Sie MTN2.exe. Unter Linux: ./mtn2/install.sh oder sudo apt install ./MTN2-*-linux-x64.deb, dann mtn2.
  3. Drücken Sie F1: Die Hilfe erklärt Tasten und Einstellungen. Danach aktualisiert sich das Programm selbst (≡ → Updates) und fragt vor der Installation immer nach.

Beim ersten Start warnt Windows SmartScreen möglicherweise vor einem unbekannten Herausgeber: „Weitere Informationen“ → „Trotzdem ausführen“. Downloads werden per SHA-256 geprüft, Details in den FAQ (englisch).
