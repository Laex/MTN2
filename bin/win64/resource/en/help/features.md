## What MTN2 can do

A map of the program by task: what to press and where to read more. Keys are for the built-in profile (see [Key bindings](keymap.md)). Not sure where a command lives? **Shift+F9** searches all of them.

### Find a command or a key

- **Shift+F9** – search over every menu command by name, category or key; **Ctrl+K** in it changes the command's key. See [Top menu](topmenu.md).
- **F1** – help for the place you are in: a dialog, a menu, the console, an archive, a viewer.

### Get around quickly

- **Ctrl+D** – folder hotlist with groups and quick letters; **Ctrl+Shift+F12** – the folders you visit most; **Alt+F12** – folder history; **Alt+←** / **Alt+→** – back and forward. See [History and folder hotlist](history.md).
- **Alt+letter** – quick search by name in the panel; **Ctrl+I** – a filter that keeps only matching names. See [Search and filters](search.md).
- **Alt+F10** – folder tree; **Alt+F1** / **Alt+F2** – drives, network shares, special places. See [Drives and special places](drives.md).
- **Ctrl+Alt+P** – paired folders: going into or up a folder in one panel does the same in the other. See [Panels and navigation](panels.md).

### Select and work with files

- **Ins**, **Space**, Gray **+** / **-** / **\***, **Ctrl+M** (bring back the last selection). See [Selecting files](selection.md).
- **Ctrl+Alt+N** – rename many files by rules, with a preview. See [File operations](fileops.md#multi-rename).
- Copy, move and delete run in the background; **Ctrl+Shift+J** shows the job list with pause, queue and speed limit. See [Background jobs](jobs.md).
- **Enter** or **Ctrl+PgDn** on an archive opens it like a folder; **F5** copies out of it. See [Archives](archives.md).

### Search and compare

- **Alt+F7** – find files by mask, text, size, date; searches can run in the background and the results open as a panel. See [Search and filters](search.md).
- **Ctrl+Alt+C** – compare and merge two files; **Ctrl+Shift+C** – compare folders; synchronize two folders. See [Synchronization and comparison](sync.md).

### View and edit

- **F3** – view, **F4** – edit, **F6** – switch between them; **Ctrl+Q** – quick view on the other panel. Text, hex, Markdown and images. See [Viewing and editing files](viewer.md).

### Console, terminals, remote

- Type a command and press **Enter**; **Ctrl+O** switches between the panels and the console. See [Command line and console](cmdline.md).
- **Ctrl+Shift+N** – a terminal in its own tab: cmd, PowerShell, WSL, saved SSH connections; full-screen programs and the mouse work in it. See [Terminals](terminals.md).
- **Ctrl+Alt+Shift+N** – SSH and SFTP connections: a remote folder as a panel. See [Network: SSH and SFTP](ssh.md).

### Organize your work

- **Ctrl+T** / **Ctrl+W** – panel tabs; **Ctrl+Shift+W** – a new workspace (its own panels, terminals and documents); **Ctrl+Shift+D** – saved workspaces. See [Tabs and workspaces](workspaces.md).
- **Ctrl+\`** – brief or wide view and column sets; **Ctrl+F12** – sort; **Ctrl+Alt+G** – group rows by type or date. See [Panel view and sorting](view.md).
- **F2** – your own menu of commands. See [User menu](usermenu.md).

### Make it yours

- **Options → Theme...** – colors and frames; **Options → Keymap...** – any key; **Options → Plugins...** – extensions. See [Settings](settings.md) and [Key bindings](keymap.md).
- **Options → Export settings...** – everything in one zip file, to move to another computer. See [Settings files](configfiles.md).

Common tasks, step by step: see [Recipes](recipes.md).
