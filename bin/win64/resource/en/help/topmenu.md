## Top menu (F9)

**F9** or **Alt** opens the menu. Arrows move, **Enter** runs, **Esc** closes. The highlighted (accent) letter of an item runs it at once – in any keyboard layout: with a submenu open the letter is looked up among its items, otherwise among the categories. Item keys are shown to the right of the items. Items unavailable in the current mode are gray. A menu that does not fit in the window scrolls: a bar with ▲ ▼ marks shows on its right border, the selected item always stays in view, and the mouse wheel moves the selection.

**Shift+F9** (or "Find command..." in the ≡ menu) opens the command palette, a search over the menu items. Typing narrows the list: the words of the caption, of the category and common synonyms are matched ("shell" finds "Background console..."; "bc" finds it by the first letters of its words). The query shows in the field above the list; a word of the query may contain `?` (one character) and `*` (any run of characters). Your own search words go into `aliases.json` in the settings folder: `{ "tmaCmdConsoleProfile": "bash, zsh" }` – the item name and the words, comma separated or as a list. The file is read again each time the palette opens. Arrows select, **Enter** runs, **Backspace** erases, **Ctrl+K** opens the key list on the selected command, so its key can be changed; closing the list returns to the palette with the same search and command, and the new key shown (a command without a key of its own says so). **Esc** closes. Only the items available now are listed; the commands run last come first. The key can be changed in the keymap (command `CommandPalette`). Commands that have no menu item (Ctrl+Enter, Alt+Shift+Enter and the other panel keys) are listed in the "Keys" category together with their shortcuts. The search also covers the shortcut column: "F9" finds the commands whose shortcut uses F9, "shift" every shortcut with Shift, "ctrl+f" the shortcuts that contain Ctrl+F.

**Key hints.** When the program enters a new state, it shows a short notice with the useful keys once for good: after a search, in an archive, in a temporary panel, in a workspace, in an SFTP folder, while a command is being typed and after a console program is started with Enter. The keys come from the current keymap. The hints already shown are remembered between runs. In **Options → User interface** the "Show key hints" check box switches them off and the "Reset hints" button makes them new again; with pop-up notifications off there are no hints either.
