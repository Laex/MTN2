## Recipes

Short answers to "how do I...": the keys to press and what you get. Keys are for the built-in profile (see [Key bindings](keymap.md)); the whole map of the program is in [What MTN2 can do](features.md).

### Copy files to the other panel

Select with **Ins** or **Space**, press **F5**, confirm. The copy runs in the background; **Ctrl+Shift+J** shows the job list where it can be paused, queued or slowed down. See [File operations](fileops.md) and [Background jobs](jobs.md).

### Find a file and go to its folder

**Alt+F7**, type a mask (and text or size if needed), start the search. The results open as a panel: **Enter** on a row goes to the file's folder. See [Search and filters](search.md).

### Rename many files at once

Select the files, press **Ctrl+Alt+N**, set the rules and look at the preview before applying. See [File operations](fileops.md#multi-rename).

### Make two folders the same

**Ctrl+Shift+C** selects what differs between the panels; **F5** copies the selection across. For two-way work use the synchronization dialog. See [Synchronization and comparison](sync.md).

### Unpack an archive

**Enter** on the archive opens it like a folder; select what you need and press **F5** to copy it to the other panel. See [Archives](archives.md).

### Return to a folder quickly

**Ctrl+D** opens the folder hotlist, **Ctrl+Shift+F12** the folders you visit most, **Alt+F12** the history. **Alt+letter** jumps to a name in the current folder. See [History and folder hotlist](history.md).

### Run a program in its own tab

**Ctrl+Shift+N** opens a terminal in a new tab (cmd, PowerShell, WSL or a saved SSH connection). Full-screen programs and the mouse work there. See [Terminals](terminals.md).

### Work with a remote server

**Ctrl+Alt+Shift+N** connects over SSH or SFTP; the remote folder becomes a panel, so copying works the same as locally. See [Network: SSH and SFTP](ssh.md).

### Move your setup to another computer

**Options → Export settings...** packs everything into one zip file; import it on the other machine. See [Settings files](configfiles.md).
