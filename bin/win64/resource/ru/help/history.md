## История и избранные папки

| Клавиша | Действие |
| --- | --- |
| Alt+F12 | история посещённых папок |
| Ctrl+D | избранные папки |
| Ctrl+Alt+D | добавить текущую папку в избранное |
| Alt+F11 | история просмотренных и отредактированных файлов |
| Alt+F8 | история команд |

В списках: **Ins** – добавить, **F2** – изменить, **Del** – удалить (где применимо).

**История файлов (Alt+F11)** – последние 100 файлов, открытых по F3/F4, сверху самые свежие; пометка слева – режим, в котором файл открывали последним (**П** – просмотр, **Р** – правка).

**Enter** открывает файл в том же режиме, **F3** / **F4** – принудительно в просмотре / редакторе, **Ctrl+Enter** – переходит к файлу в панели, **Del** – убирает его из истории. Набор текста фильтрует список по пути. Позиция в файле восстанавливается.

Выбор из истории команд подставляет команду в командную строку, но не выполняет её.
