## История и избранные папки

| Клавиша | Действие |
| --- | --- |
| Alt+F12 | история посещённых папок |
| Ctrl+Shift+F12 | частые папки (по числу и давности заходов) |
| Alt+F11 | история просмотренных и отредактированных файлов |
| Alt+F8 | история команд |
| Ctrl+D | избранные папки |
| Ctrl+Alt+D | добавить текущую папку в избранное |

В списках: **Ins** – добавить, **F2** – изменить, **Del** – удалить (где применимо). Выбор из истории команд подставляет команду в командную строку, но не выполняет её.

В историях папок, файлов и команд (Alt+F12, Alt+F11, Alt+F8) **Del** убирает выбранную запись из истории, а **Ctrl+Del** очищает всю историю; набор текста фильтрует список.

<!--frecent-->**Частые папки (Ctrl+Shift+F12)** – папки, в которые вы заходите чаще всего; недавние заходы весят больше. Набор текста сужает список, **Enter** открывает папку, **Del** забывает её счётчик, **Ctrl+Del** очищает рейтинг. В отличие от Alt+F12, где порядок по времени, ежедневные папки остаются вверху.

<!--file-history-->**История файлов (Alt+F11)** – последние 100 файлов, открытых по F3/F4, сверху самые свежие; пометка слева – режим, в котором файл открывали последним (**П** – просмотр, **Р** – правка). **Enter** открывает файл в том же режиме, **F3** / **F4** – принудительно в просмотре / редакторе, **Ctrl+Enter** – переходит к файлу в панели, **Del** – убирает его из истории. Набор текста фильтрует список по пути. Позиция в файле восстанавливается.
