## Работа с текстом и мышью

Одинаково в просмотре и редакторе, в командной строке, в полях диалогов и в консолях.

**Словом** считаются буквы любого алфавита, цифры и `_`. Всё остальное – пробелы, знаки препинания, `\`, `/`, `.`, `:` – **разделители**.

| Действие | Результат |
| --- | --- |
| Ctrl+← / Ctrl+→ | к началу слова / к концу слова (до следующего разделителя) |
| Ctrl+Shift+← / Ctrl+Shift+→ | то же с выделением; шаг назад снимает выделение с пройденной части |
| Shift+стрелки, Shift+Home/End | выделение |
| Щелчок | поставить курсор |
| Двойной щелчок | выделить слово (на разделителе – серию одинаковых символов) |
| Следующий быстрый щелчок | выделить всю строку |
| Shift+щелчок | расширить или сузить выделение до места щелчка |
| Протягивание мышью | выделение (просмотр, редактор, консоль) |
| Alt+протягивание мышью | прямоугольный блок (просмотр, редактор) |
| Ctrl+C / Ctrl+Ins, Ctrl+X / Shift+Del, Ctrl+V / Shift+Ins | буфер обмена |
| Ctrl+A | выделить всё |

В панелях при непустой командной строке Ctrl+Shift+←/→ работают в командной строке.

<!--mouse-->**Текстовая версия (mtn2-tui).** Программа забирает у терминала мышь, поэтому протягивание выделяет текст внутри MTN2, а в буфер он попадает через терминал (управляющая последовательность, которую часть терминалов, например PuTTY по умолчанию, игнорирует; внутри tmux и на рабочем столе MTN2 заполняет ещё буфер tmux и системный буфер обмена). Чтобы выделять средствами самого терминала, держите **Shift** при протягивании или выключите мышь клавишей **Ctrl+Shift+M** (**Настройки → Мышь терминала: вкл/выкл**); та же клавиша включает её обратно. Параметр `--no-mouse` запускает программу с выключенной мышью.

**История полей ввода.** У полей со стрелкой **↓** в правом конце (маски выделения, поиск файлов – маска и текст, путь и исключения при копировании/переносе, цель ссылки, создание папки и файла, поиск и замена в редакторе, запросы меню пользователя) программа помнит последние 20 значений. **Ctrl+↓** / **Alt+↓** или щелчок по стрелке раскрывают список: **Enter** – подставить, **Del** – удалить из истории, **Esc** – закрыть список. Значение попадает в историю при подтверждении диалога.
