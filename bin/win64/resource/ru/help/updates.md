## Обновления

MTN2 умеет обновляться сам: находит новую версию на GitHub, скачивает её и устанавливает, но только с согласия пользователя.

### Как проходит обновление

Через несколько секунд после запуска MTN2 раз в сутки проверяет на GitHub, не вышла ли новая версия. Если вышла, программа спрашивает: **Обновить**, **Позже** или **Пропустить версию** (о пропущенной версии больше не напомнит). Без согласия ничего не скачивается и не устанавливается.

После загрузки (архив проверяется по контрольной сумме SHA-256) предлагается **Перезапустить** сейчас или установить обновление **При выходе**. Если идут фоновые копирования, установка откладывается до выхода. Заменяются только файлы программы (в том числе `7z.dll`, который входит в пакет) – настройки и другие файлы пользователя остаются как есть.

### Настройка проверки

Меню **≡ → Обновления...** (F9, затем самый левый пункт верхнего меню) показывает установленную версию, проверяет обновления сразу (**Проверить**) и содержит два флажка:

- **Проверять обновления при запуске** – раз в сутки при старте. Если флажок снят, MTN2 сам в сеть не выходит.
- **Показывать уведомление о проверке** – при каждой проверке, которая выходит в сеть (при запуске или по кнопке **Проверить**), в правом нижнем углу на несколько секунд появляется уведомление «Проверка обновлений MTN2 на github.com...». У проверки при запуске в нём есть вторая строка – как проверку отключить. Уведомление показывается, даже если остальные всплывающие уведомления выключены, и исчезает, как только GitHub ответил; пока открыт диалог, оно скрыто под ним.

### Что уходит в сеть

Проверка – это один HTTPS-запрос к `api.github.com` за описанием последнего выпуска репозитория `Laex/MTN2`. В запросе нет ничего, кроме версии MTN2 в заголовке `User-Agent`: ни имён файлов, ни путей, ни настроек. Скачивание обновления – загрузка архива выпуска с GitHub после ответа **Обновить**.
