## Вид панели и сортировка

| Клавиша | Действие |
| --- | --- |
| Ctrl+\` | меню режимов колонок |
| Ctrl+Shift+F1 … F6 | режим: краткий или вариант широкого: размер, дата, полный, создан, типы |
| Ctrl+F12 | меню сортировки |
| Ctrl+F3 / F4 / F5 / F6 | сортировка по имени / расширению / дате изменения / размеру |
| Ctrl+F7 / F8 / F9 | без сортировки / по дате создания / по дате доступа |

Имена сравниваются без учёта регистра и по алфавиту языка системы, числа внутри имени – как числа: `file2` раньше `file10`, «абрикос» раньше «Яблоко», «ё» стоит рядом с «е» («ёлка» раньше «ель»), знаки препинания – перед буквами (`_build` раньше `A`). Повторный выбор того же порядка сортировки переключает направление. Буква в левом верхнем углу панели показывает сортировку (заглавная – по убыванию). У панели два вида: **краткий** (только имена в несколько колонок; ширина колонки (10–50 символов, по умолчанию 28; в панель помещается столько колонок, сколько влезет) задаётся в **Настройки → Колонки...** («Краткий вид», общий для всех панелей); сведения о файле – в строке состояния) и **широкий** (одна колонка имён и выбранные вами столбцы; в меню – встроенные варианты размер, дата, полный, создан, типы, а затем ваши наборы колонок). Столбцы широкого вида, в том числе добавленные плагинами (они показаны под названием плагина), выбираются в **Настройки → Колонки...**; диалог сохраняет их как именованный набор. Раскраска строк по маскам – **Настройки → Цветовая разметка...**.
