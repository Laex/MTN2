## Выделение файлов

| Клавиша | Действие |
| --- | --- |
| Ins | выделить / снять и перейти ниже |
| Shift+стрелки, Shift+Home/End/PgUp/PgDn | выделять по ходу курсора |
| Shift+Серый + | выделить все файлы |
| Ctrl+M | вернуть выделение, которое было до последнего сброса (например, после копирования); повторное нажатие возвращает обратно |
| Серый + / Серый − | выделить / снять по маске (`*.txt`, `a*.*`) |
| Серый * | инвертировать выделение |
| Ctrl+Серый + / Ctrl+Серый − | выделить / снять файлы с тем же расширением, что под курсором |
| Shift+Серый − | снять выделение со всех файлов |
| Alt+Серый + / Alt+Серый − | выделить / снять файлы с тем же именем |

В диалоге выбора по маске флажок «Выделять папки» распространяет маску и на папки. Операции (копирование, удаление, …) работают с выделенными элементами, а если ничего не выделено – с элементом под курсором.

### Группы масок

<!--mask-groups-->В любой маске (выделение, фильтр панели, поиск, цветовые группы) запись `@Имя` подставляет именованный набор масок, например `@Images` или `*.log;@Documents`. Встроены группы Images, Audio, Video, Documents, Archives и Sources. Свои группы и замена встроенных – в файле `maskgroups.json` в папке настроек: `{ "groups": { "Logs": "*.log;*.out" } }`. Неизвестное имя остаётся обычным текстом маски. Пункт меню «Параметры» – «Группы масок...» открывает список, где группы добавляют, меняют и удаляют; диалог выбора по маске тоже умеет сохранить свою маску как группу. В поле маски диалога (выделение, фильтр, поиск) Ctrl+G сохраняет введённые маски как группу с именем по первой маске и ставит в поле `@Имя`.

### Наборы колонок

В меню режимов колонок после готовых режимов перечислены именованные наборы колонок. Выбранный набор задаёт колонки той панели, на которой он выбран; другая панель сохраняет свои, и каждая панель помнит свои колонки. Наборы лежат в файле `columnsets.json` в папке настроек; если файла нет, он создаётся с наборами Minimal, Dates и Technical, после чего это обычные наборы: их можно менять, переименовывать и удалять. Чтобы сохранить текущий выбор, в диалоге «Свои колонки» (Опции, Колонки) введите имя в поле «Сохранить как набор колонок»; диалог правит колонки активной панели. В том же диалоге виден список наборов: «Правка» загружает выбранный набор в флажки и поле имени (OK сохраняет изменения под этим именем), «Переименовать» даёт выбранному набору имя из поля, «Удалить» убирает его.
