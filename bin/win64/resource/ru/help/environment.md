## Профили окружения

**Настройки → Профили окружения...** открывает файл `environment.json` в редакторе (при первом обращении он создаётся с примером). Профиль – именованный список записей `ИМЯ=значение`, которые накладываются на окружение каждой новой оболочки: вкладок-терминалов и консоли под панелями. Уже запущенные оболочки сохраняют своё окружение; оболочка, запущенная после сохранения файла, видит изменения.

```json
{
  "profiles": [
    { "name": "default", "vars": ["EDITOR=vim", "WORK=%TEMP%\\work", "OLD_VARIABLE="] },
    { "name": "proxy", "auto": false, "shells": ["pwsh"], "vars": ["HTTPS_PROXY=http://proxy:3128"] }
  ]
}
```

**Записи.** Профили применяются в порядке файла, записи – в порядке списка, поэтому следующая запись видит результат предыдущей. Запись с пустым значением (`OLD_VARIABLE=`) убирает переменную. `%ИМЯ%` заменяется текущим значением переменной во всех системах; в Linux и macOS работают также `$ИМЯ` и `${ИМЯ}`. Имя несуществующей переменной остаётся как написано. В Windows имена сравниваются без учёта регистра.

**Какие профили действуют на оболочку**
- `default` – действует на все оболочки, первым.
- `auto` (по умолчанию включено) – профиль применяется сам. При `"auto": false` – только к оболочке, которая его назначила (см. ниже).
- `shells` – профили оболочек, для которых предназначен профиль: `pwsh`, `wsl`, `wsl:Ubuntu`, идентификатор копии вроде `pwsh#2`. Короткое `wsl` охватывает и `wsl:Ubuntu`, а базовый идентификатор – его копии. Пусто или нет поля – все оболочки.
- `off` – `true` выключает профиль совсем, даже там, где он назначен.

<!--choice-->**Профиль для одной оболочки.** В списке оболочек (**Ctrl+Shift+N**) **F6** открывает выбор профиля окружения для выбранной оболочки или её копии. Такая оболочка запускается с `default` и выбранным профилем; `(нет)` возвращает автоматические профили. В списке только профили, которые не выключены и не называются `default`.

Файл входит в **экспорт и импорт настроек**.
