## 面板视图和排序

| 按键 | 作用 |
| --- | --- |
| Ctrl+\` | 列模式菜单 |
| Ctrl+Shift+F1 … F7 | 模式: 简要、大小、日期、完整、创建时间、类型、自定义 |
| Ctrl+F12 | 排序菜单 |
| Ctrl+F3 / F4 / F5 / F6 | 按名称 / 扩展名 / 修改日期 / 大小排序 |
| Ctrl+F7 / F8 / F9 | 不排序 / 按创建日期 / 按访问日期 |

再次选择同一种排序会反转方向。面板左上角的字母表示排序方式(大写 – 降序)。"自定义"模式的列在**选项 → 列...**中设置。按掩码设置行颜色 – **选项 → 颜色分组...**。
