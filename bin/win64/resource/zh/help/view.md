## 面板视图和排序

| 按键 | 作用 |
| --- | --- |
| Ctrl+\` | 列模式菜单 |
| Ctrl+Shift+F1 … F6 | 模式: 简要,或宽视图变体: 大小、日期、完整、创建时间、类型 |
| Ctrl+F12 | 排序菜单 |
| Ctrl+F3 / F4 / F5 / F6 | 按名称 / 扩展名 / 修改日期 / 大小排序 |
| Ctrl+F7 / F8 / F9 | 不排序 / 按创建日期 / 按访问日期 |

再次选择同一种排序会反转方向。面板左上角的字母表示排序方式(大写 – 降序)。面板有两种视图: **简要**(只显示名称,分多列; 列宽(10–50 个字符,默认 28; 面板容纳尽可能多的列)在**选项 → 列...**中设置(“简要视图”,所有面板相同),文件详情显示在状态栏)和**宽**(一列名称加所选的列; 菜单列出内置变体大小、日期、完整、创建时间和类型,然后是你自己的列集)。宽视图的列,包括插件添加的列(显示在插件名称之下),在**选项 → 列...**中设置; 对话框把它们保存为命名的列集。按掩码设置行颜色 – **选项 → 颜色分组...**。
