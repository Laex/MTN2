## 选择文件

| 按键 | 作用 |
| --- | --- |
| Ins | 选择 / 取消选择并下移 |
| Shift+方向键, Shift+Home/End/PgUp/PgDn | 随光标移动选择 |
| 小键盘 + / 小键盘 − | 按掩码选择 / 取消选择(`*.txt`, `a*.*`) |
| 小键盘 * | 反选 |
| Shift+小键盘 + | 选择所有文件 |
| Shift+小键盘 − | 取消选择所有文件 |
| Ctrl+小键盘 + / Ctrl+小键盘 − | 选择 / 取消选择与光标处文件扩展名相同的文件 |
| Alt+小键盘 + / Alt+小键盘 − | 选择 / 取消选择同名文件 |
| Ctrl+M | 恢复上次清除之前的选择(例如复制之后); 再按一次则换回 |

操作(复制、删除等)作用于已选项目,没有选择时作用于光标处的项目。

在按掩码选择的对话框中,"选择文件夹"复选框会把掩码同样应用到文件夹。
