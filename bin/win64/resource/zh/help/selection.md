## 选择文件

| 按键 | 作用 |
| --- | --- |
| Ins | 选择 / 取消选择并下移 |
| Shift+方向键, Shift+Home/End/PgUp/PgDn | 随光标移动选择 |
| Shift+小键盘 + | 选择所有文件 |
| Ctrl+M | 恢复上次清除之前的选择(例如复制之后); 再按一次则换回 |
| 小键盘 + / 小键盘 − | 按掩码选择 / 取消选择(`*.txt`, `a*.*`) |
| 小键盘 * | 反选 |
| Ctrl+小键盘 + / Ctrl+小键盘 − | 选择 / 取消选择与光标处文件扩展名相同的文件 |
| Shift+小键盘 − | 取消选择所有文件 |
| Alt+小键盘 + / Alt+小键盘 − | 选择 / 取消选择同名文件 |

在按掩码选择的对话框中,"选择文件夹"复选框会把掩码同样应用到文件夹。操作(复制、删除等)作用于已选项目,没有选择时作用于光标处的项目。

### 掩码组

<!--mask-groups-->同一栏中的多个掩码用 `;` 分隔(逗号也可以;文件夹同步对话框中的附加规则只认 `;`)。在任何掩码（选择、面板过滤、搜索、颜色组）中，`@名称` 表示一组命名的掩码，例如 `@Images` 或 `*.log;@Documents`。内置 Images、Audio、Video、Documents、Archives 和 Sources。自定义组通过“选项”菜单中的“掩码组...”管理（设置文件夹中的 `maskgroups.json`）；按掩码选择的对话框也可以把其掩码保存为组。在对话框的掩码字段中，Ctrl+G 会把输入的掩码保存为以第一个掩码命名的组，并在字段中填入 `@名称`。

### 列集

列模式菜单在预设模式之后列出已命名的列集。选择某个列集会让选择它的面板使用这些列; 另一个面板保持自己的列,每个面板各自记住自己的列。列集保存在设置文件夹的 `columnsets.json` 中; 文件不存在时会用 Minimal、Dates 和 Technical 三个列集创建,之后它们就是普通列集,可以修改、重命名或删除。要保存当前选择,请在自定义列对话框(选项,列)的“另存为列集”栏中输入名称,该对话框编辑活动面板的列。同一对话框列出各列集: 编辑 把所选列集载入复选框和名称栏(确定后以该名称保存修改),重命名 把栏中输入的名称赋给所选列集,删除 将其移除。
