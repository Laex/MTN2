## 更新

MTN2 可以自行更新: 它在 GitHub 上查找新版本,下载并安装,但只有在用户同意后才会进行。

### 更新流程

启动几秒后,每天一次,MTN2 会到 GitHub 检查新版本。如果有,它会询问: **更新**、**以后**或**跳过此版本**(被跳过的版本不会再次提示)。没有回答就不会下载或安装任何内容。

下载完成后(安装包会按 SHA-256 校验),MTN2 会提议现在**重启**或在**退出时**安装。复制任务运行期间,安装会等到退出。只会替换程序文件(包括随安装包提供的 `7z.dll`) – 设置和其他用户文件保持不变。

### 检查设置

**≡ → 检查更新...**(F9,然后选顶部菜单最左边的项目)显示已安装的版本,可立即检查(**立即检查**),并有两个复选框:

- **启动时检查更新** – 启动时每天一次。关闭后,MTN2 不会自行联网。
- **检查时显示通知** – 每次联网检查(启动时或点击**立即检查**)都会在右下角显示几秒钟的通知"正在 github.com 检查 MTN2 更新..."。

启动时的检查还会有第二行,说明如何关闭检查。即使其他弹出通知已关闭也会显示,GitHub 一回应它就会消失; 对话框打开期间它被隐藏在对话框下面。

### 通过网络发送的内容

检查只是向 `api.github.com` 发出一次 HTTPS 请求,获取 `Laex/MTN2` 仓库的最新版本。请求中只有 `User-Agent` 头里的 MTN2 版本 – 没有文件名、路径或设置。更新本身是点击**更新**后从 GitHub 下载的发布包。
