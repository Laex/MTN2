## 面板和导航

| 按键 | 作用 |
| --- | --- |
| ↑ ↓ PgUp PgDn Home End | 移动光标 |
| ← / → | 在简要模式下 – 向左 / 向右移动一列; 在其他模式下 – 到第一项 / 最后一项(同 Home / End) |
| Enter | 进入文件夹 / 压缩包,打开文件(按[文件关联](associations.md)); 控制台程序在内置控制台中运行(见下文) |
| Backspace | 上一级,相当于在 `..` 上按 Enter(命令行为空时; 否则在命令行中删除一个字符) |
| Ctrl+PgUp / Ctrl+PgDn | 上一级 / 进入光标处的文件夹,与 FAR 相同; 在文件上, Ctrl+PgDn 把它作为压缩包打开(见[压缩包](archives.md)) |
| Shift+Enter | 在单独的系统窗口中运行文件或命令 |
| Alt+Shift+Enter | 在后台运行命令行: 控制台短暂显示,然后面板回来 |
| Ctrl+Alt+Enter | 在新的终端标签页中运行命令行(使用后台控制台的 Shell) |
| Tab | 切换活动面板 |
| Ctrl+\\ | 转到驱动器根目录(在压缩包内 – 退出压缩包) |
| Alt+← / Alt+→ | 文件夹历史后退 / 前进 |
| Ctrl+U | 交换面板 |
| Ctrl+] | 非活动面板 := 活动面板的文件夹 |
| Ctrl+[ | 活动面板 := 非活动面板的文件夹 |
| Ctrl+F1 / Ctrl+F2 | 隐藏 / 显示左 / 右面板 |
| Ctrl+P | 隐藏 / 显示非活动面板 |
| Ctrl+L | 在另一侧显示信息面板(驱动器、内存) |
| Ctrl+H | 显示 / 隐藏隐藏文件和系统文件 |
| Ctrl+R | 刷新面板 |
| Ctrl+Q | 在另一个面板中快速查看文件: 图片、文本、Markdown 或十六进制 |
| Alt+F10 | 活动面板上方显示驱动器的文件夹树(见下文) |
| Alt+字母 | 在面板中按名称快速搜索 |

**文件夹树 (Alt+F10)** 在活动面板上方打开: 驱动器根目录,到当前文件夹的路径已展开,光标位于其上。↑ ↓ PgUp PgDn Home End 移动, → 或 `+` 展开分支(`[+]─`)或进入分支, ← 或 `-` 折叠分支(`[-]─`)或回到上级, 按字母跳到下一个以它开头的文件夹。光标停下后,另一个面板会转到光标处的文件夹。Enter 在活动面板中打开该文件夹并关闭文件夹树; Esc 或 Alt+F10 关闭文件夹树,同一个面板重新显示。Tab 或点击另一个面板会把焦点移到那里,文件夹树保留,就像 FAR 的树面板; Tab 或点击树的边框会把焦点带回来。用鼠标时,树起索引的作用: 点击文件夹会立即在另一个面板中显示它并把焦点移过去,点击 `[+]` / `[-]` 展开或折叠分支而不移动焦点; 鼠标滚轮滚动树而不移动光标。文件夹树还会跟随另一个面板: 当它转到另一个文件夹时,树会展开到该路径并把光标放在那里,换驱动器时会重新构建。文件夹在后台读取; 如果期间树下面的面板转到了别的文件夹,树会关闭。同一时间只能在一个面板上方打开文件夹树。

**快速查看 (Ctrl+Q)** 在另一个面板中显示光标处的文件: 图片、文本(自动检测编码)、渲染后的 Markdown 或二进制文件的十六进制转储; 大文件以流方式读取。鼠标滚轮可在其上滚动预览。SFTP 上的文件和压缩包内的大文件不会在每次移动光标时读取 – 面板会提示用 F3 打开它们。Tab 或再次按 Ctrl+Q 关闭快速查看。

**控制台程序**(控制台子系统的 `.exe`、`.bat`、`.cmd`、`.ps1`)按 Enter 运行,使其输出留在屏幕上,而不是在单独的 Windows 窗口中:
- 当后台控制台(Ctrl+O)的 Shell 是 cmd、PowerShell 或 pwsh 且其中没有运行任何内容时,在其中运行: 与在命令行中输入的命令相同;
- 其他情况(WSL、Git Bash 或 SSH 控制台,或者控制台正忙于其他命令) – 在使用 cmd 的新终端标签页中运行, `.ps1` 则使用 PowerShell; 程序结束后标签页保持打开。

勾选**在终端标签页中运行面板中的程序**(**命令 → 后台控制台...**)后,所有控制台程序都在终端标签页中运行,因此程序运行期间其他标签页仍可使用。从面板标签页启动的第一个程序会在其旁边打开一个终端标签页;后续程序在该标签页的 Shell 空闲且输入行为空时输入到其中(在文件所在文件夹),否则打开新标签页。该标签页的 Shell 有自己的环境配置(Shell 列表中按 **F6**)和自己的 Shell 历史。

窗口程序和文档仍用其 Windows 程序打开。**Shift+Enter** 仍然在单独的窗口中运行任何文件。

鼠标单击放置光标,双击相当于 Enter。可以用鼠标在面板之间以及向其他程序(和从其他程序)拖动文件。
