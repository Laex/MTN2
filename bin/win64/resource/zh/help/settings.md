## 设置

**选项**菜单 (F9):
- **主题...** – 选择外观; 立即生效。**自定义...**打开所选主题的编辑器: 分区(窗口、对话框、按钮、光标、面板等的颜色,以及 Markdown、文字样式、字符、边框)及其取值; 在某一行按 **Enter** 编辑取值(颜色可输入 `#RRGGBB`,或用 **F9** / **[...]** 按钮选取), **继承**会恢复基础主题的取值; 带星号的行由该主题自己设置。颜色可以是 `#RRGGBB` 值、对主题中另一角色的引用(`@cursor.bg`)或调色板中的名称。**基础主题**分区列出本主题所基于的主题(多个用 `;` 分隔,后面的覆盖前面的)。更改立即显示。**保存**把主题写入文件。内置主题是只读的: 内置主题的副本会以新名称保存(设置文件夹的 `themes` 文件夹中的一个文件),你自己的主题由**保存**就地更新,**另存为...**以另一个名称写入。**新建...**可以从零开始("空白")或基于任何其他主题创建主题。**删除**移除你自己的主题。如果已保存会话的主题找不到,程序会说明并使用经典的 Far 主题。
- **字体 / 显示...** – 字体、大小、缩放、光标闪烁、面板中的文件图标、**行距**(见下文)、弹出通知、**用鼠标拖动文件**(可以关闭)、**单按 Alt 键打开菜单**(可以关闭)、**窗口标题栏、菜单栏、功能键栏和状态栏**(隐藏的行会让给面板; 隐藏菜单栏后,菜单打开时 F9 会在顶行上方显示它; 隐藏窗口标题栏后, **[_] [□] [x]** 按钮移到菜单栏右端,如果菜单栏也隐藏则移到标签栏右端,窗口标题显示在标签栏的空白处,窗口可通过菜单栏和标签栏的空白部分拖动,通过边缘调整大小; 在标签栏空白处右击会打开顶部菜单,与 F9 相同)、窗口和按钮的**阴影**(经典、柔和或无; 对话框后面的变暗效果会随之减弱或取消)、**已标记文件**的外观("文字颜色" – 只有字母改变颜色,与 Far 相同; "行背景" – 整行还会有一条背景色带)以及**界面语言**(English / Русский / Deutsch / 简体中文); 所有这些都无需重启即可生效。同一对话框中的**"全选时包含文件夹"**复选框使 Shift+小键盘 + / Shift+小键盘 − 以及按扩展名选择也包含文件夹(默认只选文件,与 Far 相同)。
- **列...** – "自定义"模式的列。
- **控制台...** – 控制台和终端的回滚大小、粘贴多行时的确认、复制和粘贴时去掉行尾空格、从命令行运行的命令结束后返回面板(详见命令行帮助)。
- **导出设置... / 导入设置...** – 把设置存为一个 zip 文件: 会话和显示选项、按键、用户菜单、关联、常用文件夹、SSH 连接列表、工作区、自己的主题; 不含历史记录。文件名输入框带有 ↓ 下拉列表,列出以前用过的文件; 默认是活动面板文件夹中的 `mtn2-settings.zip`。导入前,被替换的文件会保存为设置文件夹中的 `settings-backup.zip`。新设置在 MTN2 重启后生效。
- **设置位置...** – 选择设置的存放位置: 用户文件夹(标准模式)或程序旁(便携模式,即 `portable.dat` 文件)。对话框显示两个位置、要移动的文件数,以及阻碍切换的原因: 程序文件夹无写入权限、程序文件夹为所有用户共用、目标处将被替换的文件(保留为 `*.before-switch`)。会话、历史记录、按键、插件设置和自己的主题一起移动,旧副本被删除; 更改立即生效,无需重启。出现任何错误时仍使用原来的位置。`resource\` 中的语言和随附主题始终留在程序旁。
- **颜色分组...** – 按名称掩码设置行颜色; 它们保存在主题中,因此使用内置主题时所做的编辑会保存为新主题(程序会询问其名称)。在颜色输入框上按 **F9**,或点击其右端的 **[...]** 按钮(它显示该输入框的颜色),会打开取色器(见下文)。
- **快捷键...** – 查看和更改按键。
- **插件...** – 已安装的插件。首次运行时所有插件都是关闭的。在某一行按**空格**可关闭或开启插件(`[x]` 为开启, `[ ]` 为关闭); 选择在按**确定**后生效并在多次运行之间保持,**取消**则放弃。**权限...**打开一个对话框: 允许插件替换内置处理程序(`[replaces .zip: on]`)以及其清单所请求的内容,例如通过程序读取文件(`[needs vfs.read: on]`)。**Ctrl+Up** 和 **Ctrl+Down** 改变插件的加载顺序(在优先级相同的插件之间有意义,下次启动时生效)。**信息**显示插件的用途和它增加的内容(命令、按键、文件类型、方案),如果有帮助页面则可打开。
- **外部查看器/编辑器...** – Alt+F3 / Alt+F4 命令; `%1` 是文件路径(没有 `%1` 时路径添加在末尾),例如 `"C:\Program Files\Notepad++\notepad++.exe" %1`。
- **Markdown 颜色...** – Markdown 视图(对 `.md` 文件按 F3)的颜色: 为每个元素 – 标题、粗体、斜体、删除线、代码、引用、列表标记、分隔线、链接、表格 – 设置前景色和背景色(`#RRGGBB`)以及**文字样式**(列表: 主题、常规、粗体、斜体、粗斜体、下划线、删除线及其组合)。输入框留空或样式列表选**主题**则保留主题自己的设置; **常规**会关闭该元素原有的样式(例如链接的下划线); 在输入框上按 **F9** 或点击其 **[...]** 按钮打开取色器。**正文 / 文档**一行设置整个 Markdown 视图的文字颜色和背景(仅用于 Markdown,其他文件保持主题颜色); 没有自己背景的元素跟随它。**从 Obsidian 导入...**从 Obsidian 主题(`theme.css`,例如 `<vault>\.obsidian\themes\<theme>\theme.css`)读取颜色; 在导入对话框中选择**深色**或**浅色**调色板,导入的颜色和文字样式(主题为标题、粗体、链接、引用和表头设置的粗细、斜体和下划线)会替换输入框和列表中的内容(按确定之前不会保存任何内容)。**重置**清空所有输入框并把每个样式设为**主题**,于是应用主题自己的颜色和样式。每一行旁边的示例用其颜色和样式绘制。保存在当前主题中: 使用内置主题时程序会询问新主题的名称,你自己的主题则就地更新; 输入框只保存主题自己设置的内容(其余继承)。
- **缩放**: Ctrl+鼠标滚轮, **Ctrl+0** – 重置。

### 取色器

取色器有一个色块网格(横向是色相,纵向从浅到深; 最下面一行是灰色)、滑块 **H、S、L**(色相、饱和度、亮度)和 **R、G、B**,以及一个 **Hex** 输入框,旁边有两个色块: 取色器打开时的颜色(**原来**)和**现在**的颜色。**上 / 下**在网格、滑块和十六进制输入框之间切换; **左 / 右**沿网格移动或把滑块改变 1(**Shift** – 改变 10, **PgUp / PgDn** – 改变 10, **Home / End** – 到两端)。网格使用当前饱和度,所以 **S** 滑块会让它更淡或更鲜艳。鼠标点击选取色块或设置滑块; 点击**原来**色块会回到原来的颜色。**使用**采用该颜色,**主题颜色**清空输入框,重新应用主题的颜色。

### 字体和行距

**选项 → 字体 / 显示...**中的**行距(与终端相同)**复选框会让行高增加字号的 15%; 文字在行内保持居中,边框和高亮会拉伸到整个行高。默认关闭: 行高与字体的行高相同,屏幕上能容纳更多行。对于 Cascadia Mono 11 pt,不加行距是 17 像素,加行距是 19 像素 – 与 Windows Terminal 相同。

字号使用印刷点数,与 Windows Terminal 和 Windows 控制台相同: 6 到 24 pt,在 8 到 12 pt 之间以半点为步长。在 Windows 缩放 100% 时 1 pt = 4/3 像素: 10.5 pt 是 14 像素(以前的默认值), 11 pt 是 14.7 像素。

同一对话框中还有两个让文字更清晰的选项:
- **字号对齐设备像素**把字母大小取整为整数个物理屏幕像素。在 Windows 缩放 125% 或 150% 且使用小数字号(11 pt)时,笔画粗细会因此一致。单元格大小可能会略有变化。默认关闭。
- **文字对比度**(关、低、中、高)会补足淡淡的抗锯齿边缘: 深色背景上细而浅的文字读起来更扎实。默认关闭。
- **单元格宽度**和**单元格高度**为每个单元格增加 0 到 4 个物理像素。它们对字母相互挨着或行距太紧的字体有帮助。字母在单元格内保持居中,边框会完全填满。默认为 0。

#### 为什么文字看起来和 Far 不同

Far 并不自己绘制文字: 绘制文字的是它所在的控制台窗口 – Windows Terminal 或经典的 Windows 控制台 – 使用其自己的字体和规则。在字体、大小和颜色相同的情况下, MTN2 和 Far 绘制的字母是一样的: 笔画粗细和抗锯齿一致。差异来自设置:
- **字体和大小。** Windows Terminal 默认使用 Cascadia Mono 11 pt。MTN2 使用"字体 / 显示"中的字体和大小(已安装则用 Cascadia Mono,否则用 Consolas; 10.5 pt)。 Ubuntu Mono 之类窄而细的字体看起来更细更淡,在蓝色背景上尤其如此。
- **行高。** Windows Terminal 在字体行高之外增加约 15% 的字号。在 MTN2 中这对应"行距"复选框; 不勾选时行更紧。经典 Windows 控制台根据字体的 Windows 度量取行高,可能再高 1–3 像素(Cascadia Mono 11 pt – 20 像素)。
- **颜色。** MTN2 的颜色来自其主题; Far 的来自自己的高亮和终端的配色方案。在默认主题中,普通文件是浅灰色; 在 Far 中通常是青色,在蓝色背景上对比度是两倍,所以文字看起来更粗。
- **抗锯齿。** MTN2 使用灰度抗锯齿。Windows Terminal 在配置的 `antialiasingMode` 为 `grayscale`(默认)时也是如此; 使用 `cleartype` 时字母会有彩色边缘。经典 Windows 控制台在 Windows 中开启 ClearType 时使用它。
- **Windows 缩放。**两者都以物理屏幕像素绘制文字,因此在 125% 和 150% 下同样清晰。

#### 何时一致

在以下情况下, MTN2 与 Windows Terminal 中的 Far 在单元格大小、笔画粗细和行高上一致:
- 字体相同(Windows Terminal 默认是 Cascadia Mono);
- 大小相同(Windows Terminal 默认是 11 pt);
- 开启了行距(与终端相同);
- Windows Terminal 配置使用 `grayscale` 抗锯齿;
- MTN2 的主题与 Far 的颜色相近。

对于经典 Windows 控制台(不使用 Windows Terminal 的 Far),两者不会完全一致: 它的行高和 ClearType 是它自己的。

### 通知

不会改变屏幕内容的命令会在右下角用简短通知自我确认; 它几秒后消失,不会占用按键。以下情况会出现通知:
- **Alt+Shift+Ins** / **Ctrl+Shift+Ins** – 已复制的路径 / 名称(或"没有可复制的内容");
- 在面板上按 **Ctrl+C** / **Ctrl+X**(**Ctrl+Ins** / **Ctrl+Del**) – 已放入剪贴板的文件;
- 在查看器 / 编辑器(没有选区时为当前行)、命令行和终端中复制文本;
- **Ctrl+R** – 面板已刷新;
- **Ctrl+Shift+O** – 控制台所转到的文件夹;
- **Ctrl+Alt+R** – 从回收站还原的项目;
- **Ctrl+Alt+D** – 添加到常用文件夹的文件夹;
- 按掩码选择(**小键盘 +/−**、**Ctrl+小键盘 +/−**、**Alt+小键盘 +/−**)没有改变任何内容时 – 以红色显示。

通知可在**选项 → 字体 / 显示...**("显示弹出通知")中关闭。检查更新的通知是个例外: 它有自己的复选框(见[更新](updates.md))。
