## 命令行和控制台

命令行始终在面板下方: 直接开始输入即可。命令在内置控制台中运行; 用 **Ctrl+O** 查看其输出。

| 按键 | 作用 |
| --- | --- |
| Enter | 运行命令; 输入的文件夹路径会转到该文件夹,文件(包括用 Ctrl+Enter 放到命令行里的名称)会被运行: 控制台程序在内置控制台中运行,其他程序用其 Windows 程序运行。之后焦点回到面板,方向键又可以移动光标 |
| Alt+Shift+Enter | 在后台运行命令行: 控制台会短暂显示开始运行,然后面板回来(见下面的**选项 → 控制台...**) |
| Ctrl+Alt+Enter | 在新的终端标签页中运行命令行: 新建一个使用后台控制台 Shell(cmd、PowerShell、WSL 等)的工作区标签页,命令在其中启动,标签页保持打开 |
| Tab | 补全: 面板中的名称,或当词中含有 `\`、`/` 或 `X:` 时补全磁盘上的路径(重复按键会在匹配项之间循环) |
| Ctrl+Enter | 插入光标处项目的名称 |
| Ctrl+F, Ctrl+Shift+Enter | 插入项目的完整路径 |
| Ctrl+↓ / Ctrl+↑ | 聚焦命令行 / 返回面板 |
| ↑ / ↓(输入命令时) | 命令历史 |
| Ctrl+↓ / Alt+↓(焦点在命令行时) | 以列表形式显示命令历史: Enter – 放到命令行, Del – 从历史中删除, Esc – 关闭 |
| Esc | 逐步执行: 清除命令行 → 把焦点交还面板 → 显示控制台。命令行为空时跳过第一步; 焦点在面板上时, Esc 直接显示控制台 |
| Ctrl+O | 面板 ↔ 控制台 |
| Ctrl+Shift+O | 同步活动面板和控制台之间的文件夹 |
| Ctrl+Alt+O | 选择后台控制台的 Shell(cmd、PowerShell、WSL 等) |

**命令 → 后台控制台...**是同一个对话框。**程序启动时启动 Shell**默认关闭: Shell 在第一次按 **Ctrl+O** 或第一次从命令行运行命令时启动。开启此选项则像以前一样,Shell 与程序一起启动。

**在控制台中:** **Ctrl+C** 中断命令; **Esc** 只隐藏控制台,不会停止进程。鼠标滚轮滚动输出。文本用鼠标选择(见[文本和鼠标操作](text.md))。在使用 cmd 的控制台中, **↑** / **↓** 翻阅共享命令历史(同 Alt+F8),在最新命令之后按 **↓** 会恢复已输入的行。

**粘贴到控制台**(**Ctrl+V**, **Shift+Ins**): 每个换行都会作为 Enter 发送给 Shell,因此粘贴的各行会依次运行,最后一行也一样。开启**粘贴多行时确认**后,程序会先询问。

**搜索输出**(控制台和终端): **Ctrl+Shift+F** 询问要查找的文字; 匹配项在整个历史中高亮,当前匹配项像鼠标选择一样被选中。**F3** / **Shift+F3** 跳到下一个 / 上一个匹配项(循环),前提是已设置搜索且窗口中没有运行全屏程序; 在对话框中输入空字符串可清除搜索。

**命令 → 保存控制台输出...**把后台控制台(Ctrl+O)的回滚内容写入 UTF-8 文本文件; **清空控制台缓冲区**会擦除它,Shell 继续运行。

**选项 → 控制台...**设置控制台和终端的回滚大小(1000 – 50,000 行,默认 10,000)、粘贴多行时的确认(默认关闭; vim 等全屏程序从不询问)、复制和粘贴时去掉行尾空格,以及**命令结束后总是返回面板**(默认关闭)。开启后,从面板下方命令行运行的命令,在 Shell 重新显示提示符时会立即带你回到面板; 在后台控制台(Ctrl+O)中输入的命令则始终留在控制台。

**Alt+Shift+Enter** 在后台运行控制台中的命令行: 控制台会按**后台运行**中设置的时间显示(0.5 – 10 秒,默认 2 秒),然后面板自动回来; 在此之前如果在控制台中按了键,它会保持在前台,命令无论如何都会继续运行。更改立即生效,对已打开的控制台也一样。
