## 文本和鼠标操作

在查看器和编辑器、命令行、对话框输入框和控制台中都相同。

**单词**由任意文字的字母、数字和 `_` 组成。其余字符 – 空格、标点、`\`、`/`、`.`、`:` – 都是**分隔符**。

| 操作 | 结果 |
| --- | --- |
| Ctrl+← / Ctrl+→ | 到单词开头 / 到单词末尾(直到下一个分隔符) |
| Ctrl+Shift+← / Ctrl+Shift+→ | 同上并选择; 往回走会取消选择已经越过的部分 |
| Shift+方向键, Shift+Home/End | 选择 |
| 单击 | 放置光标 |
| 双击 | 选择单词(在分隔符上则选择一串相同的字符) |
| 紧接着再快速点击 | 选择整行 |
| Shift+点击 | 把选区扩展或缩小到点击处 |
| 鼠标拖动 | 选择(查看器、编辑器、控制台) |
| Alt+鼠标拖动 | 矩形块(查看器、编辑器) |
| Ctrl+C / Ctrl+Ins, Ctrl+X / Shift+Del, Ctrl+V / Shift+Ins | 剪贴板 |
| Ctrl+A | 全选 |

在面板中,命令行不为空时,Ctrl+Shift+←/→ 作用于命令行。

<!--mouse-->**文本终端版本(mtn2-tui)。**程序向终端请求鼠标,因此拖动在 MTN2 内部选择文本,文本通过终端进入剪贴板(这是一条转义序列,有些终端(如默认设置的 PuTTY)会忽略它;在 tmux 中和桌面环境下,MTN2 还会写入 tmux 缓冲区和系统剪贴板)。要用终端自己的选择,拖动时按住 **Shift**,或用 **Ctrl+Shift+M** 关闭鼠标(**选项 → 终端鼠标 开/关**);同一个键再次开启。`--no-mouse` 选项让程序以关闭鼠标的状态启动。

**输入历史。**右端带 **↓** 的输入框(选择掩码、文件搜索的掩码和文本、复制/移动的目标和排除项、链接目标、新建文件夹和文件、编辑器的查找和替换、用户菜单提示)会记住最近的 20 个值。**Ctrl+↓** / **Alt+↓** 或点击箭头会展开列表: **Enter** – 使用该项, **Del** – 从历史中删除, **Esc** – 关闭列表。对话框被确认时,值会被加入历史。
