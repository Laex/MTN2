## 文件操作

| 按键 | 作用 |
| --- | --- |
| F3 | 查看文件; 在文件夹上 – 计算所选文件夹的大小(Esc – 取消) |
| F4 | 编辑 |
| Shift+F4 | 新建文件 |
| F5 | 复制 |
| Shift+F5 | 在同一文件夹中以另一个名称复制 |
| F6 | 移动 / 重命名 |
| Shift+F6 | 重命名光标处的项目 |
| F7 | 新建文件夹 |
| Alt+F6 | 创建链接(符号链接、硬链接、联接点) |
| F8, Del | 删除到回收站 |
| Shift+F8, Shift+Del | 永久删除(擦除) |
| Ctrl+A | 属性、所有者和日期(创建 / 修改 / 访问) |
| Alt+Enter | Windows"属性"窗口(针对所选项目或光标处的项目; 仅限磁盘上的文件和文件夹) |
| Shift+F10, 菜单键 | Windows 右键菜单(针对所选项目或光标处的项目) |
| Ctrl+Alt+C | 比较两个面板光标所在的文件 |
| Ctrl+Alt+H | 所选文件和文件夹的校验和(MD5、SHA-1、SHA-256、SHA-512); 在 `.md5` / `.sha1` / `.sha256` / `.sha512` 文件上 – 校验它 |
| Ctrl+Alt+M | 批量重命名选中的项目:名称与扩展名掩码、计数器、查找替换、字母大小写 |
| Ctrl+C / Ctrl+X / Ctrl+V | 通过剪贴板复制 / 剪切 / 粘贴文件 |
| Alt+Shift+Ins | 把完整路径复制到剪贴板 |
| Ctrl+Shift+Ins | 只把名称(不含路径)复制到剪贴板 |
| Ctrl+Z | 文件说明: 一个输入行,文字保存在文件旁边的 `Descript.ion` 中 |

**Alt+Shift+Ins** 和 **Ctrl+Shift+Ins** 取所选项目(每行一个),没有选择时取光标处的项目; 在 `..` 上则取当前文件夹。结果可用 **Shift+Ins** / **Ctrl+V** 粘贴到任何地方。右下角会有一条简短通知确认复制(或说明没有可复制的内容); 可以在**选项 → 字体 / 显示...**中关闭。

**文件 → 导出列表...** 把所选项目(没有选择时为光标处的项目)保存到文件。对话框中可设置文件名、格式 – 按扩展名(`.md` 为 Markdown 表格,`.csv` 为 CSV,其他为对齐的文本)、纯文本、Markdown 或 CSV – 以及字段: 名称、完整路径、扩展名、大小、修改 / 创建 / 访问日期、类型和属性。标题行可以关闭(Markdown 表格始终有标题行)。文件夹的大小处显示 `<DIR>`。所选设置在重启后保留; 该菜单项没有默认快捷键,可在按键设置对话框中分配(动作 `ExportList`)。

在 **Ctrl+A** 对话框中,日期按系统日期格式输入,时间格式为 `hh:mm:ss`(秒和时间部分可省略)。输入框留空则保持原日期: 所选文件的日期不同时就这样显示。**当前**会把当前时间填入三个输入框,**原始**恢复从文件读取的值。"包含子文件夹"同样适用于日期。

同一对话框还包含文件的其他标志: **已压缩**、**已加密**、**不索引**、**稀疏**、**临时**和**脱机**(每项: 保持 / 设置 / 清除; 压缩、加密和稀疏标志由文件系统执行,不支持的卷会报错)。对于驱动器根目录(在 **Alt+F1** / **Alt+F2** 驱动器列表中按 **F4**),顶部显示卷(GUID 路径)和设备; **系统属性**按钮打开 Windows 属性窗口。

**Windows 右键菜单** – 与在资源管理器中右键点击相同的菜单: "打开方式"、"发送到"、压缩软件、杀毒软件和版本控制项目等。用 **Shift+F10** 或**菜单键**在光标行打开,也可通过**文件 → Windows 右键菜单**,或在文件上按住鼠标右键约一秒。用键盘和菜单打开时,它作用于所选项目,没有选择时作用于光标处的项目(在 `..` 上 – 作用于当前文件夹); 按住鼠标键则打开鼠标下文件的菜单。仅限磁盘上的文件和文件夹: 压缩包、SFTP、回收站和搜索结果没有 Windows 菜单。

复制/移动对话框可让你保留所有时间戳、只复制较新的文件、复制符号链接的内容并设置排除掩码。出现名称冲突时,程序会询问如何处理(覆盖、跳过、重命名,可应用于全部…)。

**校验和。**它们在后台计算(Esc – 取消)。在结果列表中: **复制** – 到剪贴板, **保存** – 到 `<文件>.sha256`(单个文件)或面板文件夹中的 `checksums.sha256`。校验会把每一行标记为 `OK`、`FAILED` 或 `MISSING`。可识别 `hash *name`、`hash  name` 和 `SHA256 (name) = hash` 这几种行。

**批量重命名。**名称和扩展名掩码支持 `[N]`(原名称,不含扩展名)、`[E]`(原扩展名)和 `[C]`(计数器,可设置起始值、步长和位数);其他文本原样保留。“查找”和“替换”作用于新的名称和扩展名,字母大小写从列表中选择。字段下方的列表即时显示“原名 -> 新名”。名称为空、无效、重复或在文件夹中已存在(包括选中的其他项目)时以 `!` 标记,仍有此类名称时 **重命名** 不会执行。只能选择同一文件夹中的项目。重命名与移动一样作为后台任务运行。

**受保护的文件夹。**当本地路径上的复制、移动、删除、新建文件夹或重命名因"拒绝访问"失败时(例如在 `C:\Program Files` 中),错误窗口会提供**管理员**按钮,而新建文件夹和重命名会询问"以管理员身份重试?"。确认后 Windows 会显示通常的 UAC 提示,MTN2 启动一个具有管理员权限的小型助手进程; 失败的项目和任务的其余部分在其中运行,使用相同的进度和错误窗口。在你确认之前,不会以这些权限运行任何内容。助手运行期间,窗口标题显示 **[管理员助手]** 并有通知说明; 它在两分钟没有工作后会自行结束,或在 MTN2 关闭时结束。助手只在本地路径上复制、移动、删除、创建文件夹和保存文本: 它不能启动程序,而且只有启动它的那个 MTN2 能与它通信。压缩包和虚拟文件夹没有这一步。如果 MTN2 本身以管理员身份启动(右键,以管理员身份运行),标题显示 **[管理员]**,不需要助手; 此时 Windows 会阻止来自资源管理器等非提权程序的拖放。
