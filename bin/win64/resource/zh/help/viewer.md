## 查看和编辑文件

**F3** – 查看, **F4** – 编辑, **F6** – 在查看器 ↔ 编辑器之间切换,无需关闭文件。

**Alt+F3** / **Alt+F4** – 用外部查看器 / 编辑器打开光标处的文件。命令在**选项 → 外部查看器/编辑器...**中设置; 未设置时, Alt+F3 用文件对应的 Windows 程序打开, Alt+F4 使用 Windows 的"编辑"命令,没有则使用记事本。仅限磁盘上的文件。

| 按键 | 作用 |
| --- | --- |
| F7, Ctrl+F(在查看器中还有 `/`) | 搜索对话框(见下文) |
| Shift+F7 / Alt+F7, F3 / Shift+F3 | 下一个 / 上一个匹配(开启**反向搜索**时,两者互换) |
| Ctrl+F7 | 查找和替换(编辑器): 选项和按钮相同,另有**替换**和**全部** |
| Alt+F8 | 转到行 |
| F8 | 下一种编码; Shift+F8 – 选择编码 |
| F4(在查看器中), Ctrl+H | 十六进制模式(编辑器的十六进制模式下可以编辑字节) |
| Ctrl+M | Markdown: 渲染视图 ↔ 源文本 |
| Tab / Shift+Tab | Markdown: 下一个 / 上一个链接 |
| Enter,点击链接 | Markdown: 确认后用默认应用程序打开外部链接(`https://…`、`mailto:…`) |
| F2 | 保存(编辑器) / 自动换行(查看器; 与位置一起按文件记住) |
| Ctrl+S | 保存 |
| Ctrl+Z / Ctrl+Shift+Z | 撤销 / 重做 |
| Ctrl+Y, Ctrl+D | 删除行 |
| Ctrl+K | 删除到行尾 |
| Ctrl+N | 在下方插入空行 |
| Ctrl+Alt+S / Ctrl+Alt+Shift+S | 按升序 / 降序排序选中的行(无选择时为整个文件) |
| Ctrl+Alt+U | 删除重复行 |
| Ctrl+Alt+F | 按指定宽度重排文本(段落以空行分隔) |
| Alt+→ / Alt+← | 将选中的行(无选择时为当前行)右移 / 左移 |
| Alt+Shift+方向键(及 Home / End / PgUp / PgDn), Alt+鼠标 | 选择矩形块 – 若干行的相同列; Del、Backspace、输入文字和 Ctrl+X / Ctrl+C / Ctrl+V 作用于块的每一行,复制的块按块粘贴 |
| Enter(编辑器) | 新行以其所续行的缩进开头(光标左侧的空白); 该模式可用 **Ctrl+Alt+I**、“编辑”菜单和设置(字体 / 显示)开关 |
| Ctrl+F2 | 设置 / 清除光标所在行的书签(该行在左侧边框中标有 ■) |
| Ctrl+Shift+F2 / Ctrl+Alt+F2 | 跳到下一个 / 上一个书签(循环) |
| Ctrl+Alt+B | 书签列表(行号和文字): 按 Enter 跳到所选书签 |
| Ctrl+Home / Ctrl+End | 到文件开头 / 末尾 |
| Ctrl+C / Ctrl+X / Ctrl+V | 复制(没有选区时复制整行) / 剪切 / 粘贴 |
| Esc, F10(在查看器中还有小键盘 5) | 关闭 |

大文件以流方式读取,不会整个加载。如果文件在磁盘上发生变化,打开的窗口会更新。对于只读文件,程序会提议清除属性后以可写方式打开。

**搜索对话框。**输入框会保留之前的搜索(**Ctrl+↓** / **Alt+↓**); 选项有**区分大小写**、**全字匹配**、**正则表达式**和**反向搜索**。**单词**把光标处的单词放入输入框, **选区**放入所选内容(没有选区时放入当前行; 多行选区则放入第一行)。开启**正则表达式**时,这两个按钮放入的文本会被转义。找到的匹配项会被选中, **F3** / **Shift+F3** 从它继续。匹配不会跨越换行。使用**正则表达式**时,模式是 PCRE 表达式,替换文本中 `$0` 表示整个匹配, `$1` ... `$9` 表示分组, `$$` 表示美元符号; 不使用该选项时,替换文本按原样使用。无法编译的模式会被报告,并且不进行搜索。替换对话框中的**替换**逐个处理匹配项: 每一项都会被选中显示,并显示文本、其替换结果和所在的行,可回答**替换**(替换并转到下一个)、**全部**(不再询问,替换其余全部)、**跳过**或**取消**。到达文本末尾而搜索是从中间开始的时,会提议从开头继续(反向搜索时从末尾继续)。替换对话框中的**全部**一次性替换整个文本中的所有匹配。两种方式都会在**全部**结束时显示替换了多少处,都可以用一次 **Ctrl+Z** 撤销,并把光标放回替换前的位置。区分大小写、全字匹配和正则表达式会在多次运行之间被记住; **反向搜索**只在 MTN2 关闭前有效。
