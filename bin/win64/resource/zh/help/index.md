## MTN2 – 用户指南

Modern Terminal Navigator 2 是一款双面板文件管理器,风格类似 NDN / FAR Manager,内置控制台、终端、查看器和编辑器。

文中的按键均为内置配置下的按键;你可以重新定义它们(见[快捷键](keymap.md))。

### 使用帮助

| 按键 | 作用 |
| --- | --- |
| Tab / Shift+Tab | 下一个 / 上一个链接 |
| Enter,点击链接 | 打开链接 |
| Backspace, Alt+← | 返回 |
| F1 | 本页(目录) |
| F7, Shift+F7 / Alt+F7 | 搜索文本,下一个 / 上一个匹配 |
| ↑ ↓ PgUp PgDn Home End | 滚动 |
| Esc, F10 | 关闭帮助 |
