## 搜索和过滤

| 按键 | 作用 |
| --- | --- |
| Alt+F7 | 查找文件(掩码、内容、子文件夹、区分大小写、全字匹配、正则表达式) |
| Alt+字母 | 按名称快速搜索 |
| Ctrl+I | 面板过滤: 对话框中有现成的过滤器列表和输入自定义掩码的行; 按 Enter 或双击列表项应用过滤, "清除"取消过滤 |
| Ctrl+B | 平铺视图: 子树中的所有文件显示在同一个列表中 |

搜索进行中按 Esc 会询问"停止搜索?": **停止**结束搜索, **继续**(Esc)让搜索继续运行。

搜索结果以面板形式打开,常规操作都可以对它们使用。
