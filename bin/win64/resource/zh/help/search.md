## 搜索和过滤

| 按键 | 作用 |
| --- | --- |
| Alt+F7 | 查找文件(掩码、内容、子文件夹、区分大小写、全字匹配、正则表达式) |
| Ctrl+I | 面板过滤: 对话框中有现成的过滤器列表和输入自定义掩码的行; 按 Enter 或双击列表项应用过滤, "清除"取消过滤 |
| Ctrl+B | 平铺视图: 子树中的所有文件显示在同一个列表中 |
| Alt+字母 | 按名称快速搜索 |

### 通过插件搜索

Everything 插件根据其索引回答本地文件夹中的名称搜索,ripgrep 插件(PATH 中或插件旁边的 `rg`)搜索文件文本,文档查看插件让文本搜索也能查看 `.docx`、`.xlsx`、`.pptx`、`.pdf`、`.svg` 和 SQLite 文件。压缩包内、按十六进制字节或按属性的搜索使用内置搜索。带有选择性掩码的文本搜索以流水线方式运行: 第一阶段按名称列出文件(Everything 或内置遍历),第二阶段在其中查找文本(ripgrep 或内置检查)。查找对话框的 **流水线** 按钮会打开一个对话框,每个阶段一个列表: **自动** 选择最合适的插件,**内置** 使用内置代码,也可以按名称选择某个插件; 该插件无法处理该阶段时,运行内置代码。

### 快速搜索

Alt+字母 在活动面板中打开搜索框; 继续输入的字母会加入其中,光标移到名称以所输入文本开头的第一个文件。Backspace 删除最后一个字符,Esc 关闭搜索框,Enter 打开光标所在的文件。上、下键移到相邻文件; 其他任何按键或 Ctrl 组合键会关闭搜索并照常执行。

选项(设置 – 界面):

- **松开 Alt 后保持快速搜索打开** – 搜索框保持打开,直到按 Esc 或 Enter;
- **保持空的快速搜索打开** – 空搜索框不会因 Backspace 而关闭;
- **快速搜索同时过滤面板** – 除光标外,面板中只保留匹配的文件; 松开 Alt 后搜索框保持打开,Esc 或 Enter 让所有文件恢复,光标留在同一个文件上;
- **在其他文件夹中保留快速搜索过滤** – 对文件夹按 Enter 或单击会把过滤带入新文件夹,之后只有 Esc 才能取消;
- **模糊快速搜索过滤** – 名称中按顺序包含所输入字母(不必相邻)的也匹配(`mnr` 能找到 `main_readme.txt`); 光标移到开头匹配的文件,否则移到列表中的第一个。

搜索结果以面板形式打开,常规操作都可以对它们使用。

搜索进行中按 Esc 会询问"停止搜索?": **停止**结束搜索, **继续**(Esc)让搜索继续运行。
