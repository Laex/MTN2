# Настройки

Меню **Настройки** (F9):

- **Тема...** — оформление; меняется сразу.
- **Шрифт / экран...** — шрифт, кегль, масштаб, мигание курсора, значки файлов в панели, **межстрочный интервал** (см. ниже), всплывающие уведомления, **тени** окон и кнопок («Классические», «Мягкие» или «Нет»; вместе с ними ослабляется или пропадает затемнение фона под диалогом) и **язык интерфейса** (English / Русский); всё применяется без перезапуска.
- **Колонки...** — состав колонок режима «Свой».
- **Цветовая разметка...** — цвета строк по маскам имён.
- **Раскладка клавиш...** — просмотр и изменение клавиш.
- **Плагины...** — установленные плагины.
- **Внешний просмотрщик/редактор...** — команды для Alt+F3 / Alt+F4; `%1` — путь к файлу (без `%1` путь дописывается в конец), например `"C:\Program Files\Notepad++\notepad++.exe" %1`.
- **Масштаб**: Ctrl+колесо мыши, **Ctrl+0** — сброс.

## Шрифт и межстрочный интервал

Флажок **«Межстрочный интервал (как в терминале)»** в **Настройки → Шрифт / экран...** делает строки выше на 15% кегля; текст остаётся по центру строки, рамки и выделение растягиваются на всю её высоту. По умолчанию флажок снят: строки высотой в строку шрифта, и на экране помещается больше строк. Для Cascadia Mono 11 пт это 17 пикселей без интервала и 19 с интервалом — столько же, сколько в Windows Terminal.

Кегль задаётся в типографских пунктах, как в Windows Terminal и консоли Windows: от 6 до 24 пт, от 8 до 12 пт — с шагом 0,5. При масштабе Windows 100% 1 пт = 4/3 пикселя: 10,5 пт — 14 пикселей (прежний размер по умолчанию), 11 пт — 14,7 пикселя.

### Почему текст выглядит не так, как в Far

Far сам текст не рисует: это делает окно консоли, в котором он запущен, — Windows Terminal или классическая консоль Windows — своим шрифтом и по своим правилам. Если сравнить MTN2 и Far с одинаковыми шрифтом, кеглем и цветами, начертание совпадает: толщина штрихов и сглаживание одни и те же. Различия дают настройки:

- **Шрифт и кегль.** В Windows Terminal по умолчанию Cascadia Mono 11 пт. В MTN2 — шрифт и кегль из «Шрифт / экран» (по умолчанию Cascadia Mono, если он установлен, иначе Consolas; кегль 10,5 пт). Узкие и светлые шрифты, например Ubuntu Mono, выглядят тоньше и бледнее, особенно на синем фоне.
- **Высота строки.** Windows Terminal добавляет к строке шрифта около 15% кегля. В MTN2 это делает флажок «Межстрочный интервал»; без него строки плотнее. Классическая консоль Windows берёт высоту строки из метрик шрифта Windows, и она бывает ещё на 1–3 пикселя выше (Cascadia Mono 11 пт — 20 пикселей).
- **Цвета.** Цвета задаёт тема MTN2, а в Far — его собственная раскраска и цветовая схема терминала. В теме по умолчанию обычные файлы светло-серые, в Far — обычно бирюзовые; у бирюзового на синем контраст вдвое выше, и текст кажется жирнее.
- **Сглаживание.** MTN2 сглаживает текст оттенками серого. Windows Terminal делает так же, если в профиле `antialiasingMode` = `grayscale` (как по умолчанию); с `cleartype` у букв появляется цветная кайма. Классическая консоль Windows использует ClearType, если он включён в Windows.
- **Масштаб Windows.** Оба рисуют текст в физических пикселях экрана, поэтому при 125% и 150% чёткость одинаковая.

### Когда совпадает

Текст MTN2 совпадает с Far в Windows Terminal по размеру клетки, толщине штрихов и высоте строки, если:

- выбран тот же шрифт (для Windows Terminal по умолчанию — Cascadia Mono);
- тот же кегль (для Windows Terminal по умолчанию — 11 пт);
- включён «Межстрочный интервал (как в терминале)»;
- в профиле Windows Terminal сглаживание `grayscale`;
- цвета темы MTN2 и Far близки.

С классической консолью Windows (Far без Windows Terminal) полного совпадения не будет: высота строки и ClearType там свои.

## Уведомления

Команды, после которых на экране ничего не меняется, подтверждают себя коротким уведомлением в правом нижнем углу; оно исчезает через несколько секунд и не перехватывает клавиши. Уведомления появляются для:

- **Ctrl+Alt+Ins** / **Alt+Shift+Ins** — скопированный путь / имя (или «Нечего копировать»);
- **Ctrl+C** / **Ctrl+X** (**Ctrl+Ins** / **Ctrl+Del**) на панели — файлы, помещённые в буфер обмена;
- копирования текста в просмотрщике / редакторе (без выделения — текущая строка), в командной строке и в терминале;
- **Ctrl+R** — панель обновлена;
- **Ctrl+Shift+O** — папка, в которую перешла консоль;
- **Ctrl+Alt+R** — элемент, восстановленный из корзины;
- **Ctrl+Alt+D** — папка, добавленная в избранные;
- выделения по маске (**серый +/−**, **Ctrl+серый +/−**, **Alt+серый +/−**), которое ничего не изменило, — красным.

Уведомления отключаются в **Настройки → Шрифт / экран...** («Показывать всплывающие уведомления»). Исключение — уведомление о проверке обновлений: у него свой флажок (см. раздел «Обновления» ниже).

## Обновления

Через несколько секунд после запуска MTN2 раз в сутки проверяет на GitHub, не вышла ли новая версия. Если вышла, программа спрашивает: **Обновить**, **Позже** или **Пропустить версию** (о пропущенной версии больше не напомнит). Без вашего согласия ничего не скачивается и не устанавливается.

После загрузки (архив проверяется по контрольной сумме SHA-256) предлагается **Перезапустить** сейчас или установить обновление **При выходе**. Если идут фоновые копирования, установка откладывается до выхода. Заменяются только файлы программы — настройки, `7z.dll` и другие ваши файлы остаются как есть.

Меню **≡ → Обновления...** показывает установленную версию, включает и выключает проверку при запуске и проверяет обновления сразу.

Когда проверка при запуске выходит в сеть, в правом нижнем углу на несколько секунд появляется уведомление «Проверка обновлений MTN2 на github.com...» с подсказкой, как её отключить. Оно показывается, даже если остальные уведомления выключены; убрать его можно флажком «Показывать уведомление о проверке» в том же диалоге.

Проверка — это один HTTPS-запрос к `api.github.com` за описанием последнего выпуска репозитория `Laex/MTN2`. В запросе нет ничего, кроме версии MTN2 в заголовке `User-Agent`: ни имён файлов, ни путей, ни настроек. Если снять «Проверять обновления при запуске», MTN2 сам в сеть не выходит.
