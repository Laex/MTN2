## Панели и навигация

| Клавиша | Действие |
| --- | --- |
| ↑ ↓ PgUp PgDn Home End | перемещение курсора |
| ← / → | в режиме «Кратко» – на колонку влево / вправо, в остальных режимах – в начало / конец списка (как Home / End) |
| Enter | войти в папку / архив, открыть файл (по [ассоциации](associations.md)); консольную программу – запустить во встроенной консоли (см. ниже) |
| Backspace | на уровень выше, как Enter на `..` (при пустой командной строке; иначе стирает символ в ней) |
| Shift+Enter | запустить файл или команду в отдельном окне ОС |
| Tab | переключить активную панель |
| Ctrl+\\ | в корень диска (из архива – выйти из архива) |
| Alt+← / Alt+→ | назад / вперёд по истории папок |
| Ctrl+U | поменять панели местами |
| Ctrl+] | пассивная панель := папка активной |
| Ctrl+[ | активная панель := папка пассивной |
| Ctrl+F1 / Ctrl+F2 | скрыть / показать левую / правую панель |
| Ctrl+L | информационная панель (диск, память) на соседней стороне |
| Ctrl+H | показать / скрыть скрытые и системные файлы |
| Ctrl+R | обновить панель |
| Ctrl+Q | быстрый просмотр файла на соседней панели: картинка, текст, Markdown или hex |
| Alt+F10 | дерево папок диска поверх активной панели (см. ниже) |
| Alt+буква | быстрый поиск по имени в панели |

**Дерево папок (Alt+F10)** открывается поверх активной панели: корень диска, путь к текущей папке раскрыт, курсор на ней. ↑ ↓ PgUp PgDn Home End – перемещение, → или `+` – раскрыть ветку (`[+]`) или войти в неё, ← или `-` – свернуть ветку (`[-]`) или подняться к родителю, буква – к следующей папке на эту букву. Соседняя панель переходит в папку под курсором, когда курсор остановился. Enter открывает папку в активной панели и закрывает дерево, Esc или Alt+F10 закрывают дерево, и под ним снова видна та же панель. Tab или щелчок по другой панели переводят в неё фокус, а дерево остаётся на месте, как панель дерева в Far; Tab или щелчок по рамке дерева возвращают фокус ему. Мышью дерево работает как оглавление: щелчок по папке сразу показывает её в другой панели и переводит фокус туда, щелчок по `[+]` / `[-]` раскрывает или сворачивает ветку, не меняя фокуса; колесо мыши прокручивает дерево, не двигая курсор. Дерево следит и за другой панелью: если в ней перешли в другую папку, дерево раскрывает путь к ней и ставит на неё курсор, а для другого диска перестраивается. Папки читаются в фоне; если за это время панель под деревом перешла в другую папку, дерево закрывается. Дерево бывает открыто только над одной панелью.

**Быстрый просмотр (Ctrl+Q)** показывает на соседней панели файл под курсором: картинку, текст (кодировка определяется сама), оформленный Markdown или hex-дамп двоичного файла; большие файлы читаются потоково. Колесо мыши над ним прокручивает просмотр. Файлы на SFTP и крупные файлы внутри архивов не читаются при каждом движении курсора – для них показывается подсказка открыть файл по F3. Tab или повторное Ctrl+Q закрывает быстрый просмотр.

**Консольные программы** (`.exe` консольной подсистемы, `.bat`, `.cmd`, `.ps1`) по Enter запускаются не в отдельном окне Windows, а так, чтобы их вывод остался на экране:
- в фоновой консоли (Ctrl+O), если её оболочка – cmd, PowerShell или pwsh и в ней ничего не выполняется: как команда, набранная в командной строке;
- иначе (консоль WSL, Git Bash, SSH или занята другой командой) – в новой вкладке терминала с cmd, а для `.ps1` – с PowerShell; после завершения программы вкладка остаётся открытой.

Оконные программы и документы открываются, как раньше, программой Windows. **Shift+Enter** по-прежнему запускает любой файл в отдельном окне.

Щелчок мышью ставит курсор, двойной щелчок – как Enter. Файлы можно перетаскивать мышью между панелями и в другие программы (и обратно).
