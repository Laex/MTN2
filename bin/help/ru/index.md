## Как пользоваться справкой

| Клавиша | Действие |
| --- | --- |
| Tab / Shift+Tab | следующая / предыдущая ссылка |
| Enter, щелчок по ссылке | перейти по ссылке |
| Backspace, Alt+← | вернуться назад |
| F1 | эта страница (содержание) |
| F7, Shift+F7 / Alt+F7 | поиск текста, следующее / предыдущее совпадение |
| ↑ ↓ PgUp PgDn Home End | прокрутка |
| Esc, F10 | закрыть справку |
