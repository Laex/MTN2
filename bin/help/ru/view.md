# Вид панели и сортировка

| Клавиша | Действие |
| --- | --- |
| Ctrl+\` | меню режимов колонок |
| Ctrl+Shift+F1 … F7 | режим: краткий, размер, дата, полный, создан, типы, свой |
| Ctrl+F12 | меню сортировки |
| Ctrl+F3 / F4 / F5 / F6 | сортировка по имени / расширению / дате изменения / размеру |
| Ctrl+F7 / F8 / F9 | без сортировки / по дате создания / по дате доступа |

Имена сравниваются без учёта регистра и по алфавиту языка системы, числа внутри имени — как числа: `file2` раньше `file10`, «абрикос» раньше «Яблоко», «ё» стоит рядом с «е» («ёлка» раньше «ель»), знаки препинания — перед буквами (`_build` раньше `A`). Повторный выбор того же порядка сортировки переключает направление. Буква в левом верхнем углу панели показывает сортировку (заглавная — по убыванию). Состав колонок режима «Свой» — **Настройки → Колонки...**. Раскраска строк по маскам — **Настройки → Цветовая разметка...**.
