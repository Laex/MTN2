# Поиск и фильтры

| Клавиша | Действие |
| --- | --- |
| Alt+F7 | поиск файлов (маска, содержимое, подпапки, регистр, слова целиком, регулярные выражения) |
| Ctrl+F | фильтр строк панели по маске «на лету»; в поле фильтра Ctrl+↓ / Alt+↓ — прежние маски |
| Ctrl+B | плоский вид: все файлы поддерева в одном списке |
| Alt+буква | быстрый поиск по имени |

Результаты поиска открываются как панель — с ними работают обычные операции.
