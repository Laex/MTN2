## Операции с файлами

| Клавиша | Действие |
| --- | --- |
| F3 | просмотр файла; на папках – подсчёт размера выделенных папок (Esc – отмена) |
| F4 | редактирование |
| Shift+F4 | создать файл |
| F5 | копировать |
| Shift+F5 | копия под другим именем в той же папке |
| F6 | переместить / переименовать |
| Shift+F6 | переименовать элемент под курсором |
| F7 | создать папку |
| Shift+F7 | создать ссылку (символьная ссылка, жёсткая ссылка, junction) |
| F8, Del | удалить в Корзину |
| Shift+F8, Shift+Del | удалить безвозвратно (затереть) |
| Ctrl+Shift+A | атрибуты, владелец и даты (создан / изменён / доступ) |
| Alt+Enter | окно «Свойства» Windows (для выделенных или элемента под курсором; только файлы и папки на диске) |
| Shift+F10, клавиша Menu | контекстное меню Windows (для выделенных или элемента под курсором) |
| Ctrl+Alt+C | сравнить файлы под курсорами обеих панелей |
| Ctrl+Alt+H | контрольные суммы (MD5, SHA-1, SHA-256, SHA-512) выделенных файлов и папок; на файле `.md5` / `.sha1` / `.sha256` / `.sha512` – проверка по нему |
| Ctrl+C / Ctrl+X / Ctrl+V | копировать / вырезать / вставить файлы через буфер обмена |
| Ctrl+Alt+Ins | скопировать полный путь в буфер обмена |
| Alt+Shift+Ins | скопировать только имя (без пути) в буфер обмена |

**Ctrl+Alt+Ins** и **Alt+Shift+Ins** берут выделенные элементы (по одному в строке), а без выделения – элемент под курсором; на `..` – текущую папку. Вставить результат можно где угодно по **Shift+Ins** / **Ctrl+V**. Копирование подтверждает короткое уведомление в правом нижнем углу (или сообщает, что копировать нечего); отключается в **Настройки → Шрифт / экран...**.

В диалоге **Ctrl+Shift+A** даты вводятся в формате даты системы, время – `чч:мм:сс` (секунды и время можно не указывать). Пустое поле – дата не меняется: так выглядят даты, которые у выделенных файлов различаются. **Текущее** ставит во все три поля текущее время, **Исходные** возвращает прочитанные значения. Флажок «Обрабатывать вложенные папки» действует и на даты.

**Контекстное меню Windows** – то же меню, что по правой кнопке мыши в Проводнике: «Открыть с помощью», «Отправить», пункты архиваторов, антивируса, систем контроля версий и т. п. Открывается по **Shift+F10** или клавише **Menu** у строки курсора, из меню **Файлы → Контекстное меню Windows** или удержанием правой кнопки мыши на файле около секунды. С клавиатуры и из меню оно действует на выделенные элементы, а без выделения – на элемент под курсором (на `..` – на текущую папку); удержание кнопки мыши открывает меню файла под мышью. Доступно только для файлов и папок на диске: у архивов, SFTP, Корзины и результатов поиска меню Windows нет.

Диалог копирования/перемещения позволяет: сохранить все временные метки, копировать только более новые файлы, копировать содержимое символьных ссылок, задать маску исключения. При конфликте имён программа спрашивает, что делать (заменить, пропустить, переименовать, для всех…).

**Контрольные суммы.** Расчёт идёт в фоне (Esc – отмена). В списке результата: **Копировать** – в буфер обмена, **Сохранить** – в `<файл>.sha256` (для одного файла) или `checksums.sha256` в папке панели. Проверка показывает для каждой строки `OK`, `FAILED` или `MISSING`. Понимаются строки `хеш *имя`, `хеш  имя` и `SHA256 (имя) = хеш`.
