## Операции с файлами

| Клавиша | Действие |
| --- | --- |
| F3 | просмотр файла; на папках – подсчёт размера выделенных папок (Esc – отмена) |
| F4 | редактирование |
| Shift+F4 | создать файл |
| F5 | копировать |
| Shift+F5 | копия под другим именем в той же папке |
| F6 | переместить / переименовать |
| Shift+F6 | переименовать элемент под курсором |
| F7 | создать папку |
| Alt+F6 | создать ссылку (символьная ссылка, жёсткая ссылка, junction) |
| F8, Del | удалить в Корзину |
| Shift+F8, Shift+Del | удалить безвозвратно (затереть) |
| Ctrl+A | атрибуты, владелец и даты (создан / изменён / доступ) |
| Alt+Enter | окно «Свойства» Windows (для выделенных или элемента под курсором; только файлы и папки на диске) |
| Shift+F10, клавиша Menu | контекстное меню Windows (для выделенных или элемента под курсором) |
| Ctrl+Alt+C | сравнить файлы под курсорами обеих панелей |
| Ctrl+Alt+H | контрольные суммы (MD5, SHA-1, SHA-256, SHA-512) выделенных файлов и папок; на файле `.md5` / `.sha1` / `.sha256` / `.sha512` – проверка по нему |
| Ctrl+C / Ctrl+X / Ctrl+V | копировать / вырезать / вставить файлы через буфер обмена |
| Alt+Shift+Ins | скопировать полный путь в буфер обмена |
| Ctrl+Shift+Ins | скопировать только имя (без пути) в буфер обмена |
| Ctrl+Z | описание файла: строка ввода, текст сохраняется в `Descript.ion` рядом с файлом |

**Alt+Shift+Ins** и **Ctrl+Shift+Ins** берут выделенные элементы (по одному в строке), а без выделения – элемент под курсором; на `..` – текущую папку. Вставить результат можно где угодно по **Shift+Ins** / **Ctrl+V**. Копирование подтверждает короткое уведомление в правом нижнем углу (или сообщает, что копировать нечего); отключается в **Настройки → Шрифт / экран...**.

В диалоге **Ctrl+A** даты вводятся в формате даты системы, время – `чч:мм:сс` (секунды и время можно не указывать). Пустое поле – дата не меняется: так выглядят даты, которые у выделенных файлов различаются. **Текущее** ставит во все три поля текущее время, **Исходные** возвращает прочитанные значения. Флажок «Обрабатывать вложенные папки» действует и на даты.

**Контекстное меню Windows** – то же меню, что по правой кнопке мыши в Проводнике: «Открыть с помощью», «Отправить», пункты архиваторов, антивируса, систем контроля версий и т. п. Открывается по **Shift+F10** или клавише **Menu** у строки курсора, из меню **Файлы → Контекстное меню Windows** или удержанием правой кнопки мыши на файле около секунды. С клавиатуры и из меню оно действует на выделенные элементы, а без выделения – на элемент под курсором (на `..` – на текущую папку); удержание кнопки мыши открывает меню файла под мышью. Доступно только для файлов и папок на диске: у архивов, SFTP, Корзины и результатов поиска меню Windows нет.

Диалог копирования/перемещения позволяет: сохранить все временные метки, копировать только более новые файлы, копировать содержимое символьных ссылок, задать маску исключения. При конфликте имён программа спрашивает, что делать (заменить, пропустить, переименовать, для всех…).

**Контрольные суммы.** Расчёт идёт в фоне (Esc – отмена). В списке результата: **Копировать** – в буфер обмена, **Сохранить** – в `<файл>.sha256` (для одного файла) или `checksums.sha256` в папке панели. Проверка показывает для каждой строки `OK`, `FAILED` или `MISSING`. Понимаются строки `хеш *имя`, `хеш  имя` и `SHA256 (имя) = хеш`.

**Защищённые папки.** Если копирование, перемещение, удаление, создание папки или переименование на локальном пути (например, в `C:\Program Files`) заканчивается ошибкой «Отказано в доступе», в окне ошибки появляется кнопка **Админ**, а создание папки и переименование спрашивают «Повторить от администратора?». После согласия Windows показывает обычный запрос UAC, и MTN2 запускает небольшой процесс-помощник с правами администратора: упавший элемент и остаток задания выполняются в нём, в тех же окнах прогресса и ошибок. До подтверждения ничего с этими правами не выполняется. Пока помощник работает, в заголовке окна стоит **[Помощник администратора]** и показано уведомление; он завершается сам через две минуты без работы или при закрытии MTN2. Помощник только копирует, перемещает, удаляет, создаёт папки и сохраняет текст на локальных путях: запускать программы он не умеет, а говорить с ним может только запустивший его MTN2. Для архивов и виртуальных папок такого шага нет. Если сам MTN2 запущен от имени администратора (правый щелчок, «Запуск от имени администратора»), в заголовке стоит **[Администратор]** и помощник не нужен; зато Windows блокирует перетаскивание из программ без повышенных прав, например из Проводника.
