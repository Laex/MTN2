# Вкладки и рабочие пространства

**Вкладки панели** — у каждой стороны свои:

| Клавиша | Действие |
| --- | --- |
| Ctrl+T | новая вкладка |
| Ctrl+W | закрыть вкладку |
| Ctrl+Tab | следующая вкладка |

**Рабочие пространства** — вкладки верхней строки. Каждое содержит свою пару панелей или терминал. Двойной щелчок по вкладке — переименовать, по пустому месту строки — создать новое.

**Сохранённые рабочие пространства** — **Ctrl+Shift+D** (список, переход, удаление), **Ctrl+Alt+Shift+D** — сохранить текущее.
