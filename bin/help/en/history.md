# History and folder hotlist

| Key | Action |
| --- | --- |
| Alt+F12 | history of visited folders |
| Alt+F11 | history of viewed and edited files |
| Alt+F8 | command history |
| Ctrl+D | folder hotlist |
| Ctrl+Alt+D | add the current folder to the hotlist |

In the lists: **Ins** — add, **F2** — edit, **Del** — delete (where applicable). Choosing an entry from the command history puts the command on the command line but does not run it.

**File history (Alt+F11)** — the last 100 files opened with F3/F4, newest first; the mark on the left is the mode the file was last opened in (**V** — view, **E** — edit). **Enter** opens the file in the same mode, **F3** / **F4** — in the viewer / editor, **Ctrl+Enter** — goes to the file in the panel, **Del** — removes it from the history. Typing filters the list by path. The position inside the file is restored.
