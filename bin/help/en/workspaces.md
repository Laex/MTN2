# Tabs and workspaces

**Panel tabs** — each side has its own:

| Key | Action |
| --- | --- |
| Ctrl+T | new tab |
| Ctrl+W | close the tab |
| Ctrl+Tab | next tab |

**Workspaces** — the tabs of the top row. Each one holds its own pair of panels or a terminal. A double click on a tab renames it, a double click on an empty spot of the row creates a new one.

**Saved workspaces** — **Ctrl+Shift+D** (list, jump, delete), **Ctrl+Alt+Shift+D** — save the current one.
