# Synchronization and comparison

- **Ctrl+Alt+S** — synchronize the folders of the active and passive panels: one-way or two-way; the dry-run check box shows what would be done without changing anything.
- **Ctrl+Alt+C** — compare the files under the cursors of both panels.
- **Ctrl+Shift+C** — compare folders: both panels select the files missing on the other side and the newer of same-named ones; same time but a different size selects both. Folders are selected only when missing on the other side. The current panel lists are compared, without subfolders, so it works in archives and on SFTP too.
